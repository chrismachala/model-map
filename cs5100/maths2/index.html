The maths route, v2: every step written out

The same route as the maths-first path (twelve shared pieces of maths, then every model rebuilt from them), rewritten for learning it properly the first time: plain-words explanations, every symbol named, several worked examples with every line of arithmetic, the common mistakes, and guided practice that walks you through each calculation before the checkpoint asks you to do it alone.

What’s different from the first maths path

The first maths path is still there, unchanged, with your progress. This v2 is a separate, longer version of the same route:

  • Plain words first. Each idea starts with what it is for and an everyday picture, before any formula.
  • Every symbol named. Each boxed formula comes with a “what each symbol means” table.
  • Worked examples in full. Every example is laid out as a table, column by column, so you can see where each number comes from. Nothing is skipped as “obvious”.
  • Common mistakes. Every step has a red box of the slips people actually make, such as squaring the raw coordinates instead of the gaps to the centroid, and how to spot them.
  • Guided practice before each checkpoint. “Try it with me” questions ask for one line of the working at a time (the gaps, then the squares, then the total). Only after that does the fresh-numbers checkpoint ask for the whole thing.
  • Working you can check. When a checkpoint marks you wrong twice, it shows the full table of working, plus the usual slip, so you can find exactly which line went wrong.

How the gating and progress work

Progress for v2 is saved under its own name in this browser, so it can’t touch your progress on the first maths path or the guided path. The rules are the same as before: pass each step’s checkpoints to open the next step, and pass the stage test (80%, 70% for the final) to open the next stage. Revision mode at the bottom of this page unlocks everything. If you already know a step, the “Jump to the stage test” button skips ahead.

Each stage takes about twice as long as its v1 version. That’s on purpose: the extra time goes into examples and practice.

How to use a stage

  1. Read the plain-words box and the formula, then cover the worked example and try it yourself on paper.
  2. Uncover the worked example and compare it line by line. Each table column is one small step.
  3. Read the common mistakes, then do the “Try it with me” questions. They check one line of working at a time.
  4. Do the fresh-numbers checkpoint. If you get it wrong twice, read the working table, press New numbers and try again until you get two right in a row.
  5. Take the stage test with the lesson closed, as in the exam.

A habit that prevents most mistakes: write the table. For almost every calculation in this course (SSE, RSS, Gini, softmax, likelihood, distances) the safest layout is a table with one row per data point and one column per small step, with a total row at the bottom. The worked examples all use it, so by the end it will be automatic.

A4 Derivatives and gradient descent \(\beta \leftarrow \beta - \eta\nabla L\); chain rule least squares, logistic regression, backpropagation, K-means
A5 Fit + penalty \(\text{loss} + \lambda\cdot\text{complexity}\) ridge, penalised logistic, pruning, weight decay, boosting’s \(\eta\)
A6 Bayes’ rule \(P(Y{=}k\mid x) = \frac{\pi_kf_k(x)}{\sum_l\pi_lf_l(x)}\) Bayes classifier, LDA, naive Bayes, the sign test, the bootstrap’s 36.8%
A7 Gaussian density \(f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-(x - \mu)^2/2\sigma^2}\) LDA, naive Bayes, least squares, the Gaussian kernel
A8 Sigmoid and softmax \(\sigma(z) = \frac{1}{1 + e^{-z}}\), \(\ \text{softmax}_k(z) = \frac{e^{z_k}}{\sum e^{z_{k'}}}\) logistic and multinomial regression, LDA’s posterior, neural networks
A9 Likelihood and cross-entropy \(-\sum_i\log p_{y_i}(x_i)\); gradient \((p - y)\tilde x\) fitting logistic regression and NN classifiers, entropy impurity
A10 Impurity \(E\), \(G = \sum_k\hat p_k(1 - \hat p_k)\), \(D = -\sum_k\hat p_k\log\hat p_k\) classification trees and everything built from them
