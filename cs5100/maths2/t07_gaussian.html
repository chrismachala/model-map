The Gaussian bell curve

One formula, four jobs: LDA and naive Bayes use it as each class's shape, least squares is secretly maximum likelihood under it, and the Gaussian kernel uses it to smooth densities. The key insight is that its logarithm is a squared distance, which is why it fits so neatly with everything in Toolkit 3. This stage evaluates it slowly, takes its log, and builds LDA's decision rule from it.

By the end of this stage you can

  • evaluate the Gaussian density at a point in four small steps;
  • explain what \(\mu\) and \(\sigma^2\) do to the curve, and why the density can exceed 1;
  • take the log of the density and see the squared distance inside it;
  • derive the one-input LDA discriminant \(\delta_k(x)\) and use it to classify;
  • estimate LDA’s means, pooled variance and priors from data, and find the decision boundary.

1. The formula, piece by piece

In plain words

The bell curve says “values near the centre \(\mu\) are common; values far away are rare, and they get rare very fast”. The spread \(\sigma\) sets how far “far” is. The formula is a squared gap, scaled by the spread, fed into \(e^{-(\cdot)}\) so it becomes a number between 0 and 1, then multiplied by a constant so the total area is 1.

\[\boxed{f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\Big(-\frac{(x - \mu)^2}{2\sigma^2}\Big)}\]

Symbol Meaning
\(\mu\) the mean: where the peak is
\(\sigma\) the standard deviation: the spread; \(\sigma^2\) is the variance
\((x - \mu)^2\) squared gap from the centre (Toolkit 3)
\(\frac{(x - \mu)^2}{2\sigma^2}\) the gap measured in units of the spread
\(\frac{1}{\sqrt{2\pi\sigma^2}}\) the constant that makes the area 1 (and the peak height)

Four steps every time: (1) gap \(x - \mu\); (2) exponent \(\frac{(x - \mu)^2}{2\sigma^2}\); (3) constant \(\frac{1}{\sqrt{2\pi\sigma^2}}\); (4) \(f = \text{constant}\times e^{-\text{exponent}}\).

Worked example 1. \(\mu = 5\), \(\sigma = 2\) (so \(\sigma^2 = 4\)).

\(x\) gap exponent \(\frac{\text{gap}^2}{8}\) \(e^{-\text{exponent}}\) \(f(x) = 0.1995\times e^{-\cdot}\)
5 0 0 1 0.1995
7 2 0.5 0.6065 0.1210
9 4 2 0.1353 0.0270
3 −2 0.5 0.6065 0.1210

Constant: \(\frac{1}{\sqrt{2\pi\times4}} = \frac{1}{\sqrt{25.13}} = 0.1995\). Notice \(x = 3\) and \(x = 7\) give the same value (symmetry), and doubling the gap from 2 to 4 quadruples the exponent.

Worked example 2: a density can be bigger than 1. \(\mu = 4\), \(\sigma = 0.5\) (\(\sigma^2 = 0.25\)). Constant \(\frac{1}{\sqrt{2\pi\times0.25}} = 0.798\). At \(x = 4\): \(f = 0.798\). With \(\sigma = 0.1\) the peak would be \(3.99\). A density is a height, not a probability; only the area must be 1.

Common mistakes

  • \(\sigma\) where the formula wants \(\sigma^2\). Read whether you were given the standard deviation or the variance. \(2\sigma^2\) with \(\sigma = 2\) is \(8\), not \(4\).
  • Dropping the minus in the exponent. \(e^{+0.5} = 1.65\) would put \(f(7)\) above the peak. Every \(e^{-\text{exponent}}\) must be at most 1.
  • Forgetting the square root in the constant.

Standard normal: \(\mu = 0\), \(\sigma = 1\). At \(x = 1\), give the gap, the exponent, the constant and \(f(1)\).

Gap 1. Exponent \(1/2 = 0.5\). Constant \(1/\sqrt{2\pi} = 0.3989\). \(f(1) = 0.3989\times e^{-0.5} = 0.3989\times0.6065 = 0.2420\).

2. The log is a squared distance

In plain words

Taking the log undoes the \(e^{(\cdot)}\), and what’s left is a constant minus a squared gap. So “most probable under a Gaussian” means “closest in squared distance”. That is the bridge between probability and squared error.

\[\log f(x) = \underbrace{-\tfrac12\log(2\pi\sigma^2)}_{\text{constant}} - \frac{(x - \mu)^2}{2\sigma^2}\]

Consequences you’ll meet:

Where What the log gives
Least squares (w2) if \(y_i = \beta\cdot\tilde x_i + \text{Gaussian noise}\), maximising the likelihood = minimising \(\sum(y_i - \beta\cdot\tilde x_i)^2\)
LDA (w3) the class score \(\log(\pi_kf_k(x))\) becomes linear in \(x\) (section 3)
Gaussian kernel (w7) each data point adds a small bell, \(e^{-\|x - x_i\|^2/2h^2}\)

Worked example 3: least squares is maximum likelihood. For \(n\) points with Gaussian noise of variance \(\sigma^2\):

\[\log\ell(\beta) = \sum_i\log f(y_i) = n\times\text{const} - \frac{1}{2\sigma^2}\sum_i(y_i - \beta\cdot\tilde x_i)^2.\]

The first part doesn’t depend on \(\beta\), and the second is \(-\frac{1}{2\sigma^2}\text{RSS}(\beta)\). So the \(\beta\) that maximises the log-likelihood is the one that minimises the RSS.

3. From Gaussian to LDA’s rule

In plain words

LDA describes each class by a bell curve with its own centre \(\mu_k\) but the same spread \(\sigma^2\), then uses Bayes’ rule. Because every class shares \(\sigma^2\), the \(x^2\) part of each log score is identical and cancels, leaving a score that is a straight line in \(x\). Pick the class with the biggest score.

Derivation, one step at a time. Start from the Bayes score \(\pi_kf_k(x)\) and take logs:

Step Working
log of the score \(\log\pi_k - \frac12\log(2\pi\sigma^2) - \frac{(x - \mu_k)^2}{2\sigma^2}\)
expand the square \((x - \mu_k)^2 = x^2 - 2x\mu_k + \mu_k^2\)
substitute \(\log\pi_k - \frac12\log(2\pi\sigma^2) - \frac{x^2}{2\sigma^2} + \frac{x\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2}\)
drop what’s the same for every class \(-\frac12\log(2\pi\sigma^2)\) and \(-\frac{x^2}{2\sigma^2}\)

\[\boxed{\delta_k(x) = \frac{x\,\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log\pi_k},\qquad \text{predict }\arg\max_k\delta_k(x).\]

With two classes the boundary is where \(\delta_0 = \delta_1\):

\[x^* = \frac{\mu_0 + \mu_1}{2} + \frac{\sigma^2}{\mu_1 - \mu_0}\log\frac{\pi_0}{\pi_1}.\]

With equal priors the log term is 0 and the boundary is the midpoint of the two means.

Estimates from data: \(\hat\pi_k = n_k/n\); \(\hat\mu_k\) = mean of class \(k\); pooled variance \(\hat\sigma^2 = \frac{1}{n - K}\sum_k\sum_{i\in k}(x_i - \hat\mu_k)^2\) (gaps from each point’s own class mean, \(K\) = number of classes).

Worked example 4. Class 0: \(x = (1, 2, 3)\). Class 1: \(x = (6, 7, 8)\).

class \(x_i\) \(x_i - \hat\mu_k\) squared
0 1 1 − 2 = −1 1
0 2 0 0
0 3 1 1
1 6 6 − 7 = −1 1
1 7 0 0
1 8 1 1
total 4

\(\hat\mu_0 = 2\), \(\hat\mu_1 = 7\), \(\hat\sigma^2 = 4/(6 - 2) = 1\), \(\hat\pi_0 = \hat\pi_1 = 0.5\).

Classify \(x = 4\) and \(x = 5\) (\(\log0.5 = -0.693\)):

\(x\) \(\delta_0 = 2x - 2 - 0.693\) \(\delta_1 = 7x - 24.5 - 0.693\) class
4 8 − 2 − 0.693 = 5.307 28 − 24.5 − 0.693 = 2.807 0
5 10 − 2 − 0.693 = 7.307 35 − 24.5 − 0.693 = 9.807 1

Boundary: midpoint \((2 + 7)/2 = 4.5\). ✓

Unequal priors. If instead \(\hat\pi_0 = 0.75\), \(\hat\pi_1 = 0.25\): \(x^* = 4.5 + \frac{1}{5}\log3 = 4.5 + 0.220 = 4.720\). The boundary moves towards the rarer class’s mean, so the common class claims more of the line.

Common mistakes

  • Gaps from the overall mean. The pooled variance uses each point’s own class mean. (Week 3 slide (31) does it with the overall mean; that mixes in the gap between the classes and gives a much bigger \(\sigma^2\).)
  • Dividing by \(n\) instead of \(n - K\). With 6 points and 2 classes, divide by 4.
  • Boundary direction with unequal priors. It shifts away from the more common class, towards the rarer one.

Try it with me. Class 0: \(x = (0, 2, 4)\). Class 1: \(x = (5, 7, 9)\).

Give both means, the total of the squared within-class gaps, the pooled variance and the decision boundary (equal priors).

\(\hat\mu_0 = 2\), \(\hat\mu_1 = 7\). Gaps \((-2, 0, 2)\) and \((-2, 0, 2)\): squares add to \(8 + 8 = 16\). \(\hat\sigma^2 = 16/4 = 4\). Boundary \((2 + 7)/2 = 4.5\).

Stage test

LDA, one input, equal priors, \(\hat\mu_0 = 1\), \(\hat\mu_1 = 7\), \(\hat\sigma^2 = 2\). Where is the decision boundary?

Equal priors cancel the log term: midpoint \((1 + 7)/2 = 4\).

Why is LDA’s decision boundary linear in \(x\)?

With a different variance per class (QDA) the \(x^2\) terms don’t cancel and the boundary is curved.
