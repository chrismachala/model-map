Linear, polynomial and ridge regression

The whole linear family is three toolkit pieces: a dot product for the prediction, squared error for the score, and "derivative = 0" to fit. Polynomial and step regression just invent new columns and reuse the same maths. Ridge adds a penalty. This stage does the matrix formula on a tiny example so you can see it agree with the slope formula.

Built from

1. The assembly

\[\hat y = \underbrace{\beta\cdot\tilde x}_{\text{A1}},\qquad \hat\beta = \arg\min_\beta\underbrace{\sum_i(y_i - \beta\cdot\tilde x_i)^2}_{\text{A3: RSS}}\quad\Rightarrow\quad\underbrace{\mathbf X^T\mathbf X\hat\beta = \mathbf X^T\mathbf y}_{\text{A4: gradient} = 0}\]

Symbol Meaning
\(\mathbf X\) the \(n\times(p + 1)\) design matrix: one row per point, first column all 1s
\(\mathbf y\) the column of \(n\) responses
\(\mathbf X^T\mathbf X\) a \((p + 1)\times(p + 1)\) matrix of sums of products of columns
\(\hat\beta = (\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y\) the least-squares coefficients

Worked example 1: the matrix formula on three points. \(x = (0, 1, 2)\), \(y = (1, 3, 4)\).

\[\mathbf X = \begin{pmatrix}1 & 0\\1 & 1\\1 & 2\end{pmatrix},\quad \mathbf X^T\mathbf X = \begin{pmatrix}3 & 3\\3 & 5\end{pmatrix},\quad \mathbf X^T\mathbf y = \begin{pmatrix}1 + 3 + 4\\0 + 3 + 8\end{pmatrix} = \begin{pmatrix}8\\11\end{pmatrix}.\]

Where the entries come from: top-left = \(\sum1 = n = 3\); off-diagonal = \(\sum x_i = 3\); bottom-right = \(\sum x_i^2 = 0 + 1 + 4 = 5\).

Invert the \(2\times2\): determinant \(3\times5 - 3\times3 = 6\), so \((\mathbf X^T\mathbf X)^{-1} = \frac16\begin{pmatrix}5 & -3\\-3 & 3\end{pmatrix}\).

\[\hat\beta = \frac16\begin{pmatrix}5\times8 - 3\times11\\-3\times8 + 3\times11\end{pmatrix} = \frac16\begin{pmatrix}7\\9\end{pmatrix} = \begin{pmatrix}1.167\\1.5\end{pmatrix}.\]

Check with the slope formula (Toolkit 4): \(\bar x = 1\), \(\bar y = 8/3\); deviations \((-1, 0, 1)\) and \((-\frac53, \frac13, \frac43)\); \(S_{xy} = \frac53 + 0 + \frac43 = 3\), \(S_{xx} = 2\); \(\hat\beta_1 = 1.5\), \(\hat\beta_0 = \frac83 - 1.5 = 1.167\) ✓. Same answer, two routes.

Common mistakes

  • Forgetting the column of 1s in \(\mathbf X\): you’d fit a line forced through the origin.
  • \(2\times2\) inverse slips. Swap the diagonal, negate the off-diagonal, divide by the determinant \(ad - bc\).
  • Order of multiplication. \((\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y\), not \(\mathbf X^T\mathbf y(\mathbf X^T\mathbf X)^{-1}\).

For \(x = (0, 1, 2, 3)\) with an intercept, \(\mathbf X^T\mathbf X = \begin{pmatrix}a & b\\b & c\end{pmatrix}\). Give \(a\), \(b\) and \(c\).

\(a = n = 4\), \(b = 0 + 1 + 2 + 3 = 6\), \(c = 0 + 1 + 4 + 9 = 14\).

2. New columns, same maths

In plain words

To fit a curve, don’t change the method: change the columns. Add \(x^2\), \(x^3\) as extra inputs and fit a “linear” model to them. It’s linear in the coefficients (which is all least squares cares about), even though it’s curved in \(x\). Step functions do the same with indicator columns \(\mathbb 1(c_1 \le x < c_2)\).

Basis Row of \(\mathbf X\) for input \(x\) Coefficients
straight line \((1, x)\) 2
polynomial, degree \(d\) \((1, x, x^2, \dots, x^d)\) \(d + 1\)
step functions, cuts \(c_1 < \dots < c_K\) \((1, \mathbb 1(c_1 \le x < c_2), \dots, \mathbb 1(x \ge c_K))\) \(K + 1\)
full polynomial in 2 inputs, degree \(d\) all \(x_1^ax_2^b\) with \(a + b \le d\) \(\frac{(d + 1)(d + 2)}{2}\)

Worked example 2. Cubic model \(\hat y = 1 + 0.5x - x^2 + 0.25x^3\) at \(x = 2\).

term column value coefficient product
1 1 1 1
\(x\) 2 0.5 1
\(x^2\) 4 −1 −4
\(x^3\) 8 0.25 2
total 0

\(\hat y(2) = 0\). It’s just a dot product (Toolkit 1) with a longer row.

Counting coefficients (2024 Q1 style). Degree 3 in two inputs: terms \(1;\ x_1, x_2;\ x_1^2, x_1x_2, x_2^2;\ x_1^3, x_1^2x_2, x_1x_2^2, x_2^3\), that is \(1 + 2 + 3 + 4 = 10 = \frac{4\times5}{2}\) ✓.

Common mistakes

  • “Polynomial regression is non-linear regression.” It’s non-linear in \(x\) but linear in \(\beta\), so ordinary least squares still works.
  • Forgetting the constant term when counting coefficients.
  • High degree = better. More columns = more flexible = more variance. Choose \(d\) by validation error.

For \(x = -2\), give the cubic row \((1, x, x^2, x^3)\), then \(\hat y\) for \(\beta = (1, 0.5, -1, 0.25)\).

Row \((1, -2, 4, -8)\). Products: \(1\times1 = 1\); \(0.5\times(-2) = -1\); \(-1\times4 = -4\); \(0.25\times(-8) = -2\). Total \(-6\).

3. Ridge: add the penalty

\[\hat\beta^{\text{ridge}} = \arg\min_\beta\ \underbrace{\text{RSS}(\beta)}_{\text{A3}} + \underbrace{\lambda\sum_{j\ge1}\beta_j^2}_{\text{A5}}\]

Set the gradient to zero again: with centred inputs (so the intercept is just \(\bar y\)), \(\hat\beta^{\text{ridge}} = (\mathbf X^T\mathbf X + \lambda I)^{-1}\mathbf X^T\mathbf y\). With one centred input this is \(\frac{\sum x_iy_i}{\sum x_i^2 + \lambda}\) (Toolkit 5). The \(+\lambda\) on the diagonal also makes the matrix invertible even when inputs are perfectly correlated.

4. Scoring the fit

RSS, TSS and \(R^2 = 1 - \text{RSS}/\text{TSS}\) (Toolkit 3). On training data, adding columns can only lower the RSS and raise \(R^2\), so neither can choose the degree or \(\lambda\): use validation MSE.

Stage test

Polynomial regression of degree 5 on one input is fitted by…

“Linear” in linear regression means linear in the coefficients.

(4 marks; 2024 Q1.) Write a linear regression model with \(\lambda \in \mathbb R^2\), the objective used to fit it, and how ridge regression changes that objective and why.

The model is \(f(X) = \lambda_0 + \lambda_1X\). It is fitted by least squares: choose \(\lambda\) to minimise \(\text{RSS}(\lambda) = \sum_{i=1}^n(y_i - \lambda_0 - \lambda_1x_i)^2\), giving \(\hat\lambda_1 = \sum(x_i - \bar x)(y_i - \bar y)/\sum(x_i - \bar x)^2\) and \(\hat\lambda_0 = \bar y - \hat\lambda_1\bar x\). Ridge regression minimises \(\text{RSS}(\lambda) + \alpha\lambda_1^2\) instead (the intercept is not penalised). The penalty shrinks \(\lambda_1\) towards zero, which reduces variance and overfitting, especially with many or correlated inputs, at the cost of some bias; \(\alpha\) is chosen on a validation set.
