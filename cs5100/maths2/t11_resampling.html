Resampling and averaging many models

Two questions run through the second half of the course. How do you measure test error honestly when all you have is training data? And how do you make a wobbly model steadier? The answers are resampling (validation sets, the bootstrap, out-of-bag points) and averaging (bagging, random forests). This stage does the OOB calculation the way the 2023 and 2025 exams ask it, row by row.

By the end of this stage you can

  • explain what the training, validation and test sets are each for, and the mistake of tuning on the test set;
  • describe a bootstrap sample and compute the chance a point is left out, \((1 - 1/n)^n\);
  • compute the variance of an average of \(B\) correlated models, and say what bagging and random forests change in it;
  • find each point’s out-of-bag predictions from a table of bootstrap sets, and compute the OOB MSE or OOB error rate.

1. Train, validation, test

In plain words

Training error always falls as a model gets more flexible, so it can’t tell you when to stop. Think of three separate piles of exam papers: one to learn from (training), one to choose your study strategy with (validation), and one sealed final exam you sit once (test). Peek at the final while choosing a strategy, and your final mark no longer means what it says.

Set Used for Never used for
training fitting the parameters (\(\beta\), the tree, the weights) judging the model
validation choosing knobs: \(K\), \(\lambda\), \(\alpha\), the degree, the epochs fitting parameters
test one final, honest error estimate choosing anything

You try 20 values of \(\lambda\) for ridge and report the lowest test error among them. What’s wrong?

The minimum of 20 noisy numbers favours whichever value got lucky on those particular test points.

2. The bootstrap

In plain words

A bootstrap sample is made by drawing \(n\) points from your \(n\) training points with replacement: like pulling numbered balls from a bag, writing the number down, and putting the ball back. Some points come out several times, some never. Each sample is a slightly different “alternative training set”.

The chance a given point is never drawn (Toolkit 6): each draw misses it with probability \(1 - \frac1n\), and the \(n\) draws are independent, so

\[\Big(1 - \frac1n\Big)^n \;\to\; e^{-1} \approx 0.368.\]

So each bootstrap sample contains about 63.2% of the distinct points; the other 36.8% are out of bag (OOB) for that sample. The slides’ proof: \(\log(1 - \frac1n)^n = n\log(1 - \frac1n) \approx n\times(-\frac1n) = -1\).

Worked example 1. \(n = 5\) points \(\{1, 2, 3, 4, 5\}\). One bootstrap sample: \(\{2, 2, 3, 5, 5\}\). Points 1 and 4 are OOB. \(P(\text{a given point is OOB}) = 0.8^5 = 0.328\), so on average \(5\times0.328 = 1.64\) points are OOB: here we got 2.

Give \((1 - 1/n)^n\) for \(n = 3\) and \(n = 10\).

\(n = 3\): \((2/3)^3 = 8/27 = 0.2963\). \(n = 10\): \(0.9^{10} = 0.3487\). Both creep up towards \(0.368\) as \(n\) grows.

3. Averaging cuts variance

In plain words

Ask one nervous friend for a guess and you get a wobbly answer. Ask 100 friends and average: the wobble shrinks, as long as they don’t all copy each other. If they’re correlated, there’s a floor the average can’t go below.

\[\boxed{\mathrm{Var}\Big(\frac1B\sum_{b=1}^{B}\hat f_b\Big) = \rho\sigma^2 + \frac{1 - \rho}{B}\sigma^2}\]

Symbol Meaning
\(B\) number of models averaged
\(\sigma^2\) variance of one model’s prediction
\(\rho\) correlation between any two models’ predictions
\(\rho\sigma^2\) the floor as \(B \to \infty\)

Worked example 2. \(\sigma^2 = 4\).

setting \(\rho\) \(B\) \(\rho\sigma^2\) \(\frac{1 - \rho}{B}\sigma^2\) variance
one model 1 4
bagging, 10 trees 0.2 10 0.8 0.8 × 4/10 = 0.32 1.12
bagging, many trees 0.2 ∞ 0.8 0 0.8
random forest, 10 trees 0.05 10 0.2 0.95 × 4/10 = 0.38 0.58
independent, 10 models 0 10 0 0.4 0.4

More trees help until the floor \(\rho\sigma^2\). Only lowering \(\rho\) pushes the floor down, which is exactly what random forests do by letting each split consider only a random subset of \(m\) inputs. Averaging doesn’t change the bias.

Common mistakes

  • Expecting variance \(\to 0\) as \(B\) grows. Only if \(\rho = 0\).
  • “More trees overfit” is false for bagging and forests (they just average); it’s true for boosting (Toolkit 5).
  • Forgetting the \((1 - \rho)\) in the second term.

4. Out-of-bag error: a free validation set

In plain words

Each tree in a bagged ensemble never saw its OOB points. So to test a point honestly, ask only the trees that didn’t train on it, average (or vote) their predictions, and compare with the truth. Do it for every point and average the errors: that’s the OOB error, a test-error estimate with no data held back.

The recipe, for each point: (1) find the bootstrap sets that do not contain it; (2) take those sets’ models’ predictions at that point; (3) average them (regression) or vote (classification); (4) compare with the true value. Then average the squared errors (OOB MSE) or the mistakes (OOB error rate) over the points.

Worked example 3: the exam format. Data \(D = \{(1, 3), (2, 5), (4, 4), (6, 8)\}\) as \((x, y)\). Five bootstrap sets and their models’ predictions at each \(x\):

set contents \(\hat y(1)\) \(\hat y(2)\) \(\hat y(4)\) \(\hat y(6)\)
BTS1 (1,3), (1,3), (2,5), (4,4) 3 5 4 6
BTS2 (2,5), (4,4), (4,4), (6,8) 4 5 4 8
BTS3 (1,3), (2,5), (6,8), (6,8) 3 5 7 8
BTS4 (1,3), (4,4), (6,8), (6,8) 3 4 4 8
BTS5 (2,5), (2,5), (4,4), (6,8) 5 5 4 8

Bold = the set does not contain that point, so its prediction there is out-of-bag.

point \(x\) true \(y\) sets missing it OOB predictions OOB prediction squared error
1 3 BTS2, BTS5 4, 5 4.5 \((3 - 4.5)^2 = 2.25\)
2 5 BTS4 4 4 \((5 - 4)^2 = 1\)
4 4 BTS3 7 7 \((4 - 7)^2 = 9\)
6 8 BTS1 6 6 \((8 - 6)^2 = 4\)
total 16.25

OOB MSE \(= 16.25/4 = 4.0625\).

Worked example 4: classification, by vote. Points 1 to 5 with labels A, A, B, B, B. Each point’s OOB trees and their votes:

point label OOB trees’ votes OOB prediction correct?
1 A A, A A ✓
2 A B B ✗
3 B B B ✓
4 B B, B B ✓
5 B A A ✗

OOB error rate \(= 2/5 = 0.4\).

Common mistakes

  • Using the sets that DO contain the point. That’s a training prediction, not OOB. Look for the sets where the point is missing.
  • Averaging all five sets’ predictions. Only the OOB ones count.
  • A point in every set has no OOB prediction; leave it out of the average and say so.
  • Duplicates. A point that appears twice in a set is still “in” that set.

Try it with me. Use the table in worked example 3, but suppose BTS2’s prediction at \(x = 1\) were 2 instead of 4.

Give the new OOB prediction at \(x = 1\), its squared error, and the new OOB MSE.

OOB sets for \(x = 1\): BTS2 (now 2) and BTS5 (5): average \(3.5\). Squared error \((3 - 3.5)^2 = 0.25\). New total \(0.25 + 1 + 9 + 4 = 14.25\); OOB MSE \(= 14.25/4 = 3.5625\).

Stage test

Why do random forests usually beat bagging?

With a strong predictor, bagged trees all split on it first and look alike. Forests break that up.

Which statements are true? Tick all that apply.

More bagged trees only reduce variance; they don’t overfit.
