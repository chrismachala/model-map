Sigmoid, log-odds and softmax

A linear score can be any number, but a probability must sit between 0 and 1. The sigmoid squashes one score into a probability; softmax squashes a list of scores into probabilities that add to 1. Logistic regression, multinomial regression, LDA's posterior and every neural-network classifier end with one of them. This stage computes them step by step and translates between probabilities, odds and log-odds.

By the end of this stage you can

  • compute \(\sigma(z)\) in three steps and predict a class from a logistic model;
  • convert between probability, odds and log-odds, and read \(e^{\beta_1}\) as an odds multiplier;
  • compute a softmax by table and explain why adding a constant to every score changes nothing;
  • show that the sigmoid is softmax with two classes, and that LDA’s posterior is a softmax.

1. The sigmoid

In plain words

The sigmoid is a smooth “dimmer switch”. Very negative scores give probabilities near 0, very positive scores give near 1, and a score of 0 gives exactly 0.5. It never quite reaches 0 or 1.

\[\boxed{\sigma(z) = \frac{1}{1 + e^{-z}}}\]

Three steps every time: (1) the score \(z = \beta_0 + \beta_1x_1 + \dots\); (2) \(e^{-z}\); (3) \(p = 1/(1 + e^{-z})\).

\(z\) −2 −1 0 1 2
\(e^{-z}\) 7.389 2.718 1 0.368 0.135
\(\sigma(z)\) 0.119 0.269 0.5 0.731 0.881

Symmetry: \(\sigma(-z) = 1 - \sigma(z)\). So you only need to learn one half.

Worked example 1: predicting with logistic regression. \(\hat\beta_0 = -3\), \(\hat\beta_1 = 0.8\) (e.g. hours of revision → pass).

\(x\) \(z = -3 + 0.8x\) \(e^{-z}\) \(p = 1/(1 + e^{-z})\) class
2 −1.4 \(e^{1.4} = 4.055\) 1/5.055 = 0.198 0
5 1 \(e^{-1} = 0.368\) 1/1.368 = 0.731 1

Shortcut: \(p > 0.5\) exactly when \(z > 0\), i.e. here when \(x > 3/0.8 = 3.75\). The boundary is linear.

Common mistakes

  • \(e^{z}\) instead of \(e^{-z}\). You’d get \(1 - p\) instead of \(p\): at \(x = 5\) you’d report 0.269.
  • Forgetting the intercept in \(z\).
  • Calling \(p\) the class. \(p\) is a probability; the class needs a threshold (0.5 unless told otherwise).

\(\hat\beta_0 = -0.5\), \(\hat\beta_1 = 1\). At \(x = 2\), give \(z\), \(e^{-z}\) and \(p\).

\(z = -0.5 + 2 = 1.5\). \(e^{-1.5} = 0.2231\). \(p = 1/1.2231 = 0.8176\).

2. Odds and log-odds

In plain words

Bookmakers’ language. If \(p = 0.8\), the event is 4 times as likely to happen as not: the odds are 4 (to 1). The log-odds is the log of that. Logistic regression says the log-odds are a straight line in \(x\), so each extra unit of \(x\) adds \(\beta_1\) to the log-odds, which multiplies the odds by \(e^{\beta_1}\).

\[\text{odds} = \frac{p}{1 - p},\qquad \text{log-odds} = \log\frac{p}{1 - p} = z = \beta_0 + \beta_1x\]

Going from to do this
\(p\) odds \(p/(1 - p)\)
odds \(p\) \(\text{odds}/(1 + \text{odds})\)
\(p\) log-odds \(z\) \(\log\frac{p}{1 - p}\)
\(z\) \(p\) \(\sigma(z)\)

Worked example 2. \(p = 0.8\): odds \(= 0.8/0.2 = 4\); log-odds \(= \log4 = 1.386\). Check: \(\sigma(1.386) = 1/(1 + 0.25) = 0.8\) ✓.

\(p = 0.25\): odds \(= 0.25/0.75 = 1/3\); log-odds \(= \log(1/3) = -1.099\).

Worked example 3: reading a coefficient. In example 1, \(\beta_1 = 0.8\). At \(x = 5\), \(z = 1\), odds \(= e^1 = 2.718\). At \(x = 6\), \(z = 1.8\), odds \(= e^{1.8} = 6.050\). Ratio \(6.050/2.718 = 2.226 = e^{0.8}\). So “one more hour multiplies the odds of passing by \(e^{0.8} \approx 2.23\)”. It does not add 0.8 to the probability.

Common mistakes

  • “\(\beta_1\) is the change in probability.” It’s the change in log-odds. The change in probability depends on where you start.
  • Odds vs probability. Odds of 4 means \(p = 0.8\), not \(p = 4\) or \(0.25\).

\(p = 0.75\). Give the odds and the log-odds.

\(0.75/0.25 = 3\); \(\log3 = 1.0986\).

3. Softmax: many classes

In plain words

With \(m\) classes the model makes one score per class. Softmax turns them into probabilities: exponentiate each score (making it positive), then divide by the total so they add to 1. The biggest score always gets the biggest probability.

\[\boxed{\text{softmax}_k(z) = \frac{e^{z_k}}{\sum_{k'=1}^{m}e^{z_{k'}}}}\]

Worked example 4. Scores \(z = (1, 3, 0)\).

class \(k\) \(z_k\) \(e^{z_k}\) \(p_k = e^{z_k}/23.804\)
1 1 2.718 0.114
2 3 20.086 0.844
3 0 1 0.042
total 23.804 1

Predict class 2. Note how a 2-point lead in score becomes a big lead in probability: the exponential magnifies differences.

Worked example 5: only differences matter. \(z = (2, 1, 0)\): \(e^z = (7.389, 2.718, 1)\), total \(11.107\), \(p = (0.665, 0.245, 0.090)\). Now subtract 1 from every score: \(z = (1, 0, -1)\): \(e^z = (2.718, 1, 0.368)\), total \(4.086\), \(p = (0.665, 0.245, 0.090)\). Identical. Every \(e^{z_k}\) was divided by \(e^1\), top and bottom, so it cancels. (Computers use this to avoid overflow: subtract the largest score first.)

Common mistakes

  • Dividing scores by their sum without exponentiating: \(z/\sum z\) can be negative or divide by 0.
  • Rounding the exponentials too early. Keep 3 or 4 decimals until the final division.
  • Probabilities that don’t add to 1. Always check the total row.

Scores \(z = (2, 0, -1)\). Give each \(e^{z_k}\), their total and \(p_1\).

\(e^2 = 7.389\), \(e^0 = 1\), \(e^{-1} = 0.3679\). Total \(8.757\). \(p_1 = 7.389/8.757 = 0.8438\).

4. One family

In plain words

The sigmoid and softmax are the same idea. And LDA, which never mentions softmax, produces one anyway.

Sigmoid = two-class softmax. Give class 1 score \(z\) and class 0 score \(0\):

\[\text{softmax}_1 = \frac{e^z}{e^z + e^0} = \frac{e^z}{e^z + 1} = \frac{1}{1 + e^{-z}} = \sigma(z)\]

(divide top and bottom by \(e^z\) in the third step).

LDA’s posterior is a softmax. Bayes’ rule gives \(P(Y = k\mid x) = \frac{\pi_kf_k(x)}{\sum_l\pi_lf_l(x)}\). Write each \(\pi_kf_k(x)\) as \(e^{\log(\pi_kf_k(x))}\), and drop the factor every class shares (Toolkit 7): you get \(\frac{e^{\delta_k(x)}}{\sum_le^{\delta_l(x)}}\), a softmax of the linear discriminants. LDA and multinomial logistic regression give the same form of answer; they only differ in how they find the scores.

The lab’s double-softmax bug (w4). PyTorch’s nn.CrossEntropyLoss applies softmax itself. The lab’s ShallowNet.forward also ends with nn.Softmax, so the outputs get squashed twice. The predicted class survives, but with 10 classes the loss can’t go below \(\log(1 + 9/e) \approx 1.461\), which is why the lab’s loss stalls near 1.465.

Two-class LDA gives discriminants \(\delta_1(x) = \log3\) and \(\delta_0(x) = 0\) at some \(x\). Using the softmax form, what is \(P(Y = 1\mid x)\)?

\(\frac{e^{\log3}}{e^{\log3} + e^0} = \frac{3}{3 + 1} = 0.75\). Same as \(\sigma(\log3)\).

Stage test

(3 marks.) Show that with two classes, softmax reduces to the sigmoid.

With scores \(z_0 = 0\) and \(z_1 = z\) (only the difference matters, since adding a constant to both leaves softmax unchanged), \(\text{softmax}_1 = \frac{e^z}{e^0 + e^z} = \frac{e^z}{1 + e^z}\). Dividing numerator and denominator by \(e^z\) gives \(\frac{1}{e^{-z} + 1} = \sigma(z)\).

A logistic model has \(\hat\beta_1 = 0.5\) for input \(x_1\). What happens when \(x_1\) rises by 2, other inputs fixed?

Log-odds rise by \(2\times0.5 = 1\), so the odds are multiplied by \(e^1\).
