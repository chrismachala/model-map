Neural networks

A neural network with one hidden layer is a stack of Part A pieces: dot products, bent by ReLU or sigmoid, combined by another dot product, then fed into squared error (regression) or softmax and cross-entropy (classification). Training is gradient descent with the chain rule applied backwards: backpropagation. This stage does a forward pass, a parameter count and a backward pass, all by table.

1. The forward pass

In plain words

Each hidden unit computes its own linear score of the inputs and then “bends” it: ReLU sets negatives to 0; sigmoid squashes to (0, 1). The output is a linear score of those bent features. Without the bend, the whole network would collapse into one linear model.

\[A_k = g\Big(\underbrace{w_{k0} + \sum_{j=1}^pw_{kj}x_j}_{z_k,\ \text{A1}}\Big),\qquad f(x) = \beta_0 + \sum_{k=1}^K\beta_kA_k\]

Symbol Meaning
\(p\) number of inputs
\(K\) number of hidden units
\(w_{kj}\) weight from input \(j\) to hidden unit \(k\) (\(w_{k0}\) = its bias)
\(z_k\) hidden unit \(k\)’s pre-activation (a linear score)
\(g\) activation: ReLU \(\max(0, z)\) or sigmoid \(\sigma(z)\)
\(\beta_k\) output weights

Worked example 1. \(x = (1, 2)\). Hidden weights \(w_1 = (0.5, 1, -1)\), \(w_2 = (-1, 1, 1)\) (bias first). Output \(\beta = (0.5, 1, 1.5)\).

unit \(z_k = w_{k0} + w_{k1}x_1 + w_{k2}x_2\) ReLU \(A_k\) sigmoid \(A_k\)
1 0.5 + 1 − 2 = −0.5 0 0.3775
2 −1 + 1 + 2 = 2 2 0.8808

ReLU network: \(f = 0.5 + 1\times0 + 1.5\times2 = 3.5\). Sigmoid network: \(f = 0.5 + 0.3775 + 1.5\times0.8808 = 2.199\).

With ReLU, unit 1 is “off” for this input: it contributes nothing, and (section 3) receives no gradient.

Common mistakes

  • Forgetting the bias \(w_{k0}\) in each unit (the leading 1 again).
  • Applying ReLU to the output in a regression network. The output is linear.
  • Passing a negative \(z\) through ReLU. ReLU(−0.5) = 0.

\(x = (2, -1)\). \(w_1 = (0, 1, 1)\), \(w_2 = (1, -1, 1)\), \(\beta = (0.5, 2, 3)\), ReLU units. Give \(z_1\), \(z_2\), \(A_1\), \(A_2\) and \(f(x)\).

\(z_1 = 0 + 2 - 1 = 1\), \(A_1 = 1\). \(z_2 = 1 - 2 - 1 = -2\), \(A_2 = 0\). \(f = 0.5 + 2\times1 + 3\times0 = 2.5\).

2. Counting parameters

In plain words

Each hidden unit has one weight per input plus a bias. Each output has one weight per hidden unit plus a bias. Add them up.

\[\text{parameters} = \underbrace{K(p + 1)}_{\text{hidden layer}} + \underbrace{M(K + 1)}_{\text{output layer}}\]

with \(M = 1\) for regression and \(M\) = number of classes for a softmax classifier.

Worked example 2. \(p = 4\) inputs, \(K = 5\) hidden units, \(M = 1\): \(5\times5 + 1\times6 = 31\).

Digits (week 4 lab): \(p = 64\) pixels, \(K = 16\), \(M = 10\): \(16\times65 + 10\times17 = 1040 + 170 = 1210\).

\(p = 5\) inputs, \(K = 5\) hidden units, \(M = 1\) output. Count each layer and the total.

Hidden: \(5\times(5 + 1) = 30\). Output: \(1\times(5 + 1) = 6\). Total \(36\).

3. Training: the objective and backpropagation

\[\text{regression: }\sum_i\big(y_i - f(x_i)\big)^2,\qquad \text{classification: }-\sum_i\log p_{y_i}(x_i)\ \text{ with }p = \text{softmax}(f_1, \dots, f_M)\]

Both are non-convex in the weights: start from random weights, run gradient descent, maybe restart. Gradients come from the chain rule, applied from the loss backwards.

Worked example 3: one backward pass. One hidden ReLU unit: \(f = \beta_0 + \beta_1A\), \(A = \text{ReLU}(w_0 + w_1x)\). Loss \(R = (y - f)^2\). Point \(x = 2\), \(y = 5\); current \(w = (0, 1)\), \(\beta = (1, 1)\).

Forward: \(z = 0 + 1\times2 = 2\), \(A = 2\), \(f = 1 + 2 = 3\), residual \(y - f = 2\), loss \(4\).

Backward, one link of the chain at a time:

quantity rule value
\(\partial R/\partial f\) \(-2(y - f)\) −4
\(\partial R/\partial\beta_0\) \(\partial R/\partial f\times1\) −4
\(\partial R/\partial\beta_1\) \(\partial R/\partial f\times A\) −8
\(\partial R/\partial A\) \(\partial R/\partial f\times\beta_1\) −4
\(\partial R/\partial z\) \(\partial R/\partial A\times\text{ReLU}'(z)\), and \(z > 0\) so ReLU′ = 1 −4
\(\partial R/\partial w_0\) \(\partial R/\partial z\times1\) −4
\(\partial R/\partial w_1\) \(\partial R/\partial z\times x\) −8

Step with \(\eta = 0.05\): every parameter moves by \(-0.05\times\) its gradient: \(\beta = (1.2, 1.4)\), \(w = (0.2, 1.4)\). New forward pass: \(z = 3\), \(A = 3\), \(f = 1.2 + 4.2 = 5.4\); loss \(0.16\), down from 4 (a little overshoot past 5, a sign \(\eta\) is on the large side).

Common mistakes

  • Skipping the activation’s derivative. If \(z < 0\) for a ReLU unit, everything below it gets gradient 0.
  • Using the updated \(\beta_1\) when computing \(\partial R/\partial A\). Compute every gradient at the current weights, then update them all together.
  • Sign of \(\partial R/\partial f\). \(R = (y - f)^2\) gives \(-2(y - f)\).

Same network, now \(x = 2\), \(y = 2\), with \(w = (0, 1)\), \(\beta = (1, 1)\). Give the residual, \(\partial R/\partial f\), \(\partial R/\partial\beta_1\), \(\partial R/\partial z\) and \(\partial R/\partial w_1\).

Forward: \(z = 2\), \(A = 2\), \(f = 3\), residual \(2 - 3 = -1\). \(\partial R/\partial f = -2(-1) = 2\). \(\partial R/\partial\beta_1 = 2\times A = 4\). \(\partial R/\partial A = 2\times\beta_1 = 2\), and ReLU′(2) = 1, so \(\partial R/\partial z = 2\). \(\partial R/\partial w_1 = 2\times x = 4\). All positive now: the prediction is too big, so gradient descent will shrink these weights.

4. Why more flexible, and how to rein it in

More hidden units or layers = more flexibility (low bias, high variance). The course’s brakes: early stopping (stop when validation error starts rising), weight decay (\(+\lambda\sum w^2\), Toolkit 5), fewer units. Because the loss is non-convex, different random starts can end in different minima; keep the one with the best validation error.

Stage test

(4 marks; 2025 Q2.) What is a neural network with one hidden layer, and what objective is minimised to train it for (a) regression and (b) classification?

A one-hidden-layer network computes \(K\) features \(A_k = g(w_{k0} + \sum_{j=1}^pw_{kj}X_j)\), where \(g\) is a non-linear activation such as ReLU \(\max(0, z)\) or the sigmoid, and then outputs a linear model in those features, \(f(X) = \beta_0 + \sum_{k=1}^K\beta_kA_k\). For regression the weights are chosen to minimise the squared error \(\sum_i(y_i - f(x_i))^2\). For classification there are \(M\) outputs turned into probabilities by softmax, \(p_m = e^{f_m}/\sum_{m'}e^{f_{m'}}\), and the cross-entropy \(-\sum_i\log p_{y_i}(x_i)\) is minimised. In both cases the objective is non-convex and is minimised by gradient descent from random initial weights, with gradients computed by backpropagation (the chain rule).
