Impurity: error, Gini, entropy

A classification tree grows by asking: which split makes the groups purer? It needs a number for "how mixed is this bag of labels?". The course gives three: the classification error, the Gini index and the entropy. Each is zero for a pure node and largest for an even mix. Then a split is scored by the size-weighted impurity of its children. This stage computes all three by table and scores splits the way the 2024 and 2025 exams do.

By the end of this stage you can

  • compute class proportions \(\hat p_{mk}\) for a node and from them \(E\), \(G\) and \(D\), for two or more classes;
  • know each measure’s maximum for two classes, and why they’re all zero for a pure node;
  • compute the size-weighted impurity after a split and the gain (information gain for entropy);
  • compare candidate splits and pick the best, and explain why Gini or entropy is preferred to the error rate for growing.

Book and slides

ISLP 8.1.2 (classification trees: error rate eq. 8.5, Gini eq. 8.6, entropy eq. 8.7). Read all of 8.1.2. Skip the discussion of qualitative predictors with many levels. Week 4 slides use the same three measures, with classes numbered \(k = 0, \dots, M - 1\) and the entropy written \(S(R_m)\). ISLP uses the natural log; some past papers use \(\log_2\): either is fine if you say which.

1. Proportions first

In plain words

Every impurity formula works on proportions, not counts. For node \(m\), \(\hat p_{mk}\) is the fraction of its training points that are class \(k\). Get these right and the rest is plugging in.

\[\hat p_{mk} = \frac{\text{number of class-}k\text{ points in node }m}{\text{number of points in node }m}\]

The proportions in a node always add to 1. If they don’t, a count is wrong.

2. Three measures

In plain words

  • Error \(E\): if the node predicts its majority class, what fraction does it get wrong?
  • Gini \(G\): pick two points at random (with replacement); how likely are they to have different labels?
  • Entropy \(D\): how surprised are you, on average, by a point’s label (Toolkit 9)?

All three are 0 when the node is pure and biggest when the classes are evenly mixed.

\[\boxed{E = 1 - \max_k\hat p_{mk},\qquad G = \sum_k\hat p_{mk}(1 - \hat p_{mk}),\qquad D = -\sum_k\hat p_{mk}\log\hat p_{mk}}\]

Two classes, \(\hat p\) for class 1 0 0.25 0.5 0.75 1
\(E = \min(\hat p, 1 - \hat p)\) 0 0.25 0.5 0.25 0
\(G = 2\hat p(1 - \hat p)\) 0 0.375 0.5 0.375 0
\(D\) (natural log) 0 0.562 0.693 0.562 0

Maximum with two classes: \(E = 0.5\), \(G = 0.5\), \(D = \log2 = 0.693\) (or 1 bit with \(\log_2\)).

Worked example 1: two classes. A node with 6 A and 2 B.

class count \(\hat p_k\) \(\hat p_k(1 - \hat p_k)\) \(-\hat p_k\log\hat p_k\)
A 6 0.75 0.1875 0.2158
B 2 0.25 0.1875 0.3466
total 8 1 0.375 0.5623

\(E = 1 - 0.75 = 0.25\), \(G = 0.375\), \(D = 0.5623\).

Worked example 2: three classes. A node with 4 A, 3 B, 1 C.

class count \(\hat p_k\) \(\hat p_k(1 - \hat p_k)\) \(-\hat p_k\log\hat p_k\)
A 4 0.5 0.25 0.3466
B 3 0.375 0.2344 0.3678
C 1 0.125 0.1094 0.2599
total 8 1 0.5938 0.9743

\(E = 1 - 0.5 = 0.5\), \(G = 0.594\), \(D = 0.974\). With three classes the maxima are higher (\(G\) up to \(2/3\), \(D\) up to \(\log3 = 1.099\)).

Common mistakes

  • Counts instead of proportions. \(6\times2 = 12\) is not a Gini index.
  • Half a Gini. With two classes \(G = 2\hat p(1 - \hat p)\): the sum has two equal terms. Writing \(\hat p(1 - \hat p)\) once gives half the answer.
  • \(0\log0\). A class with no points contributes 0 to the entropy (the limit of \(p\log p\) as \(p \to 0\)). Don’t try to compute \(\log0\).
  • Forgetting the minus in the entropy: \(\log\hat p\) is negative, so \(-\hat p\log\hat p\) is positive.

Try it with me. A node with 2 A and 3 B.

Give the two proportions.

\(2/5 = 0.4\) and \(3/5 = 0.6\).

Now the error, the Gini index and the entropy.

\(E = 1 - 0.6 = 0.4\). \(G = 0.4\times0.6 + 0.6\times0.4 = 0.48\). \(D = -(0.4\log0.4 + 0.6\log0.6) = 0.3665 + 0.3065 = 0.673\).

3. Scoring a split: weighted impurity and gain

In plain words

A split sends some points left and some right. Its quality is the impurity of each child, weighted by how many points went there, added up. A child with 1 point shouldn’t count as much as a child with 50. The gain is how much the split lowered the impurity from the parent.

\[\text{impurity after} = \frac{n_L}{n}I(\text{left}) + \frac{n_R}{n}I(\text{right}),\qquad \text{gain} = I(\text{parent}) - \text{impurity after}\]

With entropy, the gain is called the information gain.

Worked example 3. Parent: 4 A, 4 B. Split sends (3 A, 0 B) left and (1 A, 4 B) right.

node A B size weight \(\hat p_A\) Gini entropy
parent 4 4 8 0.5 0.5 0.6931
left 3 0 3 3/8 1 0 0
right 1 4 5 5/8 0.2 0.32 0.5004

Gini after \(= \frac38\times0 + \frac58\times0.32 = 0.2\); gain \(= 0.5 - 0.2 = 0.3\).

Entropy after \(= \frac58\times0.5004 = 0.3128\); information gain \(= 0.6931 - 0.3128 = 0.3804\).

Worked example 4: why not just use the error rate? Parent 4 A, 4 B. Two candidate splits:

split left right error after Gini after
S1 (3 A, 1 B) (1 A, 3 B) \(\frac48(0.25) + \frac48(0.25) = 0.25\) \(\frac48(0.375) + \frac48(0.375) = 0.375\)
S2 (2 A, 4 B) (2 A, 0 B) \(\frac68(\frac13) + \frac28(0) = 0.25\) \(\frac68(0.444) + \frac28(0) = 0.333\)

The error rate can’t tell them apart (both 0.25). Gini prefers S2, because it creates a pure node that will never need splitting again. That’s the slides’ point: the error rate “is not sufficiently sensitive to grow a tree”. It is still the usual choice when pruning, where the final accuracy is what matters.

Common mistakes

  • Equal weights. \(\frac12(0 + 0.32) = 0.16\) is wrong here; the children have 3 and 5 points.
  • Weights from the wrong total. The weights are child size ÷ parent size, and they add to 1.
  • Gain with the sign flipped. Gain = parent − after; a good split has a positive gain.

Parent 5 A, 5 B. Split: left (4 A, 1 B), right (1 A, 4 B). Give the Gini of each child, the weighted Gini after, and the gain.

Each child has \(\hat p = 0.8\) or \(0.2\): \(G = 2\times0.8\times0.2 = 0.32\). Weighted: \(\frac5{10}(0.32) + \frac5{10}(0.32) = 0.32\). Gain \(= 0.5 - 0.32 = 0.18\).

Stage test

(3 marks; 2025 Q1.) Write the formula of the entropy and of the Gini index of a node in a classification tree, explaining the symbols.

For node \(m\) let \(\hat p_{mk}\) be the fraction of its training points in class \(k\). Entropy: \(D_m = -\sum_{k}\hat p_{mk}\log\hat p_{mk}\). Gini index: \(G_m = \sum_{k}\hat p_{mk}(1 - \hat p_{mk})\). Both are zero when the node contains a single class and largest when the classes are equally represented, so a split is chosen to make the size-weighted impurity of the children as small as possible.

A node has 6 of class 1 and 4 of class 0. What is its Gini index?

\(2\times0.6\times0.4 = 0.48\).
