Derivatives and gradient descent

Every "fit the model" step in the course is "make a loss as small as possible". There are two ways the course does it: set the derivative to zero and solve (least squares, ridge, the mean), or walk downhill one step at a time (logistic regression, neural networks). The chain rule supplies the derivatives both times. This stage builds each derivative from scratch and does full gradient steps by table.

By the end of this stage you can

  • differentiate the four functions that the course keeps using, and apply the chain rule to them;
  • derive the least-squares slope and intercept by setting derivatives to zero, and compute them from a deviations table;
  • do one or two gradient-descent steps on the RSS of a line, by table, with the signs right;
  • explain learning rates, convexity, local minima and restarts;
  • recognise the gradient pattern “(prediction − truth) × input”.

Book and slides

Week 1 slides, “calculus basics” (derivatives, chain rule, gradient, eq. 17); week 2 slides, “Gradient of the RSS” and gradient descent for the linear model (the slides minimise the RSS itself, not the MSE); week 3 slide eq. (17), \(\hat\beta^{(t+1)} \leftarrow \hat\beta^{(t)} - \eta\nabla(-\log\ell)\); week 4 slides on backpropagation. ISLP 3.1.1 (eq. 3.4) for the least-squares formulas, 10.7.1 to 10.7.2 for backpropagation and SGD. Skip momentum, Adam and dropout details in 10.7: the course uses plain gradient descent and early stopping.

1. Derivatives and the chain rule

In plain words

A derivative is a slope: how fast the output changes when you nudge the input. The gradient is the list of slopes, one per parameter; it points uphill, so minus the gradient points downhill. The chain rule handles functions inside functions: multiply the outer slope by the inner slope.

\[\boxed{\frac{d}{d\beta}g\big(h(\beta)\big) = g'\big(h(\beta)\big)\times h'(\beta)}\]

The four derivatives the course needs again and again:

Function Derivative Where
\((y - z)^2\) (as a function of \(z\)) \(-2(y - z)\) every squared-error fit
\(\log z\) \(1/z\) likelihoods (w3, w4)
\(\sigma(z) = \frac{1}{1 + e^{-z}}\) \(\sigma(z)\big(1 - \sigma(z)\big)\) logistic regression, sigmoid neurons
\(\text{ReLU}(z) = \max(0, z)\) \(1\) if \(z > 0\), \(0\) if \(z < 0\) ReLU neurons (w4)

Worked example 1: chain rule on one squared error. \(L(\beta) = (y - \beta x)^2\) with \(x = 2\), \(y = 5\), at \(\beta = 1\).

  • Outer: \(g(z) = (y - z)^2\) with \(z = \beta x\). \(g'(z) = -2(y - z)\).
  • Inner: \(z = \beta x\), so \(dz/d\beta = x\).
  • Together: \(L'(\beta) = -2(y - \beta x)\times x\).
  • Numbers: \(z = 2\), \(y - z = 3\), \(L'(1) = -2\times3\times2 = -12\).

Negative slope: increasing \(\beta\) lowers the loss, so gradient descent will increase \(\beta\).

Worked example 2: the sigmoid’s derivative (2023 Q3). \(\sigma(z) = (1 + e^{-z})^{-1}\).

  1. Outer: \(u^{-1}\) has derivative \(-u^{-2}\). Inner: \(u = 1 + e^{-z}\) has derivative \(-e^{-z}\).
  2. \(\sigma'(z) = -(1 + e^{-z})^{-2}\times(-e^{-z}) = \dfrac{e^{-z}}{(1 + e^{-z})^2}\).
  3. Split: \(\dfrac{1}{1 + e^{-z}}\times\dfrac{e^{-z}}{1 + e^{-z}} = \sigma(z)\times\big(1 - \sigma(z)\big)\), because \(\frac{e^{-z}}{1 + e^{-z}} = 1 - \frac{1}{1 + e^{-z}}\).

At \(z = 0\): \(\sigma = 0.5\), \(\sigma' = 0.25\), the steepest point of the S-curve.

Common mistakes

  • Dropping the inner derivative. \(\frac{d}{d\beta}(y - \beta x)^2\) is \(-2(y - \beta x)x\), not \(2(y - \beta x)\). The inner function \(y - \beta x\) has slope \(-x\).
  • \(\frac{d}{dz}e^{-z} = -e^{-z}\), with a minus.
  • ReLU at exactly 0 isn’t differentiable; exam questions avoid it.

Compute \(\sigma(1)\) and then \(\sigma'(1) = \sigma(1)(1 - \sigma(1))\).

\(e^{-1} = 0.3679\), so \(\sigma(1) = 1/1.3679 = 0.7311\). \(\sigma'(1) = 0.7311\times0.2689 = 0.1966\).

\(L(\beta) = (y - \beta x)^2\) with \(x = 3\), \(y = 2\), at \(\beta = 2\). Give the residual \(y - \beta x\) and then \(L'(\beta) = -2(y - \beta x)x\).

\(y - \beta x = 2 - 6 = -4\). \(L' = -2\times(-4)\times3 = 8\times3 = 24\). Positive slope, so gradient descent will decrease \(\beta\) (towards \(2/3\), where \(\beta x = y\)).

2. Way one: set the derivative to zero

In plain words

At the bottom of a smooth valley the slope is zero. If the loss is a squared error of a linear model, “slope = 0” gives linear equations you can solve exactly. That’s where the least-squares formulas come from.

For the line \(\hat y = \beta_0 + \beta_1x\) and \(\text{RSS} = \sum_i(y_i - \beta_0 - \beta_1x_i)^2\):

Step Working
derivative in \(\beta_0\) \(\partial_{\beta_0}\text{RSS} = -2\sum_i(y_i - \beta_0 - \beta_1x_i) = 0 \Rightarrow \beta_0 = \bar y - \beta_1\bar x\)
derivative in \(\beta_1\) \(\partial_{\beta_1}\text{RSS} = -2\sum_i(y_i - \beta_0 - \beta_1x_i)x_i = 0\)
substitute \(\beta_0\) and tidy \(\hat\beta_1 = \dfrac{\sum_i(x_i - \bar x)(y_i - \bar y)}{\sum_i(x_i - \bar x)^2} = \dfrac{S_{xy}}{S_{xx}}\)

\[\boxed{\hat\beta_1 = \frac{S_{xy}}{S_{xx}},\qquad \hat\beta_0 = \bar y - \hat\beta_1\bar x}\]

In matrix form for many inputs, the same “gradient = 0” gives \(\mathbf X^T\mathbf X\hat\beta = \mathbf X^T\mathbf y\), so \(\hat\beta = (\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y\).

Worked example 3. \(x = (1, 2, 3, 4)\), \(y = (2, 3, 5, 6)\). \(\bar x = 2.5\), \(\bar y = 4\).

\(x_i\) \(y_i\) \(x_i - \bar x\) \(y_i - \bar y\) product \((x_i - \bar x)^2\)
1 2 −1.5 −2 3 2.25
2 3 −0.5 −1 0.5 0.25
3 5 0.5 1 0.5 0.25
4 6 1.5 2 3 2.25
total 0 0 7 5

\(\hat\beta_1 = 7/5 = 1.4\). \(\hat\beta_0 = 4 - 1.4\times2.5 = 4 - 3.5 = 0.5\). Line: \(\hat y = 0.5 + 1.4x\).

Common mistakes

  • Using \(\sum x_iy_i\) and \(\sum x_i^2\) without centring. \(\sum x_iy_i/\sum x_i^2 = 50/30\) here, which is wrong. The plain sums only work if \(\bar x = 0\) (a “centred” input).
  • Swapping the means in \(\hat\beta_0\). It’s \(\bar y - \hat\beta_1\bar x\): the line passes through \((\bar x, \bar y)\).
  • Rounding \(\bar x\) early. Keep fractions until the end.

Data \(x = (0, 2, 4)\), \(y = (3, 3, 6)\). Build the deviations table, then give \(\bar x\), \(\bar y\), \(S_{xy}\), \(S_{xx}\), \(\hat\beta_1\) and \(\hat\beta_0\).

\(\bar x = 2\), \(\bar y = 4\). Deviations \(x_i - \bar x = (-2, 0, 2)\), \(y_i - \bar y = (-1, -1, 2)\). Products \(2, 0, 4\), so \(S_{xy} = 6\). Squares \(4, 0, 4\), so \(S_{xx} = 8\). \(\hat\beta_1 = 6/8 = 0.75\), \(\hat\beta_0 = 4 - 0.75\times2 = 2.5\).

3. Way two: gradient descent

In plain words

When “slope = 0” can’t be solved by algebra (a sigmoid or a ReLU is in the way), stand somewhere on the loss surface, look which way is downhill, take a small step that way, and repeat. The step size is the learning rate \(\eta\).

\[\boxed{\beta^{(t+1)} = \beta^{(t)} - \eta\,\nabla L\big(\beta^{(t)}\big)}\]

Symbol Meaning
\(\beta^{(t)}\) the parameters after \(t\) steps
\(\nabla L\) the gradient: one partial derivative per parameter
\(\eta\) learning rate (step size), a small positive number
minus sign step against the gradient, i.e. downhill

For the RSS of a line, from section 2: \(\partial_{\beta_0}\text{RSS} = -2\sum_ir_i\) and \(\partial_{\beta_1}\text{RSS} = -2\sum_ir_ix_i\), where \(r_i = y_i - \hat y_i\) is the residual at the current \(\beta\).

Worked example 4: two steps by table. Data \((1, 2)\), \((2, 4)\); start \(\beta = (0, 0)\); \(\eta = 0.05\).

Step 1. Predictions are all 0.

\(x_i\) \(y_i\) \(\hat y_i\) \(r_i\) \(r_ix_i\)
1 2 0 2 2
2 4 0 4 8
total 6 10

Gradient \(= (-2\times6,\ -2\times10) = (-12, -20)\). Update: \(\beta = (0, 0) - 0.05\times(-12, -20) = (0.6, 1.0)\). RSS fell from \(4 + 16 = 20\) to \((2 - 1.6)^2 + (4 - 2.6)^2 = 0.16 + 1.96 = 2.12\).

Step 2. Now \(\hat y = 0.6 + 1.0x\).

\(x_i\) \(y_i\) \(\hat y_i\) \(r_i\) \(r_ix_i\)
1 2 1.6 0.4 0.4
2 4 2.6 1.4 2.8
total 1.8 3.2

Gradient \(= (-3.6, -6.4)\). Update: \(\beta = (0.6 + 0.18,\ 1.0 + 0.32) = (0.78, 1.32)\). The exact answer is \(\beta = (0, 2)\) (the points lie on \(y = 2x\)); with more steps it gets there.

Common mistakes

  • Adding the gradient. \(\beta - \eta\nabla L\), never \(+\). If your loss goes up after a step, check this first.
  • Losing the \(-2\). The gradient of the RSS is \(-2\sum r_ix_i\). Forget the minus and you walk uphill.
  • Mixing up conventions. Some texts minimise \(\frac1n\)RSS or \(\frac12\)RSS; that only rescales the gradient (and so the effective \(\eta\)). Use the loss the question states.
  • \(\eta\) too big makes the steps overshoot the valley and can diverge; too small makes progress painfully slow.

Try it with me. Data \((0, 1)\), \((1, 3)\); start \(\beta = (0, 0)\); \(\eta = 0.1\); loss = RSS.

At the start every \(\hat y_i = 0\). Give \(\sum r_i\) and \(\sum r_ix_i\).

\(r = (1, 3)\), so \(\sum r_i = 4\). \(\sum r_ix_i = 1\times0 + 3\times1 = 3\).

Now the gradient and the updated \(\beta\).

\(\nabla = (-2\times4, -2\times3) = (-8, -6)\). \(\beta = (0, 0) - 0.1\times(-8, -6) = (0.8, 0.6)\).

4. Convex or not, and restarts

In plain words

A convex loss is one bowl: gradient descent with a small enough step reaches the same bottom from anywhere. A non-convex loss has several dips, so where you finish depends on where you start. The cure is to start several times and keep the best.

Loss Shape Consequence
RSS of linear, polynomial, ridge regression (w2) convex one answer; matches the formula
NLL of logistic regression (w3) convex one answer, but no formula: use GD
Neural network loss (w4) non-convex random starts can end in different places
K-means \(J_{SSE}\) (w7) non-convex (over assignments) stops at a local minimum: use several random starts

Why does the week 2 lab run gradient descent for linear regression from 10 random starting points, and what should you see?

Different answers would mean the step size or the number of iterations is wrong. For a neural network, different starts genuinely can end in different places.

5. The gradient that keeps coming back

For one training point, three models, one pattern:

Model and loss Gradient in \(\beta\)
linear model, squared error \(-2(y - \hat y)\,\tilde x = 2(\hat y - y)\,\tilde x\)
logistic regression, cross-entropy (Toolkit 9) \((p - y)\,\tilde x\)
softmax output, cross-entropy, per class score (w4) \(p_m - y_m\)

Each time: (prediction − truth) × input. Badly predicted points push hard, in the direction of their own input; well-predicted points barely move anything. Backpropagation (w4) passes this backwards through the layers with the chain rule.

Squared-error loss \((y - \beta_0 - \beta_1x)^2\) on one point \(x = 1\), \(y = 2\), starting at \(\beta = (0, 0)\), \(\eta = 0.025\). Using \(\nabla = -2(y - \hat y)\tilde x\), give \(\beta\) after one step.

\(\hat y = 0\); \(\nabla = -2\times2\times(1, 1) = (-4, -4)\). \(\beta = (0, 0) - 0.025\times(-4, -4) = (0.1, 0.1)\).

Stage test

What is the derivative of \(\text{ReLU}(z) = \max(0, z)\) at \(z = -2\)?

Flat at 0 for \(z < 0\): slope \(0\).

Which models are fitted by gradient descent in the course because no closed-form solution exists?

Linear and ridge regression have closed forms; KNN has nothing to fit.

(3 marks; 2023 Q3.) Show that the sigmoid \(\sigma(z) = \frac{1}{1 + e^{-z}}\) satisfies \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\).

Write \(\sigma(z) = (1 + e^{-z})^{-1}\). By the chain rule \(\sigma'(z) = -(1 + e^{-z})^{-2}\cdot(-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2} = \frac{1}{1 + e^{-z}}\cdot\frac{e^{-z}}{1 + e^{-z}}\). Since \(\frac{e^{-z}}{1 + e^{-z}} = \frac{(1 + e^{-z}) - 1}{1 + e^{-z}} = 1 - \sigma(z)\), we get \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\).
