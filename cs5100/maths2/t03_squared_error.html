Squared error: MSE, RSS, SSE and friends

Take each error, square it, add them up. The course gives this sum at least seven names (RSS, MSE, TSS, SSE, RSS(T), the NN loss, the bias-variance decomposition), but it is one recipe: find the gap, square the gap, add. This stage works through it in every form you'll meet, including the K-means SSE about a centroid, line by line.

By the end of this stage you can

  • compute RSS and MSE from a residual table, without the classic “square of the sum” slip;
  • say exactly what is being subtracted from what in RSS, TSS, the leaf RSS and the K-means SSE;
  • prove that the mean is the single number that minimises squared error, and use it;
  • compute the SSE of a cluster about its centroid, with gaps before squares;
  • compute RSS, TSS and \(R^2\) for a fitted line;
  • split an expected test error into bias², variance and noise.

Book and slides

ISLP 2.2.1 (MSE), 3.1.1 to 3.1.3 (RSS, TSS, \(R^2\), RSE), 2.2.2 (bias-variance, eq. 2.7), 12.4.1 (K-means objective). Skip in 3.1.2 the standard errors, confidence intervals, t-statistics and p-values: the course doesn’t test them. The week 5 slides (I. Rungger) give the decomposition in the course’s notation; week 7 slide 15 defines \(J_{SSE} = \sum_{j=1}^K\sum_{x\in\omega_j}\|x - \mu_j\|^2\) with \(\mu_j = \frac{1}{|\omega_j|}\sum_{x\in\omega_j}x\).

1. One recipe: gap, square, add

In plain words

Every version of squared error has the same three moves:

  1. Gap. For each data point, subtract “what we predicted” (or “the centre”) from “what we saw”.
  2. Square each gap, so overshoots and undershoots both count as positive and big misses count a lot.
  3. Add the squares. Divide by \(n\) if you want an average (MSE).

The only thing that changes between names is what you subtract.

\[\boxed{\text{RSS} = \sum_{i=1}^{n}(y_i - \hat y_i)^2,\qquad \text{MSE} = \frac1n\,\text{RSS}}\]

Name The gap is… Where
RSS, MSE \(y_i - \hat y_i\) (truth − prediction) linear regression (w2), test error everywhere
TSS \(y_i - \bar y\) (truth − overall mean) \(R^2\) (w2)
leaf RSS, \(\text{RSS}(T)\) \(y_i - \bar y_{\text{leaf}}\) regression trees (w4)
\(J_{SSE}\) \(x - \mu_j\), a vector gap to the cluster’s centroid K-means (w7)
bias-variance \(\hat f(x_0) - Y\), averaged over training sets week 5
Symbol Meaning
\(y_i\) the observed response of point \(i\)
\(\hat y_i\) the model’s prediction for point \(i\)
\(e_i = y_i - \hat y_i\) the residual (error) of point \(i\)
\(n\) number of points

Worked example 1. Truth \(y = (3, 7, 4, 10)\), predictions \(\hat y = (4, 5, 4, 7)\).

\(i\) \(y_i\) \(\hat y_i\) \(e_i = y_i - \hat y_i\) \(e_i^2\)
1 3 4 −1 1
2 7 5 2 4
3 4 4 0 0
4 10 7 3 9
total 4 14

RSS \(= 14\), MSE \(= 14/4 = 3.5\).

Common mistakes

  • Square of the sum. \((\sum e_i)^2 = 4^2 = 16\) is not the RSS. Square each row then add.
  • Sum of the gaps. \(\sum e_i = 4\) tells you about bias, not size of error: errors of \(+5\) and \(-5\) would add to 0.
  • MSE vs RSS. MSE divides by \(n\); RSS doesn’t. Read which one the question asks for.
  • \((-1)^2 = 1\), never \(-1\). Every entry in the \(e_i^2\) column must be \(\ge 0\).

Truth \(y = (1, 6, 8)\), predictions \(\hat y = (3, 5, 5)\). Give the three residuals \(e_i = y_i - \hat y_i\), then the RSS and the MSE.

\(e = (-2, 1, 3)\). Squares \(4, 1, 9\), RSS \(= 14\), MSE \(= 14/3 = 4.667\).

2. Why squares, and why the mean wins

In plain words

Squaring makes every error positive, punishes big misses heavily, and gives a smooth curve you can differentiate. It also has a neat consequence: if you must predict one number for a whole group, the number that makes the squared error smallest is the group’s mean. That one fact explains why tree leaves predict means, why K-means moves centres to means, and why \(R^2\) compares against \(\bar y\).

Fact. For numbers \(y_1, \dots, y_n\), the constant \(c\) that minimises \(g(c) = \sum_i(y_i - c)^2\) is \(c = \bar y\).

Proof, step by step.

  1. Differentiate each term with the chain rule: \(\frac{d}{dc}(y_i - c)^2 = 2(y_i - c)\times(-1) = -2(y_i - c)\).
  2. Add: \(g'(c) = -2\sum_i(y_i - c) = -2\big(\sum_iy_i - nc\big)\).
  3. Set to zero: \(\sum_iy_i = nc\), so \(c = \frac1n\sum_iy_i = \bar y\).
  4. Second derivative \(g''(c) = 2n > 0\), so it’s a minimum, not a maximum.

Worked example 2. Leaf responses \(2, 4, 9\), mean \(5\).

\(y_i\) gap to mean 5 squared gap to median 4 squared
2 −3 9 −2 4
4 −1 1 0 0
9 4 16 5 25
total 0 26 3 29

The mean gives 26, the median 29. No other number beats 26. Notice the gaps to the mean add to 0: that’s the mean’s defining property.

A tree leaf contains \(y = 1, 3, 4, 8\). Which single prediction minimises the leaf’s RSS, and what is that smallest RSS?

The mean \((1 + 3 + 4 + 8)/4 = 4\). Gaps \(-3, -1, 0, 4\); squares \(9, 1, 0, 16\); RSS \(= 26\).

3. The SSE of a cluster: gaps to the centroid

In plain words

K-means measures how tight a cluster is by the sum of squared distances from each point to the cluster’s centre (its centroid). It’s the same recipe, with vector gaps: subtract the centroid from the point in every coordinate, square each coordinate gap, add across coordinates, then add across points.

\[\boxed{\text{SSE}(\omega) = \sum_{x\in\omega}\|x - \mu\|^2 = \sum_{x\in\omega}\big[(x_1 - \mu_1)^2 + (x_2 - \mu_2)^2 + \dots\big],\qquad J_{SSE} = \sum_{j=1}^K\text{SSE}(\omega_j)}\]

Symbol Meaning
\(\omega\) or \(\omega_j\) a cluster: a set of points
\(\mu = (\mu_1, \mu_2, \dots)\) its centroid, the coordinate-wise mean
\(\|x - \mu\|^2\) squared Euclidean distance from point \(x\) to \(\mu\) (Toolkit 1)
\(J_{SSE}\) the K-means objective: add the SSE of every cluster

Worked example 3: the full layout. Cluster \(\{(1, 2), (3, 6), (5, 4)\}\).

Step 1: centroid. \(\mu_1 = (1 + 3 + 5)/3 = 3\), \(\mu_2 = (2 + 6 + 4)/3 = 4\). So \(\mu = (3, 4)\).

Step 2: gaps, squares, sums.

point \(x_1 - \mu_1\) \(x_2 - \mu_2\) \((x_1 - \mu_1)^2\) \((x_2 - \mu_2)^2\) \(\|x - \mu\|^2\)
(1, 2) 1 − 3 = −2 2 − 4 = −2 4 4 8
(3, 6) 3 − 3 = 0 6 − 4 = 2 0 4 4
(5, 4) 5 − 3 = 2 4 − 4 = 0 4 0 4
total 0 0 16

SSE \(= 16\). The two gap columns each add to 0: a built-in check that the centroid is right.

The slip to avoid. Squaring the raw coordinates gives \((1 + 4) + (9 + 36) + (25 + 16) = 91\). That number measures distance from the origin \((0, 0)\), not spread around the centre, so it’s meaningless for K-means. If your table has no subtraction column, stop and add one.

Worked example 4: decimals in the centroid. Cluster \(\{(0, 1), (2, 1), (2, 4), (4, 2)\}\). Centroid \(\mu = (8/4, 8/4) = (2, 2)\).

point gap 1 gap 2 squares \(\|x - \mu\|^2\)
(0, 1) −2 −1 4 + 1 5
(2, 1) 0 −1 0 + 1 1
(2, 4) 0 2 0 + 4 4
(4, 2) 2 0 4 + 0 4
total 0 0 14

Now the same cluster plus the point \((1, 2)\): centroid \(\mu = (9/5, 10/5) = (1.8, 2)\). Gaps in the first coordinate become \(-1.8, 0.2, 0.2, 2.2, -0.8\) (they add to 0 ✓). Squares \(3.24, 0.04, 0.04, 4.84, 0.64\), sum \(8.8\). Second coordinate gaps \(-1, -1, 2, 0, 0\), squares sum \(6\). SSE \(= 8.8 + 6 = 14.8\). You may add the columns separately like this: the SSE is the sum over coordinates of each coordinate’s own sum of squares.

Common mistakes in the SSE

  • Squaring raw coordinates instead of the gaps to the centroid (see above). This is the most common K-means slip.
  • Using the wrong centre. After a K-means update, the SSE uses the new centres. Before the update, it uses the old ones. Read which one the question wants.
  • Taking a square root. \(J_{SSE}\) uses \(\|x - \mu\|^2\), the squared distance. No roots anywhere.
  • Forgetting a coordinate. In 2D every point contributes two squared gaps.
  • Rounding the centroid early. Keep \(\mu = 1.8\), not \(2\). Rounding first changes the SSE.

Try it with me. Cluster \(\{(2, 0), (4, 6), (6, 3)\}\).

Step 1: give the centroid.

\((2 + 4 + 6)/3 = 4\) and \((0 + 6 + 3)/3 = 3\).

Step 2: for the first point \((2, 0)\), give both gaps to the centroid and its squared distance.

\(2 - 4 = -2\), \(0 - 3 = -3\); squares \(4 + 9 = 13\).

Step 3: give the other two squared distances, then the SSE.

\((4, 6)\): gaps \((0, 3)\), so \(0 + 9 = 9\). \((6, 3)\): gaps \((2, 0)\), so \(4 + 0 = 4\). SSE \(= 13 + 9 + 4 = 26\).

4. RSS, TSS and \(R^2\)

In plain words

TSS is the RSS of the laziest possible model: “always predict the average \(\bar y\)”. RSS is the error left over after your model. \(R^2\) asks what fraction of the lazy model’s error your model removed.

\[\text{TSS} = \sum_i(y_i - \bar y)^2,\qquad R^2 = 1 - \frac{\text{RSS}}{\text{TSS}}\]

\(R^2 = 0\): no better than predicting \(\bar y\). \(R^2 = 1\): a perfect fit on these points.

Worked example 5. Data \(x = (1, 2, 3, 4)\), \(y = (2, 3, 5, 6)\), fitted line \(\hat y = 0.5 + 1.4x\). \(\bar y = 16/4 = 4\).

\(x_i\) \(y_i\) \(\hat y_i\) \(y_i - \hat y_i\) squared \(y_i - \bar y\) squared
1 2 1.9 0.1 0.01 −2 4
2 3 3.3 −0.3 0.09 −1 1
3 5 4.7 0.3 0.09 1 1
4 6 6.1 −0.1 0.01 2 4
total 0 0.2 0 10

\(R^2 = 1 - 0.2/10 = 0.98\). The line explains 98% of the spread in \(y\).

Common mistakes

  • Putting \(\hat y\) into the TSS. The TSS never involves the model.
  • \(R^2\) on the test set can be negative if the model is worse than the training mean. On the training data with least squares it lies between 0 and 1.

5. The bias-variance decomposition

In plain words

Imagine retraining the same kind of model on many different training sets and predicting at one input \(x_0\) each time. The expected squared test error splits into three parts: how far the average prediction is from the truth (bias²), how much the predictions wobble between training sets (variance), and the noise in \(Y\) that nobody can predict.

\[\mathbb E\big(\hat f(x_0) - Y\big)^2 = \underbrace{\big(\mathbb E\hat f(x_0) - f(x_0)\big)^2}_{\text{bias}^2} + \underbrace{\mathbb E\big(\hat f(x_0) - \mathbb E\hat f(x_0)\big)^2}_{\text{variance}} + \underbrace{\sigma^2}_{\text{noise}}\]

Worked example 6. Predictions at \(x_0\) from four training sets: \(4, 6, 5, 5\). True \(f(x_0) = 6\), noise \(\sigma^2 = 1\).

set \(\hat f(x_0)\) \(\hat f - \bar f\) squared
1 4 −1 1
2 6 1 1
3 5 0 0
4 5 0 0
average \(\bar f = 5\) 0 0.5

Bias² \(= (5 - 6)^2 = 1\). Variance \(= 0.5\). Expected test MSE \(= 1 + 0.5 + 1 = 2.5\).

Common mistakes

  • Variance measured from the truth. The variance column subtracts the average prediction \(\bar f\), not \(f(x_0)\).
  • Forgetting to square the bias. The term is \((\bar f - f(x_0))^2\).
  • Dropping the noise. Even a perfect model pays \(\sigma^2\).

Stage test

Which single number \(c\) minimises \((1 - c)^2 + (2 - c)^2 + (3 - c)^2\)?

The mean of \(1, 2, 3\): \(c = 2\).

(3 marks; 2024 Q1.) Write the formula for the RSS of a linear regression model \(f(X) = \lambda_0 + \lambda_1X\) on data \(\{(x_i, y_i)\}_{i=1}^n\), and say what is done with it.

\(\text{RSS}(\lambda_0, \lambda_1) = \sum_{i=1}^{n}\big(y_i - (\lambda_0 + \lambda_1x_i)\big)^2\): the sum, over training points, of the squared differences between the observed \(y_i\) and the prediction. Least squares picks the \(\lambda\) that minimises it, either in closed form (both partial derivatives set to zero) or by gradient descent. It measures training fit only; a flexible model can make it small while the test error is large.
