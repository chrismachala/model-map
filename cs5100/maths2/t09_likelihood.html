Likelihood and cross-entropy

How do you fit a model that outputs probabilities? Ask: under which parameters would the labels we actually saw have been most probable? That's maximum likelihood. Take minus the log and it becomes a loss to minimise, the cross-entropy, used for logistic regression and every neural-network classifier. Its gradient is the "(prediction − truth) × input" pattern again. This stage does each of those by table.

By the end of this stage you can

  • compute the likelihood of a set of labels under a model, and compare two models with it;
  • turn it into the negative log-likelihood (cross-entropy) and compute it by table, picking the right probability for each label;
  • write the binary and multi-class forms and say why they agree;
  • compute the logistic-regression gradient \(\sum_i(p_i - y_i)\tilde x_i\) and do one gradient-descent step;
  • explain why a tree’s entropy impurity is a cross-entropy.

1. Likelihood

In plain words

A probabilistic model gives every point a probability for each label. The likelihood of the model is the probability it gave to what actually happened, all points together. Points are independent, so multiply. A good model gave the true labels high probability; a bad one was “surprised”.

\[\boxed{\ell(\beta) = \prod_{i=1}^{n}P_\beta(Y = y_i\mid x_i)}\]

For two classes with \(p_i = P(Y = 1\mid x_i)\), the probability of the true label is \(p_i\) if \(y_i = 1\) and \(1 - p_i\) if \(y_i = 0\). Compactly: \(p_i^{y_i}(1 - p_i)^{1 - y_i}\).

Worked example 1. Labels \(y = (1, 0, 1)\). Two candidate models:

\(i\) \(y_i\) model A \(p_i\) prob. of truth model B \(p_i\) prob. of truth
1 1 0.9 0.9 0.6 0.6
2 0 0.2 1 − 0.2 = 0.8 0.5 0.5
3 1 0.8 0.8 0.5 0.5
product 0.576 0.15

Model A explains the data almost four times better. Maximum likelihood picks the parameters with the biggest product.

Common mistakes

  • Using \(p_i\) for every point. For a point with \(y_i = 0\) the probability of the truth is \(1 - p_i\).
  • Adding instead of multiplying the probabilities (that’s for the log version, next).

2. Negative log-likelihood = cross-entropy

In plain words

Products of many small numbers are awkward, so take logs: the product becomes a sum. Logs of probabilities are negative, so put a minus sign in front: now it’s a positive loss to minimise. Each point costs \(-\log(\text{probability given to the truth})\): nearly 0 for a confident right answer, huge for a confident wrong one.

\[\boxed{L(\beta) = -\log\ell(\beta) = -\sum_{i=1}^{n}\Big[y_i\log p_i + (1 - y_i)\log(1 - p_i)\Big] = -\sum_{i=1}^n\log p_{y_i}(x_i)}\]

Probability given to the truth 0.99 0.9 0.7 0.5 0.1 0.01
cost \(-\log\) (natural log) 0.010 0.105 0.357 0.693 2.303 4.605

With many classes and one-hot labels \(y_{ik}\), the same loss is \(L = -\sum_i\sum_ky_{ik}\log p_k(x_i)\): only the true class’s term survives in each inner sum.

Worked example 2. Same data as example 1.

\(i\) prob. of truth (A) \(-\log\) prob. of truth (B) \(-\log\)
1 0.9 0.1054 0.6 0.5108
2 0.8 0.2231 0.5 0.6931
3 0.8 0.2231 0.5 0.6931
total 0.5516 1.8971

Check: \(-\log0.576 = 0.5516\) ✓. Lower NLL = higher likelihood = better.

Common mistakes

  • Picking the wrong probability for \(y_i = 0\) points (as above).
  • Forgetting the minus. \(\log\) of a probability is negative; the loss must come out positive.
  • Mixing log bases. Use natural log unless the question says \(\log_2\); say which you used.

Try it with me. Labels \(y = (1, 1, 0)\); the model gives \(p = (0.7, 0.4, 0.2)\).

For each point, what probability did the model give to the true label?

\(y_1 = 1\): \(0.7\). \(y_2 = 1\): \(0.4\). \(y_3 = 0\): \(1 - 0.2 = 0.8\).

Now the three costs \(-\log(\cdot)\) and the total NLL.

\(-\log0.7 = 0.3567\), \(-\log0.4 = 0.9163\), \(-\log0.8 = 0.2231\). Total \(1.4961\). The worst-predicted point (2) contributes most.

3. The gradient: (prediction − truth) × input

In plain words

To fit logistic regression by gradient descent we need the slope of \(L\). The chain rule (Toolkit 4) through \(\log\), then \(\sigma\), then the linear score gives a beautifully simple answer: each point contributes its error \(p_i - y_i\) times its input.

Derivation for one point (\(y = 1\) case; the \(y = 0\) case is similar):

Step Working
loss \(-\log\sigma(z)\) with \(z = \beta\cdot\tilde x\)
outer derivative \(\frac{d}{dz}[-\log\sigma(z)] = -\frac{\sigma'(z)}{\sigma(z)} = -\frac{\sigma(1 - \sigma)}{\sigma} = -(1 - \sigma) = \sigma - 1 = p - y\)
inner derivative \(\partial z/\partial\beta = \tilde x\)
together \((p - y)\,\tilde x\)

\[\boxed{\nabla L(\beta) = \sum_{i=1}^{n}(p_i - y_i)\,\tilde x_i},\qquad \beta \leftarrow \beta - \eta\nabla L(\beta)\]

Worked example 3: one step. \(x = (-1, 0, 1, 2)\), \(y = (0, 0, 1, 1)\), start \(\beta = (0, 0)\), \(\eta = 0.1\).

\(x_i\) \(y_i\) \(z_i\) \(p_i\) \(p_i - y_i\) \((p_i - y_i)x_i\)
−1 0 0 0.5 0.5 −0.5
0 0 0 0.5 0.5 0
1 1 0 0.5 −0.5 −0.5
2 1 0 0.5 −0.5 −1
total 0 −2

Gradient \((0, -2)\). Step: \(\beta = (0, 0) - 0.1\times(0, -2) = (0, 0.2)\). The loss falls from \(4\log2 = 2.773\) to \(2.402\). The slope went up because the class-1 points are on the right.

Common mistakes

  • \(y - p\) with a minus step. If you write the gradient as \(\sum(y_i - p_i)\tilde x_i\) you are using the gradient of the log-likelihood, which you add (ascent). Pick one convention and keep the signs consistent.
  • Forgetting the column of 1s. \(\partial L/\partial\beta_0 = \sum(p_i - y_i)\), the plain sum of the errors.
  • Using the old \(p\) after updating \(\beta\). Recompute \(p_i\) at the new \(\beta\) before the next step.

At \(\beta = (0, 0)\) (so every \(p_i = 0.5\)), data \(x = (1, 2, 3)\), \(y = (1, 0, 1)\). Give the gradient components, and the new \(\beta_1\) after one step with \(\eta = 0.1\).

\(p - y = (-0.5, 0.5, -0.5)\). \(\partial_{\beta_0} = -0.5 + 0.5 - 0.5 = -0.5\). \(\partial_{\beta_1} = (-0.5)(1) + (0.5)(2) + (-0.5)(3) = -0.5 + 1 - 1.5 = -1\). New \(\beta_1 = 0 - 0.1\times(-1) = 0.1\).

4. Entropy is a cross-entropy

In plain words

A classification-tree leaf predicts its own class proportions \(\hat p_k\) for every point in it. Its average cross-entropy per point is then \(-\sum_k\hat p_k\log\hat p_k\): a fraction \(\hat p_k\) of the points are class \(k\), each costing \(-\log\hat p_k\). That’s the entropy impurity of Toolkit 10. Splitting to reduce entropy is training to reduce cross-entropy.

Worked example 4. A leaf with 3 A and 1 B predicts \((0.75, 0.25)\). The three A points each cost \(-\log0.75 = 0.2877\); the B point costs \(-\log0.25 = 1.3863\). Average \(\frac{3\times0.2877 + 1.3863}{4} = 0.5623\). Entropy formula: \(-(0.75\log0.75 + 0.25\log0.25) = 0.2158 + 0.3466 = 0.5623\) ✓.

A leaf holds 5 A and 5 B. What is its entropy (natural log)?

\(-(0.5\log0.5 + 0.5\log0.5) = \log2 = 0.6931\), the maximum for two classes.

Stage test

(4 marks; 2023 Q3 and 2025 Q2.) Write an objective function for training a classifier that outputs class probabilities \(p_k(x)\), and explain where it comes from.

For training data \(\{(x_i, y_i)\}\), the likelihood is \(\ell = \prod_ip_{y_i}(x_i)\), the probability the model gives to the observed labels (assuming independent points). Maximum likelihood chooses the parameters that maximise it; equivalently we minimise the cross-entropy \(L = -\log\ell = -\sum_i\log p_{y_i}(x_i)\), which for two classes is \(-\sum_i[y_i\log p_i + (1 - y_i)\log(1 - p_i)]\). Each point costs \(-\log\) of the probability given to its true class, so confident mistakes cost a lot. There is no closed form, so it is minimised by gradient descent.

A classifier gives the true class of a point probability 0.1. What does that point contribute to the cross-entropy (natural log)?

\(-\log0.1 = 2.303\).
