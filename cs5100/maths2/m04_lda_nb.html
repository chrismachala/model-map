LDA and naive Bayes

Logistic regression models P(Y | X) directly. LDA and naive Bayes take the other road: describe what each class looks like, f_k(x), then flip it with Bayes' rule. LDA uses bell curves with a shared spread; naive Bayes assumes the inputs are independent within each class. This stage runs both from raw data to a posterior probability.

Built from

A6 Bayes’ rule and priors · A7 Gaussian class densities, and their log · A2 class means and proportions as estimates · A3 the pooled variance (squared gaps to each class mean) · A8 the posterior is a softmax of the discriminants. Full pages: LDA, naive Bayes.

1. LDA from data, start to finish

\[\underbrace{P(Y = k\mid x) = \frac{\pi_kf_k(x)}{\sum_l\pi_lf_l(x)}}_{\text{A6}} = \underbrace{\frac{e^{\delta_k(x)}}{\sum_le^{\delta_l(x)}}}_{\text{A8 softmax}},\qquad \underbrace{\delta_k(x) = \frac{x\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log\pi_k}_{\text{A7: log of a Gaussian, }x^2\text{ cancelled}}\]

Four steps: (1) priors \(\hat\pi_k = n_k/n\); (2) class means \(\hat\mu_k\); (3) pooled variance \(\hat\sigma^2 = \frac{1}{n - K}\sum_k\sum_{i\in k}(x_i - \hat\mu_k)^2\); (4) discriminants, then the largest wins (or softmax them for probabilities).

Worked example 1: unequal class sizes. Class 0: \(x = (2, 4, 6)\). Class 1: \(x = (8, 10)\).

Steps 1 to 3.

class \(x_i\) \(\hat\mu_k\) \(x_i - \hat\mu_k\) squared
0 2 4 −2 4
0 4 4 0 0
0 6 4 2 4
1 8 9 −1 1
1 10 9 1 1
total 10

\(\hat\pi_0 = 3/5 = 0.6\), \(\hat\pi_1 = 0.4\), \(\hat\sigma^2 = 10/(5 - 2) = 3.333\).

Step 4: boundary. \(x^* = \frac{4 + 9}{2} + \frac{3.333}{9 - 4}\log\frac{0.6}{0.4} = 6.5 + 0.667\times0.405 = 6.770\). The more common class 0 pushes the boundary towards class 1.

6.6 5.009 4.754 0 0.436

(For example, \(\delta_0(6.6) = \frac{6.6\times4}{3.333} - \frac{16}{6.667} + \log0.6 = 7.92 - 2.4 - 0.511 = 5.009\).) Both agree with the boundary at 6.77.

Common mistakes

  • Variance from the overall mean (slide (31)): that adds the between-class gap and inflates \(\sigma^2\).
  • \(n\) instead of \(n - K\). Five points, two classes: divide by 3.
  • Equal priors by habit. Use \(n_k/n\) unless told otherwise; here it moved the boundary by 0.27.
  • Boundary shift direction. It moves towards the rarer class’s mean.

Try it with me. Class 0: \(x = (1, 3)\). Class 1: \(x = (6, 8, 10)\).

Give the means, the total of squared within-class gaps, the pooled variance and the two priors.

\(\hat\mu_0 = 2\), \(\hat\mu_1 = 8\). Gaps \((-1, 1)\) and \((-2, 0, 2)\): squares \(1 + 1 + 4 + 0 + 4 = 10\). \(\hat\sigma^2 = 10/(5 - 2) = 3.333\). \(\hat\pi_0 = 0.4\), \(\hat\pi_1 = 0.6\).

Now the decision boundary \(x^* = \frac{\mu_0 + \mu_1}{2} + \frac{\sigma^2}{\mu_1 - \mu_0}\log\frac{\pi_0}{\pi_1}\).

\(5 + \frac{3.333}{6}\log\frac{0.4}{0.6} = 5 + 0.5556\times(-0.4055) = 5 - 0.2253 = 4.775\). (Class 1 is the common one now, so the boundary moves towards class 0.)

2. Naive Bayes with Gaussian inputs

In plain words

With several inputs, naive Bayes gives each class a separate one-dimensional density per input and multiplies them (Toolkit 6). With Gaussian per-input densities, it’s “LDA without correlations”, one input at a time.

\[f_k(x) = \prod_{j=1}^pf_{kj}(x_j),\qquad P(Y = k\mid x) = \frac{\pi_k\prod_jf_{kj}(x_j)}{\sum_l\pi_l\prod_jf_{lj}(x_j)}\]

Worked example 2. Two inputs, equal priors. Class A: each input \(\sim N(0, 1)\). Class B: \(x_1\sim N(2, 1)\), \(x_2\sim N(1, 1)\). Classify \(x = (1, 1)\). Use \(\varphi(z) = \frac{1}{\sqrt{2\pi}}e^{-z^2/2}\): \(\varphi(0) = 0.3989\), \(\varphi(\pm1) = 0.2420\).

class gap in \(x_1\) gap in \(x_2\) \(f_{k1}\) \(f_{k2}\) \(\pi_kf_{k1}f_{k2}\)
A 1 1 0.2420 0.2420 0.5 × 0.05855 = 0.02927
B −1 0 0.2420 0.3989 0.5 × 0.09653 = 0.04827
total 0.07754

\(P(B\mid x) = 0.04827/0.07754 = 0.622\). Predict B.

3. LDA vs logistic regression vs naive Bayes

logistic regression LDA naive Bayes
models \(P(Y\mid x)\) directly \(f_k(x)\) Gaussian, shared \(\sigma^2\) \(f_k(x)\) as a product over inputs
boundary linear linear depends on \(f_{kj}\) (linear with shared-variance Gaussians)
fitted by gradient descent on cross-entropy closed-form means, variance, priors counting or per-input means/variances
shines when Gaussian assumption is wrong classes really are Gaussian; small \(n\); classes well separated many inputs, small \(n\)
