Vectors, dot products and distances

Two operations on lists of numbers do a huge amount of work in this course. The dot product builds the "score" inside every linear model and every neuron. The distance decides who your neighbours are in KNN, K-means and hierarchical clustering. This stage does both slowly, with every multiplication and every square shown.

By the end of this stage you can

  • write a data point as a vector and add the leading 1 that carries the intercept;
  • compute a dot product and a linear score \(z = \beta\cdot\tilde x\) without dropping the intercept;
  • compute the Euclidean, squared Euclidean, Manhattan and maximum distances between two points, by table;
  • compute the squared distance from a point to a centre (the building block of the K-means SSE) by subtracting before squaring;
  • explain why columns must be rescaled before using distances.

Book and slides

Week 1 slides, “Linear algebra and calculus basics” (vectors, dot product, orthogonality, norms); week 7 slides, “Definition of metric” and the Minkowski distances. ISLP has no chapter for this, it assumes it. Read ISLP 2.2.3 for the Euclidean distance in KNN and 12.4.1 for distances in K-means. Skip the matrix-algebra details of ISLP 3.2 for now; the multiple regression stage uses only \(\mathbf X\beta\).

1. Vectors and the dot product

In plain words

A vector is just an ordered list of numbers. One customer with age 30, income 25 and 2 children is the vector \((30, 25, 2)\). Order matters: the first slot always means age.

The dot product of two lists of the same length pairs them up slot by slot, multiplies each pair, and adds the results. It’s the maths of “weighted total”: price list · shopping quantities = the bill.

\[\boxed{a\cdot b = a^Tb = a_1b_1 + a_2b_2 + \dots + a_pb_p = \sum_{j=1}^{p}a_jb_j}\]

Symbol Meaning
\(a = (a_1, \dots, a_p)\) a vector with \(p\) entries; \(a_j\) is entry number \(j\)
\(a^Tb\) the same thing as \(a\cdot b\), written as a row times a column
\(\|a\|_2 = \sqrt{a\cdot a}\) the length of \(a\)
orthogonal at right angles: exactly when \(a\cdot b = 0\)

Worked example 1. \(a = (2, -1, 3)\), \(b = (4, 5, -2)\).

slot \(j\) \(a_j\) \(b_j\) \(a_jb_j\)
1 2 4 8
2 −1 5 −5
3 3 −2 −6
total −3

So \(a\cdot b = -3\). It isn’t 0, so they’re not orthogonal. Length of \(a\): \(\|a\|_2 = \sqrt{2^2 + (-1)^2 + 3^2} = \sqrt{4 + 1 + 9} = \sqrt{14} \approx 3.742\).

Worked example 2 (2023 Q1(c)). \((1, 2, -3)\cdot(5, -4, -1) = 1\times5 + 2\times(-4) + (-3)\times(-1) = 5 - 8 + 3 = 0\). Orthogonal.

Common mistakes

  • Sign slips with negatives. \((-3)\times(-1) = +3\). Write each product in its own row so the signs stay visible.
  • Multiplying the totals. \(a\cdot b\) is not \((\sum a_j)(\sum b_j)\). In example 1 that would give \(4\times7 = 28\), nowhere near \(-3\).
  • Lengths of different sizes. The dot product only exists for two vectors with the same number of entries.

Try it with me. \(u = (3, -2, 1)\), \(v = (1, 4, 5)\). Fill in one product at a time.

Give the three products \(u_1v_1\), \(u_2v_2\), \(u_3v_3\).

\(3\times1 = 3\), \((-2)\times4 = -8\), \(1\times5 = 5\).

Now add them. What is \(u\cdot v\), and so are \(u\) and \(v\) orthogonal?

\(3 - 8 + 5 = 0\), so yes, they’re orthogonal.

2. The score inside every model

In plain words

Almost every model in the course starts by computing one number from the inputs: a weighted total of the inputs plus a starting value. The weights are the coefficients \(\beta_1, \dots, \beta_p\); the starting value is the intercept \(\beta_0\). To write that as one dot product, we put a 1 at the front of the input so it can pair with \(\beta_0\).

\[\boxed{z = \beta\cdot\tilde x = \beta_0\cdot1 + \beta_1x_1 + \dots + \beta_px_p,\qquad \tilde x = (1, x_1, \dots, x_p)}\]

Model What happens to the score \(z\)
Linear regression (w2) nothing: \(\hat y = z\)
Polynomial / step regression (w2) same, with new columns like \(x^2\) or \(\mathbb 1(x < c)\) in \(\tilde x\)
Logistic regression (w3) squashed: \(p = \sigma(z)\)
Multinomial logistic, NN classifier (w3, w4) one score per class, then softmax
LDA (w3) each class score \(\delta_k(x)\) is linear in \(x\)
Neuron (w4) bent: \(A_k = g(w_k\cdot\tilde x)\), \(g\) = ReLU or sigmoid

Worked example 3. \(\beta = (0.5, 2, -1, 3)\), input \(x = (4, 1, -2)\), so \(\tilde x = (1, 4, 1, -2)\).

\(j\) \(\beta_j\) \(\tilde x_j\) \(\beta_j\tilde x_j\)
0 0.5 1 0.5
1 2 4 8
2 −1 1 −1
3 3 −2 −6
total 1.5

\(z = 1.5\). In linear regression that is the prediction. In logistic regression it would go into \(\sigma(1.5) = 0.818\).

Common mistakes

  • Forgetting the 1. Without it you’d compute \(8 - 1 - 6 = 1\) and lose \(\beta_0 = 0.5\).
  • Pairing \(\beta_1\) with \(x_2\). After you add the 1, the indices shift: \(\tilde x_1 = x_1\), but it is the second entry of \(\tilde x\). Number the table rows from 0.

\(\beta = (0.5, 2, -1)\) and \(x = (3, 1)\). Compute \(z = \beta\cdot\tilde x\).

\(\tilde x = (1, 3, 1)\). Products: \(0.5\), \(6\), \(-1\). Total \(5.5\).

3. Distances between points

In plain words

A distance answers “how different are these two data points?”. Go slot by slot, take the gap in each slot, then combine the gaps. Different ways of combining give different distances: add the gaps up (Manhattan, like walking a city grid), or square, add and square-root (Euclidean, a straight ruler line).

\[\boxed{\|x - y\|_k = \Big(\sum_{i=1}^{p}\lvert x_i - y_i\rvert^k\Big)^{1/k}}\]

Name \(k\) Formula Used in
Manhattan 1 \(\sum_i\lvert x_i - y_i\rvert\) w7 examples
Euclidean 2 \(\sqrt{\sum_i(x_i - y_i)^2}\) KNN (w1), K-means and linkage (w7)
squared Euclidean (2, no root) \(\sum_i(x_i - y_i)^2\) the K-means SSE (w7), the ridge penalty
maximum \(\infty\) \(\max_i\lvert x_i - y_i\rvert\) w7 examples

A distance must satisfy four rules (week 7 slides): \(d \ge 0\); \(d(x, y) = 0\) only when \(x = y\); \(d(x, y) = d(y, x)\); and the triangle inequality \(d(x, z) \le d(x, y) + d(y, z)\).

Worked example 4. \(x = (1, 5, -2)\), \(y = (4, 1, 0)\).

slot \(x_i\) \(y_i\) gap \(x_i - y_i\) \(\lvert\text{gap}\rvert\) \(\text{gap}^2\)
1 1 4 −3 3 9
2 5 1 4 4 16
3 −2 0 −2 2 4
total 9 29
  • Manhattan \(L_1 = 9\).
  • Squared Euclidean \(= 29\); Euclidean \(L_2 = \sqrt{29} \approx 5.385\).
  • Maximum \(L_\infty = 4\) (the biggest \(\lvert\text{gap}\rvert\)).

Check the order: \(L_\infty \le L_2 \le L_1\), i.e. \(4 \le 5.385 \le 9\). It always holds.

Common mistakes

  • Rooting each square separately. \(\sqrt9 + \sqrt{16} + \sqrt4 = 9\) is the Manhattan distance, not Euclidean. Add first, root once at the end.
  • Losing the sign of a gap. \((-3)^2 = 9\), not \(-9\). Squares and absolute values are never negative.
  • Mixing up “distance” and “squared distance”. K-means’ SSE and ridge use the squared version (no root). KNN can use either for ranking, because squaring doesn’t change which point is nearest.

Try it with me. \(x = (2, 7)\), \(y = (5, 3)\).

Give the two gaps \(x_1 - y_1\) and \(x_2 - y_2\).

\(2 - 5 = -3\) and \(7 - 3 = 4\).

Now give the squared Euclidean distance, the Euclidean distance and the Manhattan distance.

Squares \(9 + 16 = 25\); \(\sqrt{25} = 5\); Manhattan \(3 + 4 = 7\).

4. Distance to a centre: subtract, then square

In plain words

K-means (week 7) and the centroid linkage measure how far a point is from a centre \(\mu\), usually the average of a group of points. It’s the same squared distance as above, with \(y\) replaced by \(\mu\). The centre often has decimals, which is where most arithmetic slips happen. The rule never changes: gap first, then square.

\[\|x - \mu\|^2 = (x_1 - \mu_1)^2 + (x_2 - \mu_2)^2 + \dots\]

Worked example 5. \(x = (3, 8)\), centre \(\mu = (4.5, 5)\).

coordinate \(x_j\) \(\mu_j\) gap \(x_j - \mu_j\) squared gap
1 3 4.5 −1.5 2.25
2 8 5 3 9
total 11.25

\(\|x - \mu\|^2 = 11.25\).

The slip to avoid: \(3^2 + 8^2 = 73\). That’s the squared distance from \(x\) to the origin \((0, 0)\), which has nothing to do with the cluster.

Common mistakes

  • Squaring raw coordinates. If your “distance to the centre” doesn’t involve \(\mu\) anywhere, it’s wrong. Every row of the table must have a subtraction.
  • Squaring a decimal gap badly. \((-1.5)^2 = 2.25\), \((0.5)^2 = 0.25\), \((2.5)^2 = 6.25\). Learn these three; they come up constantly because centroids of 2 or 4 points end in .5 or .25.

\(x = (6, 1)\) and the centre is \(\mu = (4.5, 3)\). Give both gaps and the squared distance \(\|x - \mu\|^2\).

Gaps \(6 - 4.5 = 1.5\) and \(1 - 3 = -2\). Squares \(2.25 + 4 = 6.25\).

5. Scale matters

In plain words

A distance adds up gaps measured in different units. A gap of £5,000 in income and a gap of 10 years in age are added as if they were the same kind of number, so income swamps age completely. Rescaling every column to a similar spread before computing distances fixes it.

Standardising a column: subtract its mean and divide by its standard deviation, \(x' = (x - \bar x)/s\). The week 2 lab’s normalize() does this before KNN regression. The same problem affects K-means and the ridge penalty.

Worked example 6. Houses A = (100 m², 2 bathrooms), B = (150 m², 2 bathrooms), C = (102 m², 4 bathrooms). Raw squared distances: \(d^2(A, B) = 50^2 + 0^2 = 2500\), \(d^2(A, C) = 2^2 + 2^2 = 8\). So C counts as A’s near-twin even though it has twice the bathrooms, while B is “far” just because of floor area. After standardising (say area sd 25, bathrooms sd 1): \(d^2(A, B) = 2^2 + 0 = 4\), \(d^2(A, C) = 0.08^2 + 2^2 = 4.0064\). Now both differences count.

You run KNN on houses with inputs “floor area in m²” (40 to 300) and “number of bathrooms” (1 to 4) without rescaling. What happens?

A 50 m² gap contributes \(2500\) to the squared distance; a 2-bathroom gap contributes \(4\). Standardise first.
