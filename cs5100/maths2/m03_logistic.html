Logistic and multinomial regression

Dot product, then sigmoid (or softmax), then cross-entropy, then gradient descent. Every piece of logistic regression is from Part A, so this stage is about putting them together in the right order and reading the answer: predicting by hand, interpreting a coefficient, and counting the parameters of the multi-class version.

Built from

1. The assembly

\[p(x) = \underbrace{\sigma}_{\text{A8}}\big(\underbrace{\beta\cdot\tilde x}_{\text{A1}}\big),\qquad \hat\beta = \arg\min_\beta\ \underbrace{-\sum_i\big[y_i\log p_i + (1 - y_i)\log(1 - p_i)\big]}_{\text{A9}}\ \big(+\ \underbrace{\lambda\textstyle\sum_{j\ge1}\beta_j^2}_{\text{A5}}\big)\]

Fitted by \(\beta \leftarrow \beta - \eta\sum_i(p_i - y_i)\tilde x_i\) (A4, A9). Predict class 1 when \(p > 0.5\), i.e. when \(\beta\cdot\tilde x > 0\): a linear decision boundary.

Worked example 1: the ISLP Default model. Fitted on credit-card data: \(\hat\beta_0 = -10.6513\), \(\hat\beta_1 = 0.0055\) per £ of balance (ISLP Table 4.1).

balance \(x\) \(z = -10.6513 + 0.0055x\) \(p = \sigma(z)\) predict default?
1000 −5.151 0.0058 no
2000 0.349 0.586 yes

Boundary: \(z = 0\) at \(x = 10.6513/0.0055 = 1936.6\).

Reading \(\hat\beta_1\): £100 more balance adds \(100\times0.0055 = 0.55\) to the log-odds, so it multiplies the odds of default by \(e^{0.55} = 1.73\). It does not add 0.55 (or 0.0055) to the probability.

Common mistakes

  • Reporting \(z\) as the probability. \(z = 0.349\) is a log-odds; \(p = 0.586\).
  • “Coefficient = change in probability.” It’s the change in log-odds per unit (Toolkit 8).
  • Least squares for logistic regression. It’s fitted by maximum likelihood (cross-entropy), not RSS.
  • Unscaled inputs in gradient descent. Balances in the thousands make the steps unstable; the lab standardises first.

Try it with me. A fitted model has \(\hat\beta = (-2, 0.5)\).

At \(x = 3\): give \(z\), \(p\) and the predicted class.

\(z = -2 + 1.5 = -0.5\). \(p = 1/(1 + e^{0.5}) = 1/2.6487 = 0.3775\). Below 0.5: class 0.

Where is the decision boundary, and by what factor do the odds change per unit of \(x\)?

\(z = 0\) when \(x = 2/0.5 = 4\). Odds multiplier \(e^{0.5} = 1.6487\).

2. Fitting: one gradient step in full

Worked example 2. \(x = (-1, 0, 1, 2)\), \(y = (0, 0, 1, 1)\), start \(\beta = (0, 0)\), \(\eta = 0.1\) (Toolkit 9).

\(x_i\) \(y_i\) \(p_i\) \(p_i - y_i\) \((p_i - y_i)x_i\)
−1 0 0.5 0.5 −0.5
0 0 0.5 0.5 0
1 1 0.5 −0.5 −0.5
2 1 0.5 −0.5 −1
total 0 −2

New \(\beta = (0, 0.2)\); NLL falls from 2.773 to 2.402. Repeat until the gradient is (nearly) zero. These data are perfectly separable (class 1 exactly when \(x > 0.5\)), so without a penalty \(\beta_1\) would keep growing forever: one reason the lab adds \(\lambda\|\beta\|^2\).

3. Many classes: multinomial logistic regression

In plain words

With \(m\) classes, give every class its own coefficient vector \(\beta_k\), compute one score per class, and softmax them. Same loss (cross-entropy), same gradient pattern.

\[z_k = \beta_k\cdot\tilde x,\qquad p_k(x) = \frac{e^{z_k}}{\sum_{k'}e^{z_{k'}}},\qquad \text{parameters} = (p + 1)\times m\]

(ISLP 4.3.5’s “baseline” version fixes one class’s \(\beta\) at 0, giving \((p + 1)(m - 1)\); the slides’ softmax form keeps all \(m\).)

Worked example 3. Three classes, two inputs, \(x = (1, 2)\) so \(\tilde x = (1, 1, 2)\). \(\beta_1 = (0, 1, 0)\), \(\beta_2 = (1, 0, 0.5)\), \(\beta_3 = (-1, 0.5, 1)\).

class \(z_k = \beta_k\cdot\tilde x\) \(e^{z_k}\) \(p_k\)
1 0 + 1 + 0 = 1 2.718 0.186
2 1 + 0 + 1 = 2 7.389 0.506
3 −1 + 0.5 + 2 = 1.5 4.482 0.307
total 14.589 1

Predict class 2. Parameters: \((2 + 1)\times3 = 9\).

Multinomial logistic regression (softmax form) with \(p = 4\) inputs and \(m = 3\) classes. How many coefficients?

\((4 + 1)\times3 = 15\).

Stage test

Why is logistic regression fitted by gradient descent rather than a formula?

Convex, but no closed form.

(4 marks; 2023 Q3.) Describe the logistic regression model for a binary response and how its parameters are estimated.

Logistic regression models \(P(Y = 1\mid x) = \sigma(\beta_0 + \beta^Tx) = \frac{1}{1 + e^{-(\beta_0 + \beta^Tx)}}\), so the log-odds \(\log\frac{p}{1 - p}\) are linear in \(x\). The parameters are estimated by maximum likelihood: choose \(\beta\) to maximise \(\ell(\beta) = \prod_ip_i^{y_i}(1 - p_i)^{1 - y_i}\), equivalently to minimise the cross-entropy \(-\sum_i[y_i\log p_i + (1 - y_i)\log(1 - p_i)]\). There is no closed-form solution, so it is minimised by gradient descent, \(\beta \leftarrow \beta - \eta\sum_i(p_i - y_i)\tilde x_i\); the loss is convex, so this reaches the global minimum. A new point is classified as 1 when \(p > 0.5\), i.e. when \(\beta_0 + \beta^Tx > 0\).
