Averages, indicators and votes

The humblest tool in the course is also the most used: average the numbers, or count the labels and take the most common one. Do that over "the nearby points" and you have KNN, a tree leaf, a K-means centre and a density estimate. Do it over many models and you have bagging. This stage drills the counting carefully, because a miscount ruins every later step.

By the end of this stage you can

  • compute a mean and a centroid (a mean of vectors), and check it;
  • use the indicator \(\mathbb 1(\cdot)\) to turn “how many?” into a sum, and get an error rate and a class proportion from it;
  • take a majority vote and explain the difference between \(\max\) and \(\arg\max\);
  • run KNN classification and KNN regression by hand with a distance table;
  • see one idea, “average or vote over a neighbourhood”, inside six different methods.

Book and slides

No single section: the idea runs through ISLP 2.2.2 to 2.2.3 (error rate, KNN), 3.5 (KNN regression), 8.1 (tree leaves), 8.2.1 (bagging) and 12.4.1 (K-means centres). Week 7 slides, “Non-parametric density estimation”, derive \(f(x) \approx k/(nV)\). Slide typo: week 1 slide equation (33) for KNN leaves out the \(\frac1K\), which turns a probability into a count. Nothing to skip here; it’s all used.

1. The mean, and the centroid

In plain words

The mean is the “fair share”: pool all the values and split them equally. For points with several coordinates, do this separately in each coordinate. The result is the centroid, the balance point of the group.

\[\boxed{\bar y = \frac1n\sum_{i=1}^ny_i,\qquad \mu = \frac1n\sum_{i=1}^nx_i = \Big(\frac1n\sum_ix_{i1},\ \frac1n\sum_ix_{i2},\ \dots\Big)}\]

Symbol Meaning
\(n\) how many values or points
\(y_i\) the \(i\)-th value
\(x_{ij}\) coordinate \(j\) of point \(i\)
\(\mu\) the centroid: one mean per coordinate

Worked example 1. Points \((1, 4)\), \((3, 0)\), \((5, 5)\), \((3, 7)\).

point \(x_{i1}\) \(x_{i2}\)
1 1 4
2 3 0
3 5 5
4 3 7
sum 12 16
÷ 4 3 4

Centroid \(\mu = (3, 4)\).

Check: the gaps from the mean always add to zero. First coordinate: \((1 - 3) + (3 - 3) + (5 - 3) + (3 - 3) = -2 + 0 + 2 + 0 = 0\). Second: \(0 - 4 + 1 + 3 = 0\). If a check doesn’t come to 0, the mean is wrong.

Common mistakes

  • Dividing by the wrong \(n\). Count the points, not the coordinates.
  • Averaging across a point instead of down a column. \((1 + 4)/2\) mixes two different inputs; it means nothing.
  • Dropping a negative sign in the sum. Write the column out in full before adding.

Find the centroid of \((0, 2)\), \((4, 5)\), \((2, 2)\).

First coordinates \(0 + 4 + 2 = 6\), \(/3 = 2\). Second \(2 + 5 + 2 = 9\), \(/3 = 3\). Check: \(-2 + 2 + 0 = 0\) and \(-1 + 2 - 1 = 0\).

2. The indicator, error rates and proportions

In plain words

The indicator \(\mathbb 1(\text{statement})\) is a switch: 1 if the statement is true, 0 if false. Adding indicators counts how often something is true. Dividing that count by \(n\) gives a proportion. So “a proportion is a mean of indicators”.

\[\boxed{\frac1n\sum_{i=1}^n\mathbb 1(y_i = k) = \text{fraction with label } k,\qquad \text{error rate} = \frac1n\sum_{i=1}^n\mathbb 1(\hat y_i \ne y_i)}\]

Worked example 2. True labels and predictions for 6 points:

\(i\) \(y_i\) \(\hat y_i\) \(\mathbb 1(\hat y_i \ne y_i)\) \(\mathbb 1(y_i = A)\)
1 A A 0 1
2 B A 1 0
3 A A 0 1
4 C C 0 0
5 A B 1 1
6 B B 0 0
sum 2 3

Error rate \(= 2/6 = 0.333\). Proportion of A’s \(\hat p_A = 3/6 = 0.5\). Accuracy \(= 1 - 0.333 = 0.667\).

True labels \((1, 0, 0, 1, 1, 0, 1, 0)\), predictions \((1, 0, 1, 1, 0, 0, 1, 0)\). How many mistakes, and what is the error rate?

Compare position by position: mismatches at 3 and 5. \(2/8 = 0.25\).

3. Vote: \(\max\) versus \(\arg\max\)

In plain words

To predict a class from a group of labels, pick the most common one. In symbols that’s \(\arg\max\): “the class \(k\) that makes the proportion biggest”. \(\max\) is the biggest value (a number like 0.6); \(\arg\max\) is which class gives it (a label like “A”).

\[\hat y = \arg\max_k\hat p_k\]

Worked example 3. Labels A, B, A, C, A. \(\hat p = (0.6, 0.2, 0.2)\) for (A, B, C). \(\max_k\hat p_k = 0.6\); \(\arg\max_k\hat p_k = A\). The prediction is A, and if it’s wrong, it’s wrong with “probability” \(1 - 0.6 = 0.4\) on this group.

Common mistakes

  • Writing a number when the question asks for a class, or the other way round. “What does the Bayes classifier predict?” wants a label; “what is the Bayes error at \(x_0\)?” wants \(1 - \max_kP(Y = k\mid x_0)\), a number.
  • Ties. With an even \(K\) in a two-class KNN you can get 2 votes each. Exam questions avoid this by using odd \(K\); if you meet one, say how you’d break it.

4. KNN: distance table, then vote or average

In plain words

To predict at a new point \(x_0\): find the \(K\) training points closest to it, then vote (classification) or average (regression). The only skill is ranking distances correctly, so use a table.

\[\tilde P(Y = k\mid x_0) = \frac1K\sum_{i\in\mathcal N_0}\mathbb 1(y_i = k),\qquad \hat f(x_0) = \frac1K\sum_{i\in\mathcal N_0}y_i\]

where \(\mathcal N_0\) is the set of the \(K\) nearest training points.

Worked example 4: classification in 2D. Training points: \((1, 1)\) A, \((2, 5)\) B, \((4, 2)\) A, \((6, 5)\) B, \((3, 4)\) B. Classify \(x_0 = (3, 2)\) with \(K = 3\).

point label gaps to \(x_0\) \(\|x - x_0\|^2\) rank
(1, 1) A (−2, −1) 4 + 1 = 5 3
(2, 5) B (−1, 3) 1 + 9 = 10 4
(4, 2) A (1, 0) 1 + 0 = 1 1
(6, 5) B (3, 3) 9 + 9 = 18 5
(3, 4) B (0, 2) 0 + 4 = 4 2

The three nearest (ranks 1 to 3) have labels A, B, A. So \(\tilde P(A\mid x_0) = 2/3\), \(\tilde P(B\mid x_0) = 1/3\), and KNN predicts A.

Tie check: the 3rd distance² is 5 and the 4th is 10, so the cut-off is clean. If they had been equal, the answer would depend on how ties are broken, and you should say so.

With \(K = 1\) the answer is A (only \((4, 2)\)). With \(K = 5\) it’s every point: 2 A, 3 B, so B. Changing \(K\) can flip the prediction, which is why \(K\) is the flexibility knob.

Worked example 5: regression on a line. Training data \(x = (1, 2, 4, 7, 8)\), \(y = (3, 5, 4, 10, 12)\). Predict at \(x_0 = 2.5\) with \(K = 3\).

\(x_i\) \(y_i\) \(\lvert x_i - 2.5\rvert\) rank
1 3 1.5 2 (tie)
2 5 0.5 1
4 4 1.5 2 (tie)
7 10 4.5 4
8 12 5.5 5

The tie at rank 2 doesn’t matter: both tied points are inside the top 3. \(\hat f(2.5) = (5 + 3 + 4)/3 = 4\).

Common mistakes

  • Not checking ties at the \(K\)-th place. If the \(K\)-th and \((K+1)\)-th distances are equal, the answer isn’t defined. Say so.
  • Dividing by the number of class-A neighbours instead of by \(K\). \(\tilde P(A) = (\text{A's among the } K)/K\).
  • Forgetting the \(\frac1K\) (week 1 slide (33) has this typo). Without it you get a count, not a probability.
  • Square roots slow you down. To rank, squared distances are enough.

Same data: \(x = (0, 3, 5, 6, 10)\), \(y = (2, 8, 7, 9, 1)\), labels A, B, A, A, B, \(x_0 = 4.6\), \(K = 2\). Give the KNN regression prediction and the number of A’s among the 2 nearest.

Distances \(\lvert x_i - 4.6\rvert\): \(4.6, 1.6, 0.4, 1.4, 5.4\). Nearest two: \(x = 5\) (\(y = 7\), A) and \(x = 6\) (\(y = 9\), A). Prediction \((7 + 9)/2 = 8\); both are A.

5. One idea, many methods

Most non-parametric methods in the course are “pick a group of points near \(x\), then average or vote”. Only the rule for “near” changes:

Method Who is “near” \(x\) Then
KNN classifier (w1) the \(K\) closest points vote
KNN regression (w2) the \(K\) closest points average
Regression tree (w4) points in the same leaf (box) average
Classification tree (w4) points in the same leaf vote
Histogram / \(k/(nV)\) (w7) points in a region of volume \(V\) count, divide by \(nV\)
K-means update (w7) points assigned to centre \(j\) average: the new centre
Bagging (w6) not points but \(B\) models average or vote their predictions

Worked example 6: the same data, three methods. \(x = (1, 2, 4, 7, 8)\), \(y = (3, 5, 4, 10, 12)\), predict at \(x_0 = 2.5\).

  • KNN, \(K = 3\): neighbours \(x = 2, 1, 4\), so \(\hat y = (5 + 3 + 4)/3 = 4\).
  • A tree split at \(x < 5.5\): \(x_0\) falls in the left leaf \(\{1, 2, 4\}\), so \(\hat y = 4\).
  • Density with region \([1, 4]\) (width \(V = 3\)): \(k = 3\) of \(n = 5\) points inside, so \(f(2.5) \approx \frac{k}{nV} = \frac{3}{5\times3} = 0.2\).

Which of these are “average or vote over a neighbourhood” methods? Tick all that apply.

Logistic regression uses one global formula \(\sigma(\beta\cdot\tilde x)\); it doesn’t look at a local group when it predicts.

Stage test

The 5 nearest neighbours of \(x_0\) have labels red, blue, red, red, blue. What is KNN’s \(\tilde P(Y = \text{red}\mid x_0)\) with \(K = 5\)?

\(\frac15\sum\mathbb 1(y_i = \text{red}) = 3/5 = 0.6\).

Bagging averages three regression trees whose predictions at \(x_0\) are \(6\), \(7\) and \(8\). What does the bagged model predict?

\((6 + 7 + 8)/3 = 7\).

At \(x_0\) the class proportions are \((0.5, 0.3, 0.2)\) for classes (1, 2, 3). Which statement is right?

\(\arg\max\) returns the class; \(\max\) returns the value.
