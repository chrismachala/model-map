The pattern behind the course

You spotted it already: the course teaches models, and inside each model, techniques.

  • A model is a shape you assume for the rule connecting inputs to the answer. “It’s a straight line” (linear regression). “It’s an S-curve of probability” (logistic regression). “Copy your nearest neighbours” (KNN).
  • A technique is a tool for using that model: how to find its numbers (least squares, gradient descent, maximum likelihood), how to stop it overreacting (ridge penalty, choosing \(K\)), or how to score it (MSE, ROC).

The same handful of techniques keeps reappearing across models. Once you know them, each “new” model is mostly old pieces in a new arrangement.

Which techniques belong to which model

Model How its numbers are found How you control bendiness How you score it
Bayes classifier nothing to fit: needs the true chances (never known) n/a Bayes error rate (the floor)
KNN nothing to fit: just stores the data \(K\), chosen on a validation set error rate
Linear regression least squares, by formula or gradient descent add or remove inputs RSS, RSE, \(R^2\), test MSE
Polynomial and step least squares on new columns degree or number of cut points test MSE
Ridge regression least squares plus a penalty \(\lambda\), chosen on a validation set test MSE
KNN regression nothing to fit \(K\) test MSE
Logistic regression maximum likelihood, by gradient descent inputs, optional penalty \(\lambda\) error rate, ROC, AUC
LDA counting and averaging (priors, means, pooled spread) (fixed by its assumption) error rate, ROC, AUC
Naive Bayes counting and averaging per input (fixed by its assumption) error rate, ROC, AUC
Regression tree greedy splits that cut the RSS most; leaf averages depth, leaf size, pruning fee \(\alpha\) test MSE, \(R^2\)
Classification tree greedy splits that cut the Gini index most; leaf votes depth, pruning fee \(\alpha\) error rate
Neural network gradient descent + backpropagation hidden units \(K\), penalty \(\lambda\), early stopping test MSE
Neural network classifier gradient descent on cross-entropy same as above error rate, confusion matrix

How the weeks build on each other

  1. Week 1 sets the stage. What a model is, how to score it, why the test score matters more than the training score, and the ideal classifier we’re all trying to copy. KNN is the first real model: it copies the ideal by counting neighbours.
  2. Week 2 builds the first model with numbers to fit, the straight line. Then it bends it (polynomials, steps) and calms it down when it bends too much (ridge).
  3. Week 3 goes back to categories. Three new ways to estimate the chance of each class: squash a line into an S-curve (logistic), or describe each class and flip with Bayes’ theorem (LDA, naive Bayes). Then how to judge them properly.
  4. Week 4 brings two flexible models that work for numbers and categories. Trees cut the inputs into boxes with yes/no questions (and get pruned with a penalty, like ridge). Neural networks learn their own features and are fitted with gradient descent, using the chain rule (backpropagation) and week 3’s softmax.

How to use these pages

  • Read the green “why this exists” box first on every page. That’s the context the lectures skip.
  • Purple boxes are plain-English word lists. Yellow boxes are worked examples to copy out by hand. Red boxes flag slide typos and lab bugs.
  • Turn on Try-first (top bar) to hide every worked example until you’ve had a go on paper.
  • Press Mark as understood on each technique. Your progress shows in the sidebar and on these tiles (it’s saved in this browser only).
  • Play with the interactive demos: sliders that move the S-curve, roll gradient descent downhill, shift a decision boundary and more.
  • Each page ends with a practice prompt. Click “Copy prompt” and paste it into any AI chat to get questions one at a time, with worked solutions after you answer.
  • Each page also says which parts of the book chapter are on the slides and which you can skip.
