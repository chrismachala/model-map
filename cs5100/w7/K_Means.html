K-means clustering

No labels at all: just points. Guess K groups, put a centre at each group's mean, move every point to its nearest centre, and repeat until nothing moves. Fast and simple, but the answer depends on where you start.

Question type: unsupervised: clustering (a flat partition into at most \(K\) groups).
Week: 7 (slides 9–28, 50).
Book: ISLP 12.1 (p503–504), 12.4 intro and 12.4.1 (p520–525), Algorithm 12.2. (Slide 78 says “Section 10.3”: that’s the old R edition.)
Past paper: 2023 Q5(a) i and ii (is K-means deterministic? must it output \(K\) clusters?).
Techniques on this page: metrics, the SSE objective, K-means by hand, why it terminates, restarts, choosing \(K\), empty clusters, the lab’s KMeans.

The problem it solves

Sometimes you have data but no answers to predict: customers, genes, documents. You want to find natural groups. Trying every grouping is hopeless (\(K^n\) of them; slide 19: \(5^{100} \approx 10^{70}\)), so K-means starts from a guess and keeps improving it until it can’t.

Words you’ll hear

Word Plain meaning
cluster \(\omega_j\) a group of observations
centroid \(\mu_j\) the mean of a cluster’s points
metric \(d(x, y)\) a distance: \(\ge 0\), \(= 0\) only for \(x = y\), symmetric, triangle inequality
\(J_{SSE}\) sum of squared distances from each point to its cluster’s centroid
local minimum no single step can improve it, but a better answer may exist elsewhere
flat vs hierarchical one partition vs a tree of nested partitions

Technique 1: metrics (slides 11–14)

Minkowski \(L_k\): \(\big(\sum_i|x_i - y_i|^k\big)^{1/k}\). Manhattan (\(k = 1\)) adds the differences, Euclidean (\(k = 2\)) is the straight line, Chebyshev (\(k = \infty\)) takes the largest difference.

\(x = (1, 2)\), \(y = (4, -2)\): differences 3 and 4. Manhattan 7, Euclidean 5, Chebyshev 4. Always \(L_1 \ge L_2 \ge L_\infty\).

Squared Euclidean distance is not a metric: \(0, 1, 2\) give \(4 > 1 + 1\), breaking the triangle inequality.

Technique 2: the SSE objective (slide 15)

\[J_{SSE} = \sum_{j=1}^K\sum_{x \in \omega_j}\|x - \mu_j\|^2 .\] Each point is summarised by its centroid; \(J_{SSE}\) adds up the squared errors. Smaller is better. (ISLP’s eq. 12.17 is exactly twice this, so it picks the same clusters.)

Technique 3: the algorithm by hand (slide 22, Algorithm 12.2)

  1. Randomly assign each observation to one of \(K\) clusters.
  2. Repeat until nothing changes: (a) compute each cluster’s centroid; (b) move each point to the nearest centroid (ties: stay put).

Data \(1, 2, 4, 7, 8, 9\), \(K = 2\), start A \(= \{1, 4, 8\}\), B \(= \{2, 7, 9\}\). Centroids \(4.33\) and \(6\). Reassign: \(1, 2, 4 \to\) A; \(7, 8, 9 \to\) B. Centroids \(2.33\) and \(8\). Nothing moves: stop. \(J_{SSE} = (1.78 + 0.11 + 2.78) + (1 + 0 + 1) = 6.67\).

Technique 4: why it stops, and why restart (slides 24–26)

  • Step (a) never raises \(J_{SSE}\): for fixed points, the mean minimises the sum of squared distances (\(\frac{d}{dc}\sum(x_i - c)^2 = 0 \iff c = \bar x\)).
  • Step (b) never raises it: a point only moves to a closer centre.
  • Only finitely many assignments (\(\le K^n\)), and every real move strictly lowers \(J_{SSE}\), so no assignment repeats: it must stop.

But it stops at a local minimum that depends on the start. Slide 25: six runs give 320.9, 235.8 (×4), 310.9. Run it several times and keep the lowest. So K-means is not deterministic (2023 Q5(a)i).

Technique 5: choosing K, and fewer than K clusters (slides 27–28)

\(J_{SSE}\) always falls as \(K\) grows (0 at \(K = n\)), so you can’t minimise it over \(K\). Plot it against \(K\) and look for the elbow: big drops, then small ones. (Lab: Iris drops 152 → 79 → 57 → 46, elbow near 3.)

Empty cluster (2023 Q5(a)ii). Data \(-3, -2, 2, 3\), \(K = 3\), start \(\{-3\}, \{3\}, \{-2, 2\}\). Centroids \(-3, 3, 0\). Now \(-2\) is nearer \(-3\) and \(2\) nearer \(3\): the third cluster is empty. Output: 2 clusters. \(K\) is a maximum.

The lab’s KMeans is not quite the lecture’s. It starts from k-means++ centroids, not a random assignment; n_init does the restarts for you; score(X) is minus \(J_{SSE}\) (inertia_); and it re-seeds empty clusters, so it always returns exactly \(K\).
