Bias, variance and regularisation

A model is judged on data it has never seen. Its expected test error splits into three parts: bias (wrong on average), variance (jumps around with the training set) and noise (nobody can fix). Flexibility trades the first two; regularisation is the dial.

Question type: not a model: how to judge and tune any model.
Week: 5 (Ivan Rungger).
Book: ISLP 2.2.1–2.2.2 (p29–35), 5.1.1 (p202–204); re-read 6.2.1 (ridge) and 8.1.1 “Tree pruning”. The slides cite ESL, Bishop and Mitchell instead; you don’t need them.
Techniques on this page: training vs test error, the bias-variance decomposition, the U-shaped test error, validation sets, pruning and ridge as “fit + penalty”.

The problem it solves

Training a model means minimising its error on the training set. So the training error is measured on exactly the data the model was tuned to: it is optimistic, sometimes absurdly (1-NN and a fully grown tree have training error 0). What we actually want is a low error on new data from the same source. This page explains why the two differ, how to predict which way a change of model will push the test error, and how to turn a model’s flexibility down when it overfits.

Words you’ll hear

Word Plain meaning
i.i.d. training and test examples are independent draws from the same distribution \(P(X, Y)\)
overfitting low training error, much higher test error: the model learned the noise
underfitting both errors high: the model is too rigid
flexibility how wiggly a model can be: degree, leaves, \(1/K\), hidden units
bias how far the average model (over many training sets) is from the truth
variance how much the model changes from one training set to another
irreducible error the noise in the labels, \(\mathrm{Var}(\mathcal E)\): the floor no model can beat
regularisation adding a complexity penalty to the training objective

Technique 1: training vs test error and the U-shape

Problem it solves: choosing how flexible a model should be.

Plot error against flexibility (ISLP Fig 2.9, slide 10):

  • training error always goes down;
  • test error goes down, then up: a U.

The best model is at the bottom of the test U, not the training curve. You can’t choose on the test set (that makes the test error optimistic too), so hold out a validation set from the training data, choose there, and use the test set once at the end.

training error test error fix
underfitting high high more flexible
overfitting very low much higher less flexible, regularise, more data

Technique 2: the bias-variance decomposition

Problem it solves: explaining the U.

With \(Y = f_{true}(X) + \mathcal E\), \(\mathbb E\mathcal E = 0\), and the expectation taken over training sets and test noise:

\[\mathbb E\big(\hat f(x_0) - Y\big)^2 = \underbrace{\big(\mathbb E\hat f(x_0) - f_{true}(x_0)\big)^2}_{\text{bias}^2} + \underbrace{\mathrm{Var}\,\hat f(x_0)}_{\text{variance}} + \underbrace{\mathrm{Var}\,\mathcal E}_{\text{irreducible}}\]

Proof in one line: \(\mathbb E(Z - \mathcal E)^2 = \mathbb EZ^2 + \mathbb E\mathcal E^2\) for \(Z = \hat f(x_0) - f_{true}(x_0)\) independent of the test noise, then \(\mathbb EZ^2 = (\mathbb EZ)^2 + \mathrm{Var}Z\).

More flexibility: bias ↓, variance ↑. The sum is the U (ISLP Fig 2.12).

Worked example. \(f_{true}(x_0) = 5\), noise variance 1. Over training sets the model predicts 2, 4 or 6 at \(x_0\), equally often. Average 4, so bias² \(= 1\). Variance \(= \frac{4 + 0 + 4}{3} = 2.67\). Expected test error \(= 1 + 2.67 + 1 = 4.67\).

KNN runs backwards. Flexibility decreases as \(K\) grows. \(K = 1\): training error 0, jagged boundary, high variance. \(K = 100\): smooth boundary, high bias (slide 18, ISLP Fig 2.16).

Technique 3: regularisation = fit + α × complexity

Problem it solves: sliding flexibility down within a model class.

Model penalised objective more \(\alpha\) ⟹
tree (pruning) \(\mathrm{RSS}(T) + \alpha\lvert T\rvert\) fewer leaves
linear (ridge) \(\mathrm{RSS}(\lambda) + \alpha\sum_{i\ge1}\lambda_i^2\) smaller coefficients

More regularisation: a little more bias, a lot less variance. Choose \(\alpha\) on validation data; then (slide 24) refit with the chosen \(\alpha\) on training + validation data.

Ridge with one coefficient. Minimise \(\sum(y_n - \lambda x_n)^2 + \alpha\lambda^2\): \(\hat\lambda = \frac{\sum x_ny_n}{\sum x_n^2 + \alpha}\). With \(x = (1, 2, 3)\), \(y = (2, 4, 7)\): \(\alpha = 0\) gives 2.21, \(\alpha = 14\) gives 1.11. The penalty shrinks the slope towards 0.

Slide 25 penalises the intercept (\(\|\lambda\|^2\) includes \(\lambda_0\)). ISLP and the week 2 slides don’t, and that’s the usual choice. In an exam write \(\alpha\sum_{i=1}^d\lambda_i^2\) and say “intercept not penalised”. Standardise the inputs first.
