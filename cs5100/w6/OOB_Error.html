Out-of-bag (OOB) error

Every bootstrap sample leaves out about a third of the data. Each point can be predicted by the trees that never saw it: a free, honest test error for bagging. And the most repeated question in your past papers.

Question type: not a model: a test-error estimate for bagging and random forests.
Week: 6 (slides 19–25).
Book: ISLP 8.2.1, “Out-of-bag error estimation” (p345).
Past papers: 2023 Q4(b) and 2025 Q3(b), almost word for word; revision sheet q06 Q11–13.
Techniques on this page: the OOB procedure, the hand calculation, the \((1 - 1/n)^n \to 1/e\) lemma.

The problem it solves

To estimate the test error of a bagged model you’d normally need a validation set (less training data) or cross-validation (bag \(B\) trees again \(K\) times). But each tree was trained on a bootstrap sample that missed some points, and for those points it is an untouched test case. Collect those predictions and you have a test error for free.

Words you’ll hear

Word Plain meaning
out-of-bag (OOB) for tree \(b\) a training point not in tree \(b\)’s bootstrap sample
OOB prediction of point \(i\) average (or vote) of the trees for which \(i\) is OOB
OOB MSE \(\frac1n\sum_i(y_i - \hat y_i^{OOB})^2\)
OOB error rate fraction of points whose OOB vote is wrong

Technique 1: the procedure

For each training point \(i\):

  1. find the trees whose bootstrap sample does not contain \(i\) (about \(B/3\));
  2. OOB prediction = their average (regression) or majority vote (classification).

Then OOB MSE (or error rate) over all points. Valid because each prediction uses only trees that never saw the point. Cheaper than cross-validation (no retraining). If some point is in every sample, leave it out of the average (or use more trees).

Technique 2: by hand (the exam question)

Slide 22 toy example. \(y = (1, 2, 0, 1)\); samples \(\{O_1, O_2, O_2, O_4\}\), \(\{O_2, O_3, O_4, O_4\}\), \(\{O_1, O_1, O_1, O_2\}\), \(\{O_1, O_3, O_3, O_4\}\) with predictions \((1,2,2,1)\), \((0,2,0,1)\), \((1,2,0,0)\), \((1,0,0,1)\).

  • \(O_1\): missing only from sample 2 → 0. Error \(1\).
  • \(O_2\): missing only from sample 4 → 0. Error \(4\).
  • \(O_3\): missing from samples 1 and 3 → \((2 + 0)/2 = 1\). Error \(1\).
  • \(O_4\): missing only from sample 3 → 0. Error \(1\).

OOB MSE \(= 7/4\).

2023 Q4(b). \(D = \{(1,4),(3,10),(4,9),(7,10),(10,6),(12,-1)\}\). \(x = 3\) is missing from BTS 1, 4, 5 (predictions 8, 9, 10): 9. \(x = 7\) only from BTS 2: 7. \(x = 12\) from BTS 2, 3 (\(-6, -4\)): −5. With the given 6, 7, 9 at \(x = 1, 4, 10\): OOB MSE \(= \frac{4 + 1 + 4 + 9 + 9 + 16}{6} = \frac{43}{6} \approx 7.17\).

2025 Q3(b). \(x = 2\): BTS 4, 5 → 3.5. \(x = 5\): BTS 1, 3 → 9. OOB MSE \(= 0.625\).

The classic slip: averaging the samples that do contain the point. Tick off the samples containing it first; use the others. Read the bootstrap sets by their \((x, y)\) pairs: \((7, 10)\) appearing twice still means \(x = 7\) is in.

Technique 3: why “about a third”

A point is missed by one draw with probability \(1 - \frac1n\), by all \(n\) draws with probability \((1 - \frac1n)^n \to e^{-1} \approx 0.368\).

\(n\) 2 5 10 100 ∞
\((1 - 1/n)^n\) 0.25 0.328 0.349 0.366 0.368

So each BTS contains about 63.2% of the distinct points.
