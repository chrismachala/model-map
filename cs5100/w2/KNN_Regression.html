KNN regression

Week 1's KNN, but for numbers: instead of a majority vote, take the average answer of the K nearest neighbours.

Question type: regression.
Week: 2 (lab Q2 compares it with linear regression on the Boston housing data).
Book: ISLP 3.5 (recommended; not in the slide headers but it’s exactly lab Q2).
Techniques on this page: neighbourhood average, normalising, the comparison with linear regression.

The problem it solves

Linear regression assumes a straight-line shape. If the true relationship is curvy in ways you can’t guess, that assumption hurts. KNN regression assumes no shape: to predict a house price, it averages the prices of the most similar houses. It’s the non-parametric alternative, and the lab asks you to compare the two.

If you’ve read the KNN classifier page, you already know 90% of this.

Technique 1: the neighbourhood average

  1. Find the \(K\) training points nearest to the new point \(x_0\) (same distance as week 1).
  2. Predict the average of their \(y\) values:

\[\hat y(x_0) = \frac1K\sum_{i\,\in\,\text{neighbours}} y_i\]

Worked example. \(x = (1,2,3,4,5,6)\), \(y = (1.0, 1.5, 2.5, 3.0, 5.0, 6.0)\).

  • New point \(x_0 = 3.4\), \(K = 3\). Nearest: \(x = 3\) (gap 0.4), \(x = 4\) (0.6), \(x = 2\) (1.4). Prediction \((2.5 + 3.0 + 1.5)/3 \approx 2.33\).
  • New point \(x_0 = 5.2\), \(K = 2\). Nearest: \(x = 5\) (0.2), \(x = 6\) (0.8). Prediction \((5.0 + 6.0)/2 = 5.5\).

\(K\) is the same bendiness dial as before. \(K = 1\) has zero training error (every point predicts itself) and means nothing. Large \(K\) flattens everything towards the overall average. Choose \(K\) on a validation set (see ridge regression for the train/validation/test recipe).

Technique 2: normalise first

Distances add up raw differences. In the Boston data, TAX is in the hundreds and NOX is around 0.5, so without rescaling, “nearest” would mean “similar tax” and nothing else. The lab’s normalize() rescales each column to average 0 and spread 1. Strictly, use the training set’s average and spread for all three splits, so no information leaks from the test data.

Technique 3: KNN vs linear regression (lab Q2)

Situation Usually wins Why
the truth is close to a straight line linear regression right shape, low variance
strongly curved truth, plenty of data KNN with a good \(K\) no wrong shape assumed
many inputs (large \(p\)) linear regression with many inputs every point is far from every other, so “neighbours” aren’t really near (the curse of dimensionality)
you need to explain why linear regression coefficients can be read; KNN is a black box

Compare them fairly: choose each one’s settings on the validation set, then compare on the test set once.
