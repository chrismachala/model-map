Likelihood, log-likelihood and cross-entropy

Squared error is the loss for numbers. For classes, the course uses one loss everywhere: minus the log of the probability the model gave to the right answer. It comes from maximum likelihood, it trains logistic regression and neural network classifiers, and its gradient is the same "prediction minus truth" every time. It even turns out to be the entropy of a tree leaf.

Book and slides

ISLP 4.3.2 (the likelihood, eq. 4.5: read the first half, skip Table 4.1’s standard errors and z-statistics), 10.2 p. 405 (one-hot labels and cross-entropy, eq. 10.14). Week 3 slides on maximum likelihood; week 4 slides on the classification objective. Watch the notation: on the slides \(\ell\) is the likelihood and \(-\log\ell\) is minimised; in the week 3 lab notebook \(\ell\) already means the negative log-likelihood.

1. The likelihood

A model gives probabilities to outcomes. The likelihood of the parameters is the probability the model gives to the data you actually saw. With independent points, multiply:

\[\ell(\beta) = \prod_{i=1}^{n}P_\beta(y_i\mid x_i).\]

Maximum likelihood picks the parameters that make \(\ell\) as big as possible: “the explanation under which what happened was least surprising”.

For 0/1 labels with \(p_i = P(Y = 1\mid x_i)\), the probability of what happened is \(p_i\) if \(y_i = 1\) and \(1 - p_i\) if \(y_i = 0\), written in one go as \(p_i^{y_i}(1 - p_i)^{1 - y_i}\).

Worked example. \(y = (1, 0, 1)\). Model A: \(p = (0.9, 0.2, 0.8)\), \(\ell = 0.9 \times 0.8 \times 0.8 = 0.576\). Model B: \(p = (0.6, 0.5, 0.5)\), \(\ell = 0.6 \times 0.5 \times 0.5 = 0.15\). A explains the data almost four times better.

2. Take logs, flip the sign

Products of many small numbers underflow to 0 and are awkward to differentiate. Take logs (products become sums; log is increasing, so the best parameters don’t move) and negate so we minimise:

\[\boxed{L(\beta) = -\log\ell(\beta) = -\sum_{i=1}^{n}\Big[y_i\log p_i + (1 - y_i)\log(1 - p_i)\Big]}\]

This is the negative log-likelihood (NLL), also called binary cross-entropy or log loss. Each term is \(-\log(\text{probability given to the truth})\): \(-\log 0.99 = 0.01\) for a confident correct answer, \(-\log 0.01 = 4.6\) for a confident wrong one.

3. Many classes: cross-entropy

With \(m\) classes, encode the label as one-hot (\(y_{ik} = 1\) for the true class, 0 for the others) and let \(p_k(x_i)\) be the model’s probabilities (softmax, Toolkit 8):

\[L = -\sum_{i=1}^{n}\sum_{k=1}^{m}y_{ik}\log p_k(x_i) = -\sum_{i=1}^{n}\log p_{y_i}(x_i).\]

Only the true class’s probability counts. The binary formula above is this with \(m = 2\).

4. The gradient: prediction minus truth

For logistic regression, chain \(\beta \to z = \beta\cdot\tilde x \to p = \sigma(z) \to L\) (Toolkit 4):

\[\frac{\partial L_i}{\partial p_i} = -\frac{y_i}{p_i} + \frac{1 - y_i}{1 - p_i}, \quad \frac{\partial p_i}{\partial z_i} = p_i(1 - p_i), \quad \frac{\partial z_i}{\partial\beta} = \tilde x_i.\]

The first two multiply to \(p_i - y_i\), so

\[\boxed{\nabla L(\beta) = \sum_{i=1}^{n}(p_i - y_i)\,\tilde x_i}\]

For softmax + cross-entropy the same cancellation happens per output: \(\partial L_i/\partial z_k = p_k(x_i) - y_{ik}\) (w4). And squared error gave \(-2(y_i - \hat y_i)\tilde x_i\). One shape, three models.

Worked example: one step. \(x = (-1, 0, 1, 2)\), \(y = (0, 0, 1, 1)\), \(\beta = (0, 0)\), \(\eta = 0.1\). All \(p_i = 0.5\), so \(p - y = (0.5, 0.5, -0.5, -0.5)\). \(\partial L/\partial\beta_0 = \sum(p_i - y_i) = 0\); \(\partial L/\partial\beta_1 = \sum(p_i - y_i)x_i = -0.5 + 0 - 0.5 - 1 = -2\). Step: \(\beta = (0, 0) - 0.1(0, -2) = (0, 0.2)\). Loss falls from \(2.773\) to \(2.402\).

One point \(x = 2\), \(y = 1\), logistic regression at \(\beta = (0, 0)\), \(\eta = 0.1\). Using \(\nabla L = (p - y)\tilde x\), what is \(\beta_1\) after one step?

\(p = 0.5\), \(\nabla L = (0.5 - 1)(1, 2) = (-0.5, -1)\), \(\beta = (0, 0) - 0.1(-0.5, -1) = (0.05, 0.1)\).

5. Maximum likelihood is behind other estimates too

  • Counting is maximum likelihood. If each class has probability \(\pi_k\), the likelihood of seeing \(n_k\) of class \(k\) is maximised at \(\hat\pi_k = n_k/n\) (LDA and naive Bayes priors, w3; tree leaf proportions, w4).
  • The mean is maximum likelihood for a Gaussian’s centre (Toolkit 7), so LDA’s \(\hat\mu_k\) is too.
  • Least squares is maximum likelihood under Gaussian noise (Toolkit 7).

6. Entropy is cross-entropy in disguise

Suppose a tree leaf has class proportions \(\hat p_1, \dots, \hat p_m\) and predicts exactly those probabilities for every point in it. Its average cross-entropy per point is \(-\sum_k\hat p_k\log\hat p_k\): a fraction \(\hat p_k\) of the points are class \(k\), and each costs \(-\log\hat p_k\). That is the entropy impurity \(D\) of Toolkit 10. So splitting a tree to reduce entropy is splitting it to reduce the NLL.

A leaf holds 3 red and 3 blue points. What is its average cross-entropy if it predicts \((0.5, 0.5)\) for each point (natural log)?

Every point costs \(-\log 0.5 = 0.693\), so the average is \(0.693 = \log 2\): the maximum entropy for two classes.

Stage test

(4 marks; 2023 Q3 and 2025 Q2.) Write an objective function for training a classifier that outputs class probabilities \(p_k(x)\), and explain where it comes from.

For training data \(\{(x_i, y_i)\}\), the likelihood is \(\ell = \prod_ip_{y_i}(x_i)\), the probability the model assigns to the labels actually observed (assuming independent points). Maximum likelihood chooses the parameters that maximise it; equivalently we minimise the cross-entropy \(L = -\log\ell = -\sum_i\log p_{y_i}(x_i)\), which for two classes is \(-\sum_i[y_i\log p_i + (1 - y_i)\log(1 - p_i)]\). The log turns the product into a numerically stable sum without changing the optimum. There is usually no closed form, so it’s minimised by gradient descent, using the gradient \((p - y)\times\) input.

A 3-class network gives the true class probability \(0.1\). What does this point add to the cross-entropy loss?

\(-\log 0.1 = 2.303\).
