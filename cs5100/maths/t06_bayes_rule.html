Probability and Bayes' rule

Classification is about one quantity: the probability of each class given the inputs, P(Y = k | X = x). The Bayes classifier wants it, KNN estimates it by counting, logistic regression models it directly, and LDA and naive Bayes get it by flipping the other conditional with Bayes' rule. The same few probability facts also give the 36.8% of the bootstrap and the p-value of the sign test.

1. Conditional probability

\(P(A\mid B)\) is “the probability of \(A\) among the cases where \(B\) happened”:

\[P(A\mid B) = \frac{P(A\text{ and }B)}{P(B)}.\]

Independent events satisfy \(P(A\text{ and }B) = P(A)P(B)\): knowing one tells you nothing about the other.

2. Bayes’ rule

Flip a conditional around:

\[P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}.\]

In classification, with prior \(\pi_k = P(Y = k)\) and class density \(f_k(x) = P(X = x\mid Y = k)\):

\[\boxed{P(Y = k\mid X = x) = \frac{\pi_k\,f_k(x)}{\sum_{l}\pi_l\,f_l(x)}}\]

The denominator is just “add up the top line over all classes”, so the answers sum to 1. To predict, you can skip it: \(\arg\max_k\pi_kf_k(x)\) gives the same class.

Worked example: rare disease. 1% of people have it (\(\pi_1 = 0.01\)). The test is positive for 90% of the sick and 5% of the healthy. \(P(\text{sick}\mid +) = \frac{0.01 \times 0.9}{0.01 \times 0.9 + 0.99 \times 0.05} = \frac{0.009}{0.0585} = 0.154\). A positive test still means only a 15% chance: the prior matters.

3. The Bayes classifier: the ideal

If you knew \(P(Y = k\mid x)\) exactly, the best rule (lowest possible error rate) would be

\[\hat Y(x) = \arg\max_k P(Y = k\mid X = x),\]

with error \(1 - \max_kP(Y = k\mid x)\) at that \(x\). Averaged over \(x\), that’s the Bayes error rate: the floor no classifier can beat. Every classifier in the course is a way of estimating \(P(Y = k\mid x)\) and plugging it into this rule:

Classifier How it gets \(P(Y = k\mid x)\)
KNN (w1) count labels among the \(K\) neighbours (Toolkit 2)
Logistic regression (w3) model it directly: \(\sigma(\beta\cdot\tilde x)\) or softmax (Toolkit 8)
LDA (w3) model \(f_k\) as a Gaussian, then Bayes’ rule (Toolkit 7)
Naive Bayes (w3) model \(f_k\) as a product over inputs, then Bayes’ rule
Trees (w4) class proportions in the leaf
Neural network classifier (w4) softmax of the outputs

At \(x_0\), the true class probabilities are \((0.7, 0.2, 0.1)\). What is the Bayes classifier’s error rate at \(x_0\)?

It predicts class 1 (probability 0.7) and is wrong the rest of the time: \(1 - 0.7 = 0.3\).

4. Independence: naive Bayes

Naive Bayes assumes the inputs are independent within each class, so the class density factorises:

\[f_k(x) = f_{k1}(x_1)\times f_{k2}(x_2)\times\dots\times f_{kp}(x_p).\]

Each one-dimensional \(f_{kj}\) is easy to estimate (count, or fit a Gaussian per input). Then Bayes’ rule as before.

Worked example. Spam filter, \(\pi_{\text{spam}} = 0.4\). \(P(\text{"win"}\mid\text{spam}) = 0.5\), \(P(\text{"free"}\mid\text{spam}) = 0.6\); for ham, \(0.1\) and \(0.2\). An email with both words: spam score \(0.4 \times 0.5 \times 0.6 = 0.12\), ham score \(0.6 \times 0.1 \times 0.2 = 0.012\). \(P(\text{spam}\mid x) = 0.12/0.132 = 0.909\).

\(\pi_{\text{spam}} = 0.5\). An email has words \(w_1, w_2\). \(P(w_1\mid\text{spam}) = 0.6\), \(P(w_2\mid\text{spam}) = 0.5\), \(P(w_1\mid\text{ham}) = 0.2\), \(P(w_2\mid\text{ham}) = 0.5\). Using naive Bayes, what is \(P(\text{spam}\mid w_1, w_2)\)?

Spam: \(0.5 \times 0.6 \times 0.5 = 0.15\). Ham: \(0.5 \times 0.2 \times 0.5 = 0.05\). \(0.15/(0.15 + 0.05) = 0.75\).

5. Repeated independent trials

Two more places where “multiply probabilities of independent events” does the work:

The bootstrap (w6). Draw \(n\) times with replacement from \(n\) points. A given point is missed by one draw with probability \(1 - \frac1n\), so it is missed by all \(n\) draws with probability

\[\Big(1 - \frac1n\Big)^n \;\to\; e^{-1} \approx 0.368.\]

About 36.8% of points are out of bag for each tree; that’s what OOB error uses (Toolkit 11).

The binomial sign test (w5). If two algorithms are equally good, each of the \(N\) test points where they disagree goes either way with probability \(\frac12\), so the number \(Y\) won by algorithm A is Binomial\((N, \frac12)\):

\[P(Y = j) = \binom{N}{j}\frac{1}{2^N}, \qquad p\text{-value} = P(Y \ge k).\]

Two classifiers disagree on 10 test points; A is right on 8 of them. Under the null hypothesis (equally good), what is \(P(Y \ge 8)\)?

\(\frac{1}{2^{10}}\big[\binom{10}{8} + \binom{10}{9} + \binom{10}{10}\big] = \frac{45 + 10 + 1}{1024} = \frac{56}{1024} = 0.0547\). Not below 0.05, so not significant at 5% (one-sided).

Stage test

Two classes. At \(x_0\) the true \(P(Y = 1\mid x_0) = 0.25\). What is the Bayes error rate at \(x_0\)?

Bayes predicts class 0 (probability 0.75), so it errs with probability \(1 - 0.75 = 0.25\).

What does “naive” in naive Bayes refer to?

Equal variances is LDA’s assumption. Naive Bayes’s is conditional independence.
