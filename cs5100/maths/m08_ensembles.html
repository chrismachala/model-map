Bagging, random forests and boosting

Week 6 builds on trees with two toolkit ideas. Bagging and forests resample and average, cutting variance by the formula from Toolkit 11. Boosting fits residuals, a squared-error idea, and adds trees slowly with a shrinkage factor.

Built from

A11 bootstrap, OOB, variance of an average · A6 the 36.8% from \((1 - 1/n)^n\) · A2 average (regression) or majority vote (classification) · A10 / A3 the trees inside, grown by impurity or RSS · A3 residuals in boosting · A5 shrinkage \(\eta\), depth \(d\), number of trees \(B\). Full pages: bootstrap and bagging, OOB error, random forests, boosting; week-order stages: 21 and 22.

1. The assembly

Bagging: for \(b = 1..B\), draw a bootstrap sample (A11), grow a deep tree \(\hat f_b\) on it; predict \(\hat f(x) = \frac1B\sum_b\hat f_b(x)\) or the majority vote (A2). Variance \(\rho\sigma^2 + \frac{1 - \rho}{B}\sigma^2\) (A11); bias unchanged.

Random forest: bagging, but each split considers only \(m\) randomly chosen inputs (often \(m \approx \sqrt p\) for classification), lowering \(\rho\).

OOB error: predict each point with only the trees whose bootstrap sample missed it (about 36.8% of them, A6), then average the errors.

Boosting: start with \(\hat f = 0\), \(r_i = y_i\). For \(b = 1..B\): fit a small tree \(\hat f_b\) (depth \(d\)) to the residuals \(r\), then \(\hat f \leftarrow \hat f + \eta\hat f_b\) and \(r_i \leftarrow r_i - \eta\hat f_b(x_i)\). Output \(\sum_b\eta\hat f_b\).

Worked example (week 6 slides). Residuals \(2, 1, 3, 5, 4\); the new tree predicts \(1, 2, 4, 5, 4\); \(\eta = 0.1\). New residuals: \(2 - 0.1, 1 - 0.2, 3 - 0.4, 5 - 0.5, 4 - 0.4 = 1.9, 0.8, 2.6, 4.5, 3.6\). With \(\eta = 1\): \(1, -1, -1, 0, 0\): the tree’s noise is fully absorbed in one step.

Stage test

(4 marks; 2025 Q3a.) Compare bagging and boosting: how each builds its ensemble, and which can overfit as the number of trees grows, with a reason.

Bagging draws \(B\) bootstrap samples, grows a deep tree on each independently, and averages their predictions (or takes a majority vote). Averaging reduces variance and leaves bias unchanged, so adding more trees never makes it overfit; the error simply levels off. Boosting grows small trees one after another: each is fitted to the residuals of the current model and added with a small weight \(\eta\), so the ensemble gradually reduces bias. Because every new tree fits whatever error remains, with enough trees it starts fitting noise, so boosting can overfit and \(B\) (with \(d\) and \(\eta\)) must be chosen by validation.
