Neural networks

The network that looks the most complicated is the one that reuses the most toolkit pieces: dot products, sigmoid or ReLU bends, a linear or softmax output, squared error or cross-entropy, and the chain rule to train it. A one-hidden-layer classifier is multinomial logistic regression on learned features.

Built from

A1 every unit is \(g(w\cdot\tilde x)\) · A8 sigmoid activation, softmax output · A3 squared-error objective (regression) · A9 cross-entropy objective and the \(p - y\) error signal (classification) · A4 gradient descent, chain rule = backpropagation, non-convexity · A5 early stopping, weight decay. Full pages: neural network, classifier, training; week-order stages: 16 and 17.

1. The assembly

\[A_k = \underbrace{g}_{\text{ReLU or A8 }\sigma}\big(\underbrace{w_k\cdot\tilde x}_{\text{A1}}\big),\ k = 1..K;\qquad f(X) = \underbrace{\beta\cdot\tilde A}_{\text{A1 again}}\ \text{(regression)}\quad\text{or}\quad p_m = \underbrace{\text{softmax}_m(f_0, \dots, f_{M-1})}_{\text{A8}}\]

\[\text{objective} = \underbrace{\sum_i(y_i - f(x_i))^2}_{\text{A3}}\quad\text{or}\quad \underbrace{-\sum_i\log p_{y_i}(x_i)}_{\text{A9}},\qquad \text{fitted by A4 gradient descent from random starts.}\]

Parameters (one hidden layer, \(p\) inputs, \(K\) units, \(M\) outputs): \(K(p + 1) + M(K + 1)\).

2. Training: the chain rule

For squared error with error \(e = y - f(x)\), the chain rule (A4) gives

\[\frac{\partial R}{\partial\beta_k} = -2e\,A_k,\qquad \frac{\partial R}{\partial w_{kj}} = -2e\cdot\beta_k\cdot g'(z_k)\cdot x_j.\]

Read right to left: the output error, passed back through \(\beta_k\), through the bend \(g'\) (0 for an “off” ReLU, \(\sigma(1 - \sigma)\) for a sigmoid), times the input. For classification the output error is \(p_m - y_m\) instead (A9). The loss is non-convex, so different random starts can end in different minima; early stopping on validation error controls overfitting (A5).

Stage test

(4 marks; 2025 Q2.) What is a neural network with one hidden layer, and what objective is minimised to train it for (a) regression and (b) classification?

A one-hidden-layer network computes \(K\) features \(A_k = g(w_{k0} + \sum_{j=1}^pw_{kj}X_j)\), where \(g\) is a non-linear activation such as ReLU \(\max(0, z)\) or the sigmoid, and then outputs a linear model in those features, \(f(X) = \beta_0 + \sum_{k=1}^K\beta_kA_k\). For regression the weights are chosen to minimise the squared error \(\sum_i(y_i - f(x_i))^2\). For classification there are \(M\) outputs turned into probabilities by softmax, \(p_m = e^{f_m}/\sum_{m'}e^{f_{m'}}\), and the cross-entropy \(-\sum_i\log p_{y_i}(x_i)\) is minimised. In both cases the objective is non-convex and is minimised by gradient descent from random initial weights, with gradients computed by backpropagation (the chain rule).
