Impurity: error rate, Gini, entropy

How mixed is a bag of labels? Three formulas answer that, all built from the class proportions in the bag. Trees use them to choose splits, pruning and the ensembles of week 6 inherit them, and the exam asks for a calculation with one of them almost every year.

Book and slides

ISLP 8.1.2 (classification trees: classification error rate eq. 8.5, Gini eq. 8.6, entropy eq. 8.7). Read all of 8.1.2. Skip the discussion of qualitative predictors with many levels. Week 4 slides use the same three measures. ISLP uses natural log; some past papers use \(\log_2\); either is fine if you say which.

1. Proportions first

In a node \(m\) with \(n_m\) points, the proportion of class \(k\) is \(\hat p_{mk} = \frac{1}{n_m}\sum_{i\in m}\mathbb 1(y_i = k)\): an average of indicators (Toolkit 2). Every impurity measure is a function of these proportions. All three are 0 for a pure node (one class only) and largest when the classes are equally mixed.

2. The three measures

\[\boxed{E = 1 - \max_k\hat p_{mk}, \qquad G = \sum_k\hat p_{mk}(1 - \hat p_{mk}), \qquad D = -\sum_k\hat p_{mk}\log\hat p_{mk}}\]

  • Error rate \(E\): the fraction misclassified if the node predicts its majority class (Toolkit 2 vote).
  • Gini \(G\): for two classes, \(G = 2p(1 - p)\). Max \(0.5\).
  • Entropy \(D\): for two classes, max \(\log 2 = 0.693\) (or 1 bit with \(\log_2\)). It is the average cross-entropy of predicting the node’s own proportions (Toolkit 9).

Worked example. A node with 6 A and 2 B: \(\hat p = (0.75, 0.25)\). \(E = 0.25\). \(G = 2 \times 0.75 \times 0.25 = 0.375\). \(D = -(0.75\log0.75 + 0.25\log0.25) = 0.216 + 0.347 = 0.562\).

3. Scoring a split: weighted average

A split sends \(n_L\) points left and \(n_R\) right. Its impurity is the size-weighted average of the children, and the gain is how much that beats the parent:

\[\text{gain} = I(\text{parent}) - \Big(\frac{n_L}{n}I(\text{left}) + \frac{n_R}{n}I(\text{right})\Big).\]

With entropy this is the information gain. The tree picks the split with the biggest gain (equivalently the smallest weighted child impurity). It’s exactly the regression tree’s rule with RSS swapped for impurity: the RSS of a split is also a sum over the two children (Toolkit 3).

Worked example. Parent 4 A, 4 B (\(G = 0.5\)). Split: left 3 A, 0 B (\(G = 0\)); right 1 A, 4 B (\(G = 2 \times 0.2 \times 0.8 = 0.32\)). Weighted: \(\frac38 \times 0 + \frac58 \times 0.32 = 0.2\). Gain \(= 0.5 - 0.2 = 0.3\).

4. Why grow with Gini or entropy, but prune with error?

The error rate only looks at the majority class, so it often can’t tell two splits apart: a split that makes one child much purer without changing either child’s majority gets zero gain. Gini and entropy are smooth and reward any increase in purity, so they grow better trees. When pruning, the goal is prediction accuracy, so the error rate is the natural choice (ISLP 8.1.2).

Parent: 400 A, 400 B. Split 1 gives children (300 A, 100 B) and (100 A, 300 B). Split 2 gives (200 A, 400 B) and (200 A, 0 B). Both have weighted error rate 0.25. Which split does the Gini index prefer?

Split 1: both children have \(G = 2 \times 0.75 \times 0.25 = 0.375\), weighted \(0.375\). Split 2: the first child has \(G = 2 \times \frac13 \times \frac23 = 0.444\) with weight \(\frac{600}{800}\), the second is pure: weighted \(0.75 \times 0.444 = 0.333\). Lower is better, so Gini prefers split 2, which creates a pure node. The error rate can’t see the difference (ISLP 8.1.2’s example).

Stage test

(3 marks, exam format 2; 2025 Q1.) Write the formula of the entropy and of the Gini index of a node in a classification tree, explaining the symbols.

For node \(m\) let \(\hat p_{mk}\) be the fraction of its training points in class \(k\). Entropy: \(D_m = -\sum_{k=1}^{K}\hat p_{mk}\log\hat p_{mk}\). Gini index: \(G_m = \sum_{k=1}^{K}\hat p_{mk}(1 - \hat p_{mk})\). Both are zero when the node contains a single class and largest when the classes are equally represented, so a split is chosen to make the size-weighted impurity of the children as small as possible.

A node contains 2 red and 3 blue points. Compute its Gini index.

\(2 \times 0.4 \times 0.6 = 0.48\).
