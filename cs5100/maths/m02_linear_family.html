Linear, polynomial and ridge regression

Week 2 in one line: a dot product for the prediction, squared error for the loss, derivative equals zero for the fit. Polynomials and steps change only the columns; ridge adds a penalty.

Built from

A1 the score \(\beta\cdot\tilde x\) · A3 RSS, TSS, \(R^2\) · A4 derivative = 0 (normal equations) or gradient descent · A5 the ridge penalty · A7 why squares (Gaussian noise) · A11 choosing degree or \(\lambda\) on validation data. Full pages: linear, polynomial and step, ridge; week-order stages: 5 to 8.

1. The assembly

\[\hat\beta = \arg\min_\beta\ \underbrace{\sum_{i=1}^{n}\big(y_i - \overbrace{\beta\cdot\tilde x_i}^{\text{A1}}\big)^2}_{\text{A3 RSS}}\ +\ \underbrace{\lambda\sum_{j\ge1}\beta_j^2}_{\text{A5, ridge only}}\]

Setting the gradient to zero (A4):

  • \(\lambda = 0\): \(\hat\beta = (\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y\); with one input, \(\hat\beta_1 = S_{xy}/S_{xx}\), \(\hat\beta_0 = \bar y - \hat\beta_1\bar x\).
  • Ridge: \(\hat\beta = (\mathbf X^T\mathbf X + \lambda\mathbf I)^{-1}\mathbf X^T\mathbf y\) (not penalising \(\beta_0\)); with one centred input, \(S_{xy}/(S_{xx} + \lambda)\).

2. New columns, same maths

Polynomial regression uses \(\tilde x = (1, x, x^2, \dots, x^d)\); step functions use indicators \(\mathbb 1(c_k \le x < c_{k+1})\) (A2). The model is non-linear in \(x\) but linear in \(\beta\), so everything in step 1 still applies unchanged. Degree \(d\) (or the number of cuts) is the flexibility knob; a polynomial of degree \(d\) in one input has \(d + 1\) parameters.

3. Scoring

RSS (training), \(R^2 = 1 - \text{RSS}/\text{TSS}\), RSE \(= \sqrt{\text{RSS}/(n - p - 1)}\), and the one that matters for choosing models: validation or test MSE (A3, A11).

Stage test

Polynomial regression \(Y = \beta_0 + \beta_1X + \beta_2X^2 + \epsilon\) is called a linear model because:

“Linear” refers to how \(\beta\) enters, not to the shape in \(X\).

(4 marks; 2024 Q1.) Write a linear regression model with \(\lambda \in \mathbb R^2\), the objective used to fit it, and how ridge regression changes that objective and why.

The model is \(f(X) = \lambda_0 + \lambda_1X\). It is fitted by least squares: choose \(\lambda\) to minimise \(\text{RSS}(\lambda) = \sum_{i=1}^n(y_i - \lambda_0 - \lambda_1x_i)^2\), giving \(\hat\lambda_1 = \sum(x_i - \bar x)(y_i - \bar y)/\sum(x_i - \bar x)^2\) and \(\hat\lambda_0 = \bar y - \hat\lambda_1\bar x\). Ridge regression minimises \(\text{RSS}(\lambda) + \alpha\lambda_1^2\) instead (the intercept is not penalised). The penalty shrinks \(\lambda_1\) towards zero, which reduces variance and overfitting, especially with many or correlated inputs, at the cost of some bias; \(\alpha\) is chosen on a validation set.
