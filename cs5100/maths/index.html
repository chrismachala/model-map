The maths-first path

CS5100 teaches about twenty models, but underneath them sit about eleven pieces of maths that keep coming back. Learn those pieces once (Part A), then meet each model as a new arrangement of pieces you already know (Part B).

Why learn it in this order

You noticed softmax turning up in week 3 and again in week 4. It isn’t a one-off. The same few formulas sit inside model after model:

  • Softmax appears in multinomial logistic regression (week 3), the neural network classifier (week 4), and, hidden, in LDA’s posterior (week 3).
  • Squared error is the RSS of linear regression (week 2), the split rule of regression trees (week 4), the neural network regression loss (week 4), the bias-variance decomposition (week 5), the residuals of boosting (week 6) and the SSE that K-means minimises (week 7).
  • “Take the average of the nearby points” is KNN regression (week 2), a regression tree leaf (week 4), bagging (week 6), the K-means centre update and the density estimate \(k/(nV)\) (week 7).

So Part A teaches each piece once, properly, with a worked example and a table of every place it reappears. Part B then goes model by model and shows which pieces it is built from. Each model stage is short, because most of the work has already been done.

How this path relates to the other one

This is a second route through the same course. The original guided path follows the lectures week by week; this one follows the maths. Progress is saved separately, so you can do both. Every stage links to the full week page in the Model Map when you want more depth. The gating works the same way: pass each checkpoint to open the next step, and pass each stage test (80%, or 70% for the final) to open the next stage. Revision mode at the bottom of this page unlocks everything.
