Derivatives and gradient descent

Every "fit the model" step in the course is "make a loss as small as possible". There are only two ways the course does it: set the derivative to zero and solve (least squares, ridge, the mean), or, when that can't be solved, walk downhill a step at a time (logistic regression, neural networks). The chain rule supplies the derivatives in both cases.

Book and slides

Week 1 slides, “calculus basics” (derivatives, chain rule, gradient); week 2 slides, gradient descent for the linear model; week 4 slides, backpropagation. ISLP 10.7.1 (backpropagation) and 10.7.2 to 10.7.3 (regularisation, SGD). Skip ISLP 10.7’s mentions of momentum, Adam and dropout details beyond the idea; the course uses plain gradient descent and early stopping.

1. Derivative, gradient, chain rule

The derivative \(f'(z)\) is the slope: how much \(f\) changes per unit change in \(z\). With several parameters, the gradient \(\nabla L = (\partial L/\partial\beta_0, \dots, \partial L/\partial\beta_p)\) collects all the slopes. It points uphill, so \(-\nabla L\) points downhill.

The chain rule: if \(L\) depends on \(\beta\) only through \(z\), then

\[\frac{\partial L}{\partial\beta} = \frac{\partial L}{\partial z}\cdot\frac{\partial z}{\partial\beta}.\]

Models in this course are chains: \(\beta \to z = \beta\cdot\tilde x \to p = \sigma(z) \to L\). The last link \(\partial z/\partial\beta = \tilde x\) is always the input vector, which is why every gradient in the course ends “\(\times\ \tilde x_i\)”.

The four derivatives you need again and again:

Function Derivative Used in
\((y - z)^2\) \(-2(y - z)\) all squared-error fits
\(\log z\) \(1/z\) likelihoods (w3, w4)
\(\sigma(z) = 1/(1 + e^{-z})\) \(\sigma(z)(1 - \sigma(z))\) logistic regression, sigmoid neurons
\(\text{ReLU}(z) = \max(0, z)\) \(1\) if \(z > 0\), else \(0\) ReLU neurons (w4)

Compute \(\sigma'(1) = \sigma(1)(1 - \sigma(1))\).

\(\sigma(1) = 1/(1 + e^{-1}) = 0.7311\). So \(\sigma'(1) = 0.7311 \times 0.2689 = 0.1966\).

2. Way one: set the derivative to zero

When the loss is a polynomial in the parameters (squared error with a linear model), setting the gradient to zero gives linear equations you can solve:

  • Simple regression: \(\hat\beta_1 = \frac{\sum(x_i - \bar x)(y_i - \bar y)}{\sum(x_i - \bar x)^2}\), \(\hat\beta_0 = \bar y - \hat\beta_1\bar x\) (w2).
  • Multiple regression: \(\mathbf X^T\mathbf X\hat\beta = \mathbf X^T\mathbf y\), so \(\hat\beta = (\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y\) (w2).
  • Ridge, one centred input: \(\hat\beta = \frac{\sum x_iy_i}{\sum x_i^2 + \lambda}\) (w2).
  • The best constant: \(c = \bar y\) (Toolkit 3).

Worked example. Minimise \(g(\beta) = \sum(y_i - \beta x_i)^2\) for \(x = (1, 2)\), \(y = (2, 3)\). \(g'(\beta) = -2\sum x_i(y_i - \beta x_i) = -2(\sum x_iy_i - \beta\sum x_i^2) = -2(8 - 5\beta)\). Zero at \(\beta = 8/5 = 1.6\).

3. Way two: gradient descent

When \(\beta\) is trapped inside a non-linear function (a sigmoid, a ReLU network), \(\nabla L = 0\) has no algebraic solution. Then repeat:

\[\boxed{\beta^{(t+1)} = \beta^{(t)} - \eta\,\nabla L(\beta^{(t)})}\]

with learning rate \(\eta\). Too small: painfully slow. Too big: overshoots and can diverge. The week 2 lab runs it on the linear model (where you could have used the formula) precisely so you can check it against the exact answer.

4. Convex or not?

A convex loss is bowl-shaped: one minimum, and gradient descent with a small enough \(\eta\) finds it from any start. RSS for linear models and the negative log-likelihood for logistic regression are convex.

A non-convex loss has several valleys, so where you end up depends on where you started:

  • Neural networks (w4): random starting weights, possibly different answers each run.
  • K-means (w7): it alternately (1) assigns points to their nearest centre, (2) moves centres to the means. Each step can only lower the SSE, so it always stops, but often in a local minimum. Hence: several random restarts, keep the lowest SSE. Same cure as for networks.

Why does the week 2 lab ask you to run gradient descent for linear regression from 10 random starting points, and what should you see?

Different answers would mean the step size or number of iterations is wrong, not that the problem has several minima. For a neural network, by contrast, different starts can genuinely end in different places.

5. The gradient that keeps coming back

Here’s a pattern worth spotting now. For one training point:

  • Squared error with a linear model: \(\nabla_\beta(y - \beta\cdot\tilde x)^2 = -2(y - \hat y)\,\tilde x\).
  • Cross-entropy with logistic regression: \(\nabla_\beta L = -(y - p)\,\tilde x\) (Toolkit 9).
  • Cross-entropy with softmax, per output score: \(p_m - y_m\) (Toolkit 9, w4).

Each time: (prediction − truth) × input. A badly predicted point pushes hard in the direction of its own input; a well-predicted one barely moves anything. Backpropagation (w4) is this, passed backwards through the layers with the chain rule.

Squared-error loss \((y - \beta_0 - \beta_1x)^2\) on one point \(x = 1\), \(y = 2\), starting at \(\beta = (0, 0)\). Using \(\nabla = -2(y - \hat y)\tilde x\) and \(\eta = 0.025\), what is \(\beta_1\) after one step?

\(\hat y = 0\), so \(\nabla = -2(2)(1, 1) = (-4, -4)\). \(\beta \leftarrow (0, 0) - 0.025(-4, -4) = (0.1, 0.1)\).

Stage test

What is the derivative of \(\text{ReLU}(z) = \max(0, z)\) at \(z = -2\)?

For \(z < 0\) the function is flat at 0, so its slope is \(0\). That’s why a ReLU unit that is “off” passes no gradient back in backpropagation.

Which of these models are fitted by gradient descent in the course because no closed-form solution exists?

Linear and ridge regression have closed forms (gradient descent is optional); KNN has nothing to fit.

Which statements are true? Tick all that apply.

The logistic NLL is convex. The last statement holds because \(\partial(\beta\cdot\tilde x)/\partial\beta = \tilde x\).
