LDA and naive Bayes

The generative route: describe how each class's inputs are spread, then flip it with Bayes' rule. LDA uses one Gaussian per class with a shared variance; naive Bayes multiplies one-input densities. LDA's answer comes out as a softmax of linear scores, the same form as logistic regression, found a different way.

Built from

A6 Bayes’ rule, priors, independence · A7 the Gaussian, and its log as a squared distance · A8 softmax (the posterior’s form) · A2 estimates as averages and counts · A9 those estimates are maximum likelihood. Full pages: LDA, naive Bayes; week-order stage: 11.

1. The assembly

\[P(Y = k\mid x) = \underbrace{\frac{\pi_kf_k(x)}{\sum_l\pi_lf_l(x)}}_{\text{A6}} = \underbrace{\frac{e^{\delta_k(x)}}{\sum_le^{\delta_l(x)}}}_{\text{A8 softmax}},\qquad \underbrace{\delta_k(x) = \frac{x\mu_k}{\sigma^2} - \frac{\mu_k^2}{2\sigma^2} + \log\pi_k}_{\text{A7: log of a Gaussian, } x^2 \text{ cancelled}}\]

Estimates (A2, A9): \(\hat\pi_k = n_k/n\), \(\hat\mu_k\) = mean of class \(k\), \(\hat\sigma^2 = \frac{1}{n - m}\sum_k\sum_{i\in k}(x_i - \hat\mu_k)^2\). Predict \(\arg\max_k\delta_k(x)\). Two classes: boundary at \(x^* = \frac{\mu_0 + \mu_1}{2} + \frac{\sigma^2}{\mu_1 - \mu_0}\log\frac{\pi_0}{\pi_1}\).

Naive Bayes replaces \(f_k\) by a product over inputs, \(f_k(x) = \prod_jf_{kj}(x_j)\) (A6 independence), each estimated separately (counts, or a Gaussian per input).

2. LDA vs logistic regression

Both end with \(P(Y = k\mid x)\) as a softmax (two classes: a sigmoid) of a linear function of \(x\). Logistic regression fits that function directly by maximum likelihood of \(P(Y\mid X)\). LDA gets it from the class means, shared variance and priors. LDA is more stable when the classes are well separated or \(n\) is small, and its Gaussian assumption helps if it’s roughly true; logistic regression assumes less.

With equal priors and one input, where is LDA’s boundary between classes with means \(\mu_0 < \mu_1\)?

The \(\log\frac{\pi_0}{\pi_1}\) term is 0, leaving the midpoint. Unequal priors shift it towards the rarer class’s mean.

Stage test

Naive Bayes, two classes with \(\pi_A = 0.5\). For an email \(x = (x_1, x_2)\): \(f_{A1}(x_1) = 0.6\), \(f_{A2}(x_2) = 0.3\), \(f_{B1}(x_1) = 0.1\), \(f_{B2}(x_2) = 0.2\). Compute \(P(A\mid x)\).

A: \(0.5 \times 0.6 \times 0.3 = 0.09\). B: \(0.5 \times 0.1 \times 0.2 = 0.01\). \(0.09/0.10 = 0.9\).

Which statement about LDA’s posterior is correct?

\(\pi_kf_k(x) \propto e^{\delta_k(x)}\) after dropping class-independent factors.
