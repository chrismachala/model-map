Logistic and multinomial regression

Week 3's main model has no new maths at all. It's a dot product, pushed through a sigmoid (or softmax), scored with cross-entropy, and fitted by gradient descent. If Part A is solid, this stage is assembly.

Built from

A1 the score \(z = \beta\cdot\tilde x\) · A8 sigmoid / softmax, odds and log-odds · A9 likelihood and cross-entropy, gradient \((p - y)\tilde x\) · A4 gradient descent (no closed form) · A5 the lab’s \(L_2\) penalty. Full page: logistic regression; week-order stages: 9 and 10.

1. The assembly

\[\underbrace{p(x) = \sigma}_{\text{A8}}\big(\underbrace{\beta\cdot\tilde x}_{\text{A1}}\big),\qquad \hat\beta = \arg\min_\beta\ \underbrace{-\sum_i\big[y_i\log p_i + (1 - y_i)\log(1 - p_i)\big]}_{\text{A9}}\ \big(+\ \underbrace{\lambda\|\beta\|^2}_{\text{A5}}\big)\]

fitted by \(\beta \leftarrow \beta - \eta\sum_i(p_i - y_i)\tilde x_i\) (A4, A9).

Multinomial: one score per class, \(z_k = \beta_k\cdot\tilde x\), \(p_k = \text{softmax}_k(z)\), loss \(-\sum_i\log p_{y_i}(x_i)\); \((p + 1)\times m\) coefficients.

Reading it: \(\log\frac{p}{1 - p} = \beta\cdot\tilde x\), so \(e^{\beta_j}\) is the odds multiplier per unit of \(x_j\). Predict class 1 when \(p > 0.5\), i.e. when \(\beta\cdot\tilde x > 0\): a linear boundary.

2. What’s specific to logistic regression

  • No closed form: \(\beta\) is inside the sigmoid, so \(\sum(p_i - y_i)\tilde x_i = 0\) can’t be solved algebraically. The NLL is convex, though, so gradient descent finds the single minimum.
  • Separable data: if a line splits the classes perfectly, the NLL keeps falling as \(\|\beta\|\) grows, so \(\beta\) runs off to infinity. The \(L_2\) penalty in lab Q2 stops it.
  • Lab bug: grad_log_likelihood sums with np.sum(...) and no axis=0, returning a scalar, so every coefficient gets the same update.

Stage test

Multinomial logistic regression with \(m = 3\) classes and \(p = 4\) inputs: how many coefficients?

\((p + 1)\times m = 5 \times 3 = 15\).
