Squared error: MSE, RSS, SSE and friends

Take each error, square it, add them up. The course gives this sum at least seven names (RSS, MSE, TSS, SSE, RSS(T), the NN loss, the bias-variance decomposition), but it is one formula. Learn it once, plus one fact: the mean is the number that makes it smallest.

Book and slides

ISLP 2.2.1 (MSE), 3.1.1 to 3.1.3 (RSS, TSS, \(R^2\), RSE), 2.2.2 (the bias-variance trade-off, eq. 2.7). Skip in 3.1.2 the standard errors, confidence intervals, t-statistics and p-values: the course doesn’t test them. The decomposition is in the week 5 slides (I. Rungger) with the course’s notation.

1. One formula, many names

For true values \(y_i\) and predictions \(\hat y_i\), the residual is \(e_i = y_i - \hat y_i\) and

\[\boxed{\text{RSS} = \sum_{i=1}^{n}(y_i - \hat y_i)^2, \qquad \text{MSE} = \frac1n\,\text{RSS}}\]

Name What it is Where
MSE RSS divided by \(n\) w1 accuracy, test MSE everywhere
RSS the sum itself linear regression (w2)
TSS RSS of the “always predict \(\bar y\)” model: \(\sum(y_i - \bar y)^2\) \(R^2 = 1 - \text{RSS}/\text{TSS}\) (w2)
RSE \(\sqrt{\text{RSS}/(n - p - 1)}\) w2
\(\text{RSS}(T)\) RSS added over the leaves of a tree regression trees (w4)
\(R(\theta)\) the NN regression objective neural networks (w4)
\(J_{SSE}\) \(\sum_j\sum_{x\in\omega_j}\|x - \mu_j\|^2\) K-means (w7)

The K-means version uses vectors, but \(\|x - \mu\|^2 = \sum_d(x_d - \mu_d)^2\) is still a sum of squared gaps (Toolkit 1).

2. Why squares?

Squaring makes every error positive (so overshoots and undershoots don’t cancel), punishes big errors far more than small ones, and is smooth, so you can differentiate it (Toolkit 4). It also has a probability story: least squares is exactly maximum likelihood when the noise is Gaussian (Toolkits 7 and 9).

3. The mean minimises squared error

Fact. For numbers \(y_1, \dots, y_n\), the constant \(c\) that minimises \(\sum_i(y_i - c)^2\) is \(c = \bar y\).

Proof. Differentiate: \(\frac{d}{dc}\sum(y_i - c)^2 = -2\sum(y_i - c) = -2(n\bar y - nc)\). This is zero when \(c = \bar y\), and the second derivative \(2n > 0\) says it’s a minimum.

This one fact explains a lot:

  • A regression tree predicts the mean of each leaf, because that minimises the leaf’s RSS (w4).
  • K-means moves each centre to the mean of its points, because that minimises the SSE (w7).
  • TSS is the RSS of the best constant model, which is why \(R^2\) compares against it (w2).
  • Linear regression’s intercept makes the residuals sum to zero for the same reason.

Worked example. Leaf responses \(2, 4, 9\). Mean \(5\): RSS \(= 9 + 1 + 16 = 26\). Try the median \(4\) instead: \(4 + 0 + 25 = 29\). Bigger, as promised.

A tree leaf contains \(y = 1, 3, 4, 8\). What is the smallest RSS any single prediction for this leaf can achieve?

Predict the mean, \((1 + 3 + 4 + 8)/4 = 4\). RSS \(= (1 - 4)^2 + (3 - 4)^2 + (4 - 4)^2 + (8 - 4)^2 = 9 + 1 + 0 + 16 = 26\).

4. RSS, TSS and \(R^2\)

\(R^2 = 1 - \text{RSS}/\text{TSS}\) says what fraction of the spread in \(y\) the model explains. 0 means no better than predicting \(\bar y\); 1 means a perfect fit on these points.

5. The bias-variance decomposition

The week 5 result: for a fixed input \(x_0\), averaging over training sets,

\[\mathbb E\big(\hat f(x_0) - Y\big)^2 = \underbrace{\big(\mathbb E\hat f(x_0) - f(x_0)\big)^2}_{\text{bias}^2} + \underbrace{\mathrm{Var}\,\hat f(x_0)}_{\text{variance}} + \underbrace{\sigma^2}_{\text{noise}}.\]

It is a statement about expected squared error, so it only exists because the course measures error with squares. It’s the reason the test-error curve is U-shaped and why every model has a flexibility knob (Toolkit 5).

Worked example. Over many training sets a model’s predictions at \(x_0\) are \(4, 6, 5, 5\), the true \(f(x_0) = 6\) and \(\sigma^2 = 1\). Average prediction \(5\), so bias\(^2 = (5 - 6)^2 = 1\); variance \(= \frac14(1 + 1 + 0 + 0) = 0.5\); expected test MSE \(= 1 + 0.5 + 1 = 2.5\).

At \(x_0\), a model’s predictions over training sets are \(2, 4, 3, 3\). The truth is \(f(x_0) = 4.5\) and the noise variance is \(\sigma^2 = 0.5\). Compute bias² + variance + noise.

Mean prediction \(3\). Bias\(^2 = (3 - 4.5)^2 = 2.25\). Variance \(= \frac14(1 + 1 + 0 + 0) = 0.5\). Total \(2.25 + 0.5 + 0.5 = 3.25\).

Stage test

Which single number \(c\) minimises \((1 - c)^2 + (2 - c)^2 + (3 - c)^2\)?

The mean of \(1, 2, 3\), which is \(2\).

(3 marks, exam format 2; 2024 Q1.) Write the formula for the RSS of a linear regression model \(f(X) = \lambda_0 + \lambda_1X\) on data \(\{(x_i, y_i)\}_{i=1}^n\), and say what is done with it.

\(\text{RSS}(\lambda_0, \lambda_1) = \sum_{i=1}^{n}\big(y_i - (\lambda_0 + \lambda_1x_i)\big)^2\): the sum, over training points, of the squared differences between the observed \(y_i\) and the model’s prediction. Least squares picks the \(\lambda\) that minimises it, either in closed form (set both partial derivatives to zero) or by gradient descent. It measures training fit only; a flexible model can make it small while the test error is large.

Why does a regression tree predict the mean of the responses in each leaf?

\(\frac{d}{dc}\sum(y_i - c)^2 = 0\) gives \(c = \bar y\). The same reason makes K-means use means.
