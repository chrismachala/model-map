Vectors, dot products and distances

Two operations on lists of numbers do a huge amount of work in this course. The dot product builds the "score" inside every linear model and every neuron. The distance decides who your neighbours are in KNN, K-means and hierarchical clustering.

Book and slides

Week 1 slides, “Linear algebra and calculus basics” (vectors, dot product, orthogonality); week 7 slides, “Definition of metric” and the Minkowski / Manhattan distances. ISLP has no chapter for this: it assumes it. Read ISLP 2.2.3 for the Euclidean distance in KNN and 12.4.1 for distances in K-means. Skip the matrix-algebra details of ISLP 3.2 beyond \(\mathbf X\beta\) for now; the multiple regression stage uses them.

1. A vector is one data point

An observation with \(p\) inputs is a vector \(x = (x_1, x_2, \dots, x_p)\). Stack \(n\) of them as rows and you get the data matrix \(\mathbf X\) (\(n \times p\)). Models add a 1 at the front, \(\tilde x = (1, x_1, \dots, x_p)\), so the intercept can be written like any other coefficient.

The dot product of two vectors of the same length multiplies matching entries and adds:

\[a\cdot b = a^Tb = a_1b_1 + a_2b_2 + \dots + a_pb_p.\]

Two vectors are orthogonal (at right angles) exactly when \(a\cdot b = 0\). The length of a vector is \(\|a\|_2 = \sqrt{a\cdot a}\).

Worked example. \(a = (1, 2, -1)\), \(b = (3, 0, 3)\). \(a\cdot b = 3 + 0 - 3 = 0\), so they are orthogonal. \(\|a\|_2 = \sqrt{1 + 4 + 1} = \sqrt6\).

2. The score inside every model is a dot product

Write the parameters as a vector \(\beta = (\beta_0, \beta_1, \dots, \beta_p)\). Then

\[\boxed{z = \beta\cdot\tilde x = \beta_0 + \beta_1x_1 + \dots + \beta_px_p}\]

is the linear score. Learn to spot it, because the course keeps feeding it into different functions:

Model What happens to the score \(z = \beta\cdot\tilde x\)
Linear regression (w2) nothing: \(\hat y = z\)
Polynomial / step regression (w2) same, but \(\tilde x\) holds new columns like \(x^2\) or \(\mathbb 1(x < c)\)
Logistic regression (w3) squashed: \(p = \sigma(z)\)
Multinomial logistic (w3) one score per class, then softmax
LDA (w3) the discriminant \(\delta_k(x)\) is linear in \(x\): a dot product plus a constant
Neuron in a network (w4) bent: \(A_k = g(w_k\cdot\tilde x)\) with ReLU or sigmoid \(g\)

All of the data at once: \(\mathbf X\beta\) is the vector of all \(n\) scores.

\(\beta = (0.5, 2, -1)\) and \(x = (3, 1)\). Compute the score \(z = \beta\cdot\tilde x\).

\(\tilde x = (1, 3, 1)\), so \(z = 0.5 \times 1 + 2 \times 3 + (-1) \times 1 = 5.5\). Don’t forget the 1 in front that multiplies the intercept.

3. Distances

A distance (metric) \(d(x, y)\) must satisfy four rules from the week 7 slides: \(d \ge 0\); \(d(x, y) = 0\) only if \(x = y\); \(d(x, y) = d(y, x)\); and the triangle inequality \(d(x, z) \le d(x, y) + d(y, z)\).

The family the course uses is the Minkowski (\(L_k\)) distance:

\[\boxed{\|x - y\|_k = \Big(\sum_{i=1}^{p}\lvert x_i - y_i\rvert^k\Big)^{1/k}}\]

  • \(k = 2\): Euclidean, \(\sqrt{\sum(x_i - y_i)^2}\). The default in KNN (w1, 2023 Q2), K-means (w7) and the linkage examples (w7).
  • \(k = 1\): Manhattan (city block), \(\sum\lvert x_i - y_i\rvert\).
  • \(k \to \infty\): the maximum gap, \(\max_i\lvert x_i - y_i\rvert\).

The squared Euclidean distance \(\|x - y\|_2^2 = \sum(x_i - y_i)^2\) is a sum of squares: the same shape as RSS (Toolkit 3). That’s why K-means and least squares end up so alike.

Worked example. \(x = (1, 4)\), \(y = (4, 0)\). Gaps \(3, 4\). \(L_1 = 7\), \(L_2 = \sqrt{9 + 16} = 5\), \(L_\infty = 4\).

4. Scale matters

Distances add up gaps in different units. If one input is income in pounds and another is age in years, income dominates every distance and KNN effectively ignores age. The week 2 lab’s normalize() fixes this by rescaling each column (subtract the mean, divide by the standard deviation) before running KNN. The same issue hits K-means and the ridge penalty (Toolkit 5), which also adds up coefficients across inputs.

You run KNN on houses with inputs “floor area in m²” (values 40 to 300) and “number of bathrooms” (1 to 4) without rescaling. What happens?

A gap of 50 m² contributes \(2500\) to the squared distance; a gap of 2 bathrooms contributes \(4\). Standardise the columns first.

Stage test

(3 marks, exam format 2; 2023 Q2.) Write the formula for a distance measure KNN could use in \(\mathbb R^n\), showing the dependence on each coordinate, and name one alternative.

Euclidean distance: \(d(x, x') = \sqrt{\sum_{i=1}^{n}(x_i - x'_i)^2}\), where \(x_i\) and \(x'_i\) are the \(i\)-th coordinates of the two points. An alternative is the Manhattan distance \(\sum_{i=1}^{n}\lvert x_i - x'_i\rvert\); both are Minkowski distances \(\big(\sum_i\lvert x_i - x'_i\rvert^k\big)^{1/k}\) with \(k = 2\) and \(k = 1\). Because each coordinate’s gap is added, inputs should be standardised first, otherwise the input with the largest units dominates.

Which of these contain a dot product \(\beta\cdot\tilde x\) (or \(w\cdot\tilde x\))? Tick all that apply.

Gini is computed from class proportions and a bootstrap sample is a resampling of rows; neither has a weighted sum of inputs.
