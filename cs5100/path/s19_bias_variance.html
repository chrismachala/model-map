Bias, variance and regularisation

Week 5 opens the second half. A model is judged on data it hasn't seen, and its expected test error splits into bias², variance and noise. Every flexibility knob in the course trades the first two; regularisation is a dial for doing it on purpose.

Book: what to read for this stage

ISLP 2.2.1–2.2.2 (training vs test MSE, eq. 2.7, Figs 2.9 and 2.12): read. 5.1.1 (validation set): read. 5.1.2–5.1.5 (cross-validation): skim, not on the slides. Re-read 6.2.1 (ridge) and 8.1.1 (pruning). The slides cite ESL, Bishop and Mitchell; you don’t need them.

1. Training error is optimistic

The model was tuned to the training data, so its error there is too rosy: 1-NN and a fully grown tree score 0. What matters is the error on new data from the same distribution (training and test examples are i.i.d.).

Plot error against flexibility: training error only falls; test error falls then rises, a U. The bottom of the U is the model you want. You can’t pick it on the test set (then the test error is optimistic too), so hold out a validation set, choose there, and touch the test set once.

training error test error
underfitting high high
overfitting very low much higher

A model has training MSE 0.2 and test MSE 9.5. A simpler model has 3.1 and 3.6. What is happening to the first?

A tiny training error with a much larger test error is the signature of overfitting (high variance).

2. The decomposition

With \(Y = f_{true}(X) + \mathcal E\) and the average taken over training sets and test noise: \[\mathbb E\big(\hat f(x_0) - Y\big)^2 = \underbrace{\big(\mathbb E\hat f(x_0) - f_{true}(x_0)\big)^2}_{\text{bias}^2} + \underbrace{\mathrm{Var}\,\hat f(x_0)}_{\text{variance}} + \underbrace{\mathrm{Var}\,\mathcal E}_{\text{noise}}.\]

More flexibility: bias down, variance up. Their sum is the U.

Worked example. \(f_{true}(x_0) = 5\), noise variance 1. Over training sets the model predicts 2, 4 or 6, equally often. Mean 4: bias² \(= 1\). Variance \(= (4 + 0 + 4)/3 = 2.67\). Expected test error \(= 1 + 2.67 + 1 = 4.67\).

\(f_{true}(x_0) = 10\), noise variance 2. Over four training sets the model predicts 8, 12, 10 and 14 at \(x_0\). What is the expected test error at \(x_0\)?

Mean \(11\): bias² \(= 1\). Deviations \(-3, 1, -1, 3\): variance \(= (9 + 1 + 1 + 9)/4 = 5\). Total \(1 + 5 + 2 = 8\).

In KNN, increasing \(K\) from 1 to 50 makes the model…

KNN runs backwards: flexibility falls as \(K\) grows. \(K = 1\) has training error 0 and the most variance.

3. Regularisation: fit + α × complexity

model objective more \(\alpha\)
tree (pruning) \(\mathrm{RSS}(T) + \alpha\lvert T\rvert\) fewer leaves
linear (ridge) \(\mathrm{RSS}(\lambda) + \alpha\sum_{i \ge 1}\lambda_i^2\) smaller coefficients

More \(\alpha\): a little more bias, much less variance. Choose \(\alpha\) on validation data, then refit on training + validation. (Slide 25 penalises the intercept too; the usual choice, and ISLP’s, doesn’t.)

One coefficient, no intercept: minimise \(\sum(y_n - \lambda x_n)^2 + \alpha\lambda^2\), so \(\hat\lambda = \frac{\sum x_ny_n}{\sum x_n^2 + \alpha}\). With \(x = (1, 2, 3)\), \(y = (2, 4, 7)\) and \(\alpha = 17\), what is \(\hat\lambda\)?

\(\sum x_ny_n = 2 + 8 + 21 = 31\), \(\sum x_n^2 = 14\). \(\hat\lambda = 31/(14 + 17) = 1\). Without the penalty it would be \(31/14 = 2.21\).

Stage test

(4 marks) State the bias-variance decomposition of the expected test error at \(x_0\) and explain each term.

\(\mathbb E(\hat f(x_0) - Y)^2 = (\mathbb E\hat f(x_0) - f_{true}(x_0))^2 + \mathrm{Var}\,\hat f(x_0) + \mathrm{Var}\,\mathcal E\), the expectation taken over random training sets and the noise in the test label. The bias² measures how far the average model is from the truth (rigid models are systematically wrong); the variance measures how much the fitted model moves when the training set changes (flexible models chase the noise); the last term is the noise in \(Y\), which no model can remove.

Truth \(f_{true}(x_0) = 6\), noise variance 0.5. Over training sets the model predicts 3, 5 or 7 at \(x_0\), equally often. Expected test error at \(x_0\)?

Mean 5: bias² \(= 1\). Variance \(= (4 + 0 + 4)/3 = 2.667\). Total \(1 + 2.667 + 0.5 = 4.167\).

Why must the regularisation strength \(\alpha\) be chosen on a validation set and not on the training set?

Only data the model hasn’t been fitted to can show when extra flexibility starts to hurt.

Tick every change that usually lowers variance.

Less flexibility or more data both steady the fitted model.
