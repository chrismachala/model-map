Comparing two algorithms

Algorithm 1 makes fewer test errors than Algorithm 0. Real or luck? Keep only the test cases where they disagree, treat each one as a coin flip, and ask how surprising the score would be if neither were better.

Book: what to read for this stage

ISLP 13.1 A quick review of hypothesis testing (p558–563): read for null hypotheses, p-values, Type I and II errors (it uses a t-test; the slides use a binomial test). The slides’ binomial sign test itself isn’t in ISLP: this stage covers it. 13.2–13.5 (multiple testing) aren’t on this year’s slides, but the 2024 paper had a big question on them: ask the lecturer.

1. Keep only the disagreements

Alg 1 correct Alg 1 wrong
Alg 0 correct 189 9
Alg 0 wrong 17 23

Alg 0 errs \((17 + 23)/238 = 16.8\%\), Alg 1 \((9 + 23)/238 = 13.4\%\). Cases where both are right or both wrong say nothing about which is better. That leaves \(N = 9 + 17 = 26\) disagreements, and Alg 1 wins \(k = 17\).

On 200 test cases: both right 150, only A right 10, only B right 25, both wrong 15. What is B’s error rate, in percent?

B is wrong when only A is right or both are wrong: \((10 + 15)/200 = 12.5\%\).

2. The null hypothesis and the p-value

\(H_0\): “Alg 1 is not better than Alg 0”. If they’re equally good, each disagreement is a fair coin flip, so the number of wins \(Y \sim \text{Binomial}(N, \frac12)\). (If Alg 1 were worse, 17 wins would be even less likely, so the fair coin is the worst case.)

\[p = P(Y \ge k) = \sum_{j=k}^N\binom Nj\frac1{2^N}.\]

Reject \(H_0\) when \(p \le \epsilon\) (5% or 1%, fixed beforehand). For 17 of 26, \(p = 0.0843\): can’t reject at 5%.

\(N = 10\), \(k = 9\): \(p = \frac{\binom{10}{9} + \binom{10}{10}}{1024} = \frac{11}{1024} = 0.0107\). Reject at 5%, not at 1%.

\(N = 8\) disagreements; Algorithm 1 wins 7. Compute the one-sided p-value.

\(\frac{\binom87 + \binom88}{2^8} = \frac{8 + 1}{256} = 0.0352\). Reject at 5%, not at 1%.

3. Reading it right

  • “Can’t reject” is not “they’re equal”: just not enough evidence.
  • The p-value is \(P(\text{data at least this extreme} \mid H_0)\), not \(P(H_0 \mid \text{data})\).
  • Same win rate, more data: smaller p (34 of 52 gives 0.018).
  • A Type I error is rejecting a true \(H_0\); testing at level \(\epsilon\) keeps its probability \(\le \epsilon\).

A test gives \(p = 0.03\). Which statement is correct?

A p-value is a probability about the data, computed assuming \(H_0\).

Stage test

(4 marks) Explain why the binomial test for comparing two classifiers ignores the test cases where both are right or both are wrong, and why under \(H_0\) the number of wins is \(\text{Binomial}(N, \frac12)\).

When both classifiers are right, or both wrong, the case says nothing about which is better, so only the \(N\) disagreements matter. If the two were equally good, each disagreement would be equally likely to be won by either, independently across the i.i.d. test cases, so the number \(Y\) won by Algorithm 1 is \(\text{Binomial}(N, \frac12)\); the p-value is \(P(Y \ge k)\) for the observed \(k\).

With \(\epsilon = 5\%\) you get \(p = 0.084\). The right conclusion is:

Failing to reject only means there isn’t enough evidence.

All 8 disagreements go to Algorithm 1. p-value?

\(1/2^8 = 1/256 = 0.0039\). Reject even at 1%.
