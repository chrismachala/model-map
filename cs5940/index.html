The pattern behind the module

The CS5940 lectures teach architectures: ways of building the inside of an agent. Every one of them is an answer to the same few questions from week 1: what can it observe, what does it remember, what is its goal, how does it decide, what can it do?

  • A deliberative agent keeps an explicit model of the world and reasons about it: prove what to do, commit to intentions, plan.
  • A reactive agent skips the reasoning and maps what it senses straight to an action, by priority.
  • A hybrid agent stacks both in layers.
  • A learning agent (week 4) works out what to do from rewards, by planning over a known model or by trial and error.
  • The practicals build an LLM-based agent from scratch, one layer of scaffold at a time.

And the same tension runs through all of them: react in time to a changing world, or pursue goals systematically? Each architecture strikes a different balance.

How the weeks build on each other

  1. Week 1 sets the stage: what counts as an agent, why delegating to one is risky, how to describe its environment, and the maths of runs and utility. The practical shows that an LLM on its own remembers nothing.
  2. Week 2 builds the first real architectures, all symbolic: prove what to do (deductive), follow ordered rules towards a goal (teleo-reactive), program in beliefs and commitments (Agent0), and BDI with STRIPS planning. The practical adds budgets, settings and a trimmed memory.
  3. Week 3 asks what happens when the world changes while the agent is thinking. BDI answers with commitment and controlled reconsideration, and gets a language (AgentSpeak). Brooks answers by not thinking at all (subsumption). Hybrids do both, in layers.
  4. Week 4 makes “choosing well” mathematical. An MDP describes a world with random outcomes and rewards; the value of a state counts everything that might follow. With a known model the agent can plan (value iteration); without one it can learn (Q-learning), as long as it explores. Then the assumptions break: the agent can’t see the state (POMDPs and beliefs), or the reward isn’t what we meant (reward hacking).

How to use these pages

  • Read the green “why this exists” box first on every page. That’s the context the lectures skip.
  • Purple boxes are plain-English word lists. Yellow boxes are worked examples to copy out by hand. Red boxes flag slide typos and points the slides compress.
  • Turn on Try-first (top bar) to hide every worked example until you’ve had a go on paper.
  • Press Mark as understood on each technique. Your progress shows in the sidebar, on these tiles and on the module picker (saved in this browser only).
  • Play with the interactive demos: step the vacuum and corridor robots, stack blocks with STRIPS, run an AgentSpeak trace, pit bold against cautious agents, run value iteration on the gridworld, train a Q-learner, and more.
  • Each page ends with a practice prompt. Click “Copy prompt” and paste it into any AI chat to get questions one at a time, with model answers after you reply.
  • Each page says which parts of Wooldridge are on the slides and which you can skip. In the scanned PDF, add 21 to the book’s page number.
