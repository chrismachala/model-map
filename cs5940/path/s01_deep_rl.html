Deep reinforcement learning

Week 5 Part A in quiz form: why tables fail, what DQN learns, the two stabilising tricks, and the vocabulary (value vs policy, actor–critic, model-free vs model-based) that quiz distractors are built from.

Full notes: Deep reinforcement learning.

1. From tables to networks

A Q-table stores one number per (state, action) and learns nothing about states it hasn’t visited. With pixel observations the table is impossibly large and there’s no reuse between similar states. Deep RL replaces the lookup with \(Q_\theta(s, a)\): a network whose shared weights give estimates for unseen states too. That’s generalisation, which is not a guarantee of correctness.

DQN feeds the network four recent frames because one frame can’t show which way the ball is moving: a single observation needn’t reveal the full state (partial observability).

Why does DQN use the four most recent frames as its input, rather than one?

Same pixels, ball moving left or right: different underlying states. A short history helps infer motion (partial observability from week 4). It isn’t a physics model: DQN is model-free.

2. The DQN target

\[y = \begin{cases} r & \text{episode ends} \\ r + \gamma \max_{a'} Q_{\theta^-}(s', a') & \text{otherwise}\end{cases} \qquad L(\theta) \approx \tfrac{1}{N}\textstyle\sum (y_i - Q_\theta(s_i, a_i))^2\]

Reward now plus discounted best value later, computed with the frozen target network \(\theta^-\); the online network \(\theta\) is trained to predict it.

\(\gamma = 0.9\). A replayed transition has reward \(r = 1\) and does not end the episode. The target network gives \(Q_{\theta^-}(s', \cdot) = (2, 5, 3)\). What is the DQN target \(y\)?

\(y = 1 + 0.9 \times \max(2, 5, 3) = 1 + 4.5 = 5.5\).

3. Replay and the target network

Problem Fix
consecutive frames are highly correlated experience replay: store \((s, a, r, s', \text{done})\), train on random mini-batches
the network moves its own targets (moving targets) target network \(Q_{\theta^-}\): frozen copy for targets, refreshed periodically

Both improve stability; neither guarantees convergence.

4. Value, policy, actor–critic, model-based

  • Value-based (DQN): learn \(Q_\theta(s, a)\), act by argmax. Suits small discrete action sets.
  • Policy-based: learn \(\pi_\theta(a \mid s)\), sample actions. Suits stochastic policies and continuous control.
  • Actor–critic: actor = policy that acts; critic = value estimate \(V_w(s)\) that helps train the actor. The critic isn’t needed at deployment.
  • Model-free learns values/policies directly; model-based plans with known (AlphaZero: the game rules) or learned (MuZero) dynamics. AlphaGo used human games + self-play + MCTS; AlphaZero dropped the human games.

In an actor–critic method, what is the critic for?

Actor acts; critic estimates \(V_w(s)\) as a training aid. Replay buffers and transition models are other things.

Stage test

A robot must learn to control the continuous torque on each of its six joints. Which approach fits best?

Continuous actions: you can’t argmax over infinitely many torques, and a table can’t cover continuous states. Policy-based methods output a distribution over continuous actions. Value iteration needs a known model.

Which statement about function approximation \(Q_\theta(s, a)\) is correct?

Shared weights generalise, but generalisation is not correctness. One parameter per pair would just be a table.

DQN stores transitions in a buffer and trains on random mini-batches drawn from it. Which problem does this mainly address?

That’s experience replay, the fix for correlated samples. Moving targets → target network; partial observability → frame stacking.

\(\gamma = 0.9\). A transition has \(r = 1\) and ends the episode. The target network gives \(Q_{\theta^-}(s', \cdot) = (2, 5, 3)\). What is the DQN target?

At the end of an episode the target is just the reward: \(y = 1\).

Continuing: the target is \(y = 5.5\) and the online network predicts \(Q_\theta(s, a) = 4\). What is this sample’s squared error \((y - Q_\theta(s,a))^2\)?

\((5.5 - 4)^2 = 1.5^2 = 2.25\).

AlphaZero plays Go by combining a learned policy and value with Monte Carlo tree search over the game’s rules. How is it best classified?

The rules are a known model used for search: model-based. AlphaZero used no human games (that was AlphaGo); MuZero learns its model.

Select all the failure modes of deep RL named on the slides.

The slide lists sample efficiency, instability, reward misspecification, generalisation and (for model-based) model error. Instability is a risk, not a guarantee.

In multi-agent hide and seek, both teams learn at the same time. Why is this different from a single-agent MDP?

From each agent’s point of view, the others are part of the environment, and they keep changing their behaviour. That’s the bridge to game theory in week 7.

Which pairing is correct?

AlphaGo (2016) used human games, self-play and search; AlphaZero (2018) dropped human games; MuZero learns a model instead of being given the rules.

What do the critic and actor need at deployment (after training) in a typical actor–critic agent?

The critic is primarily a training aid (slide 20); the actor can act alone.
