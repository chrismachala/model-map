Mock Quiz 2

Fifteen questions drawn at random from a bank covering weeks 4 to 7, in Quiz 1's style: short scenarios, one best answer, a matching question, select-all, and a number to type. Give yourself 30 minutes, the same as Quiz 1, and no notes.

How to sit this mock

  • Set a 30-minute timer. Quiz 1 took you 32 minutes for 15 questions.
  • Read every option before choosing: the distractors are built from the confusions the lectures warn about (replay vs target network, workflow vs agent, decoding vs training, Pareto vs Nash).
  • After submitting, read the explanation for every question you missed, then follow the link to that topic’s page. Retake: you’ll get a different draw.

Mock quiz

A customer-support system sends every email through the same three LLM calls in a fixed order: summarise, classify urgency, draft a reply. Which describes it?

Control decides it: the model never chooses the next step.

Match each fix to the DQN problem it addresses. Which pairing is fully correct?

Replay samples randomly from stored transitions; the target network freezes the targets; four frames reveal motion.

DQN, \(\gamma = 0.9\). A non-terminal transition has \(r = 1\) and the target network gives \(Q_{\theta^-}(s', \cdot) = (2, 5, 3)\). What is the target \(y\)?

\(1 + 0.9 \times 5 = 5.5\).

Which of the following updates the model’s parameters \(\theta\)?

Only training changes \(\theta\).

A model uses greedy decoding. Its temperature is changed from 1 to 0.5. What happens to its output?

Greedy always takes the top token, and dividing logits by \(T\) doesn’t change which is top.

A coding model is trained by rewarding solutions that pass hidden unit tests. Which method is this, and what is its known risk?

Verifiable rewards from tests. DPO, by contrast, has no separate reward model.

Where should the rule “do not book without approval” live to be enforced regardless of what the model generates?

The first three are advisory text the model must obey.

A model outputs a call to a tool that isn’t in its tool list. What should the harness do?

Validate: known tool? valid arguments? permitted? Rejections go back into the context.

Step 2’s search showed #441 at $490; step 12’s check_fare(441) returned $560. Much later the passenger asks “How much was #441 again?” What will the model report?

Slide 35’s poll. Reconcile: current fact with source and time, old one marked superseded.

Query: “What is the carry-on allowance?” Passage: “Cabin baggage: one item up to 8 kg is included on all fares.” Which retrieval method finds it?

No shared words (keyword misses); same meaning (vector finds).

Match the memory type to the example. Which pairing is fully correct?

Past events, stored facts, how-to.

Every morning, check one fare and email the passenger if it falls below $450. What is the cheapest adequate architecture?

Nothing must be decided at run time.

Select all that are part of the harness rather than the learned model.

Only \(p_\theta\) is learned.

A run ends with “Done, I’ve booked you on #517”, but no booking tool was exposed. Which engineered check would have caught the false claim?

Autopsy run 3.

In the prisoner’s dilemma (T = 4, R = 3, P = 2, S = 1), which outcome is the unique Nash equilibrium?

From (D, D) switching to C drops you to 1; from every other cell someone gains by switching to D.

In the prisoner’s dilemma, select all Pareto optimal outcomes.

Only (D, D) is Pareto dominated (by (C, C)).

Payoffs (i, j), \(i\) on rows: (a, c) = (5, 5), (a, d) = (8, 2), (b, c) = (2, 8), (b, d) = (3, 3). Which is a Nash equilibrium?

Neither player gains by deviating alone from (a, c).

Two agents know they’ll play the prisoner’s dilemma exactly 10 times. What does backwards induction predict?

The last round is one-shot → defect; then the one before is effectively last, and so on.

Five rounds, payoffs T = 4, R = 3, P = 2, S = 1. TIT-FOR-TAT plays ALLD. What is TIT-FOR-TAT’s total?

1 + 2 + 2 + 2 + 2 = 9.

Matching pennies has which equilibrium?

No pure NE; the 50/50 mix makes each player indifferent.

Q-learning: \(Q(s,a) = 2\), \(\alpha = 0.1\), \(\gamma = 0.9\), \(r = 1\), \(\max_{a'} Q(s', a') = 3\). New \(Q(s,a)\)?

\(2 + 0.1(1 + 2.7 - 2) = 2.17\).

Which statement about AlphaZero is correct?

Model-based with a given model; self-play only.

An agent has dozens of skills, but only each skill’s name and one-line description sit in its context until one is needed. What is this?

Discover → load → use.

Which is a difference between pretraining and RL?

Distinction 3 of the five; RL appears in post-training (RLHF, RLVR).
