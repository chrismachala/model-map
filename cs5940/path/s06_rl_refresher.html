Week 4 refresher: MDPs and Q-learning

Quiz 2 will almost certainly include week 4, and week 5 builds straight on it. A fast pass over the MDP pieces, returns, Bellman, value iteration vs Q-learning, ε-greedy, POMDPs and reward hacking, with the hand calculations a quiz can ask for.

Full notes: the week 4 pages (return and value, value iteration, Q-learning, exploration, POMDPs, when RL goes wrong).

1. MDPs, return and value

An MDP: states \(S\), actions \(A\), transitions \(P(s' \mid s, a)\), rewards \(R\), discount \(\gamma\). Markov property: the next state depends only on the current state and action. The answer is a policy \(\pi: S \to A\), not a fixed plan, because outcomes are random. Return \(G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots\); value = expected return.

Rewards along a run: −0.04, −0.04, −0.04, −0.04, +1, with \(\gamma = 0.9\). What is the return \(G_0\)? (Four decimals.)

Backwards: \(G_4 = 1\), \(G_3 = -0.04 + 0.9 = 0.86\), \(G_2 = 0.734\), \(G_1 = 0.6206\), \(G_0 = -0.04 + 0.9 \times 0.6206 = 0.5185\).

2. Value iteration vs Q-learning

Value iteration (planning) needs the model \(P\), \(R\): repeat \(V(s) \leftarrow \max_a \sum_{s'} P(s' \mid s, a)[R + \gamma V(s')]\) until it settles. Q-learning (model-free) learns from samples: \(Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma \max_{a'} Q(s', a') - Q(s,a)]\). Off-policy (learns greedy values while exploring), bootstraps on its own estimates.

\(Q(s, a) = 2\), \(\alpha = 0.1\), \(\gamma = 0.9\), \(r = 1\), and \(\max_{a'} Q(s', a') = 3\). What is the new \(Q(s, a)\)?

Target \(1 + 2.7 = 3.7\); TD error \(1.7\); new \(Q = 2 + 0.17 = 2.17\).

3. Exploration, POMDPs, reward hacking

ε-greedy: with probability ε act at random (over all actions), else greedy. Greedy action probability \(1 - \varepsilon + \varepsilon/|A|\). POMDP: the agent can’t see the state, so it keeps a belief (a probability over states) updated by predict → correct → normalise. Reward hacking: high reward, wrong behaviour (the boat going in circles collecting points).

\(|A| = 4\) and \(\varepsilon = 0.2\), with the random choice made over all four actions. What is the probability of taking the greedy action?

\(0.8 + 0.2/4 = 0.85\).

Stage test

Which statement is the Markov property?

Knowing the state is full observability (POMDPs drop it); knowing \(P\) is what planning needs.

Why is the solution to an MDP a policy rather than a fixed sequence of actions?

A plan can be wrecked by the first slip; a policy covers every state.

What does value iteration need that Q-learning doesn’t?

Planning sweeps the known model; Q-learning learns from sampled transitions.

\(Q(s, a) = 2\), \(\alpha = 0.1\), \(\gamma = 0.9\), \(r = 1\), and \(s'\) is terminal. What is the new \(Q(s, a)\)?

Terminal: target \(= 1\); TD error \(= -1\); new \(Q = 2 - 0.1 = 1.9\).

Why is Q-learning called off-policy?

The \(\max_{a'}\) in the target is what makes it off-policy.

\(|A| = 3\) and \(\varepsilon = 0.3\), random choice over all three actions. What is the probability of the greedy action?

\(0.7 + 0.3/3 = 0.8\).

\(Q^*(s, \cdot) = \{N: 0.3,\ S: -0.2,\ E: 0.8,\ W: 0.5\}\). What is \(V^*(s)\)?

\(V^*(s) = \max_a Q^*(s, a) = 0.8\), and \(\pi^*(s) = E\).

A robot can’t tell two identical-looking corridors apart, but must act differently in each. In week 4 terms, what does it need?

Quiz 1 asked the same idea: internal state that tracks where it has been. Week 4 calls it a belief over states in a POMDP.

A boat-racing agent learns to circle forever collecting bonus points instead of finishing the race. What is this?

High measured reward, unwanted behaviour. Week 5 lists it again as reward misspecification.

With \(\gamma\) close to 0, what does the agent care about?

\(\gamma^k\) shrinks fast when \(\gamma\) is small, so later rewards barely count.
