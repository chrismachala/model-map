Game theory and the prisoner's dilemma

Week 7: read a payoff matrix, find dominant strategies and Nash equilibria, spot Pareto optimal and welfare-maximising outcomes, and know the prisoner's dilemma, its iterated version and the beauty contest cold.

Full notes: Utilities and games, Solution concepts, The prisoner’s dilemma. In this stage every matrix is written (i, j) with i choosing the row.

1. Best responses, dominance, Nash

For each of \(j\)’s columns, mark \(i\)’s best row; for each of \(i\)’s rows, mark \(j\)’s best column. A player whose best response never changes has a dominant strategy. A cell with both marked is a pure Nash equilibrium: no one gains by deviating alone.

\(j\): c \(j\): d
\(i\): a (5, 5) (8, 2)
\(i\): b (2, 8) (3, 3)

In the matrix above, which outcome is a pure Nash equilibrium?

At (a, c): \(i\) switching to b gets 2 < 5; \(j\) switching to d gets 2 < 5. Every other cell has someone who gains by switching.

2. Pareto and social welfare

Pareto optimal: no other outcome makes someone better off without making someone worse off. Social welfare: the sum of utilities. In a zero-sum game utilities always add to 0, so every outcome is Pareto optimal.

Prisoner’s dilemma: (D, D) = (2, 2), (D, C) = (4, 1), (C, D) = (1, 4), (C, C) = (3, 3).

In the prisoner’s dilemma above, select all Pareto optimal outcomes.

(C, C) beats (D, D) for both, so only (D, D) is Pareto dominated.

3. Mixed strategies

Matching pennies has no pure NE. The mixed NE: each plays heads with probability 0.5, making the other indifferent (\(EU = 0\) either way). Every finite game has at least one NE in mixed strategies.

Matching pennies: \(i\) gets +1 if the coins match and −1 otherwise. If \(j\) plays heads with probability \(q\), then \(EU_i(H) = 2q - 1\) and \(EU_i(T) = 1 - 2q\). For which \(q\) is \(i\) indifferent?

\(2q - 1 = 1 - 2q \Rightarrow q = 0.5\).

4. Recovering cooperation

  • Program equilibria: submit “IF TheirProgram == ThisProgram THEN C ELSE D”; best response is the same program → (C, C), and it can never be suckered.
  • Infinitely repeated PD: cooperation can be rational. Known finite \(n\) rounds: backwards induction unravels to defect every round.
  • Axelrod: TIT-FOR-TAT (cooperate, then copy) won overall; GRIM (defect for ever after one defection); Pavlov (win-stay, lose-shift); ALLD.
  • Chicken: \((D, C) \succ (C, C) \succ (C, D) \succ (D, D)\): no dominant strategy, two pure NE, (C, D) and (D, C).
  • Beauty contest (\(\frac{2}{3}\) of the average): unique NE everyone picks 0; level-k: 50 → 33.3 → 22.2 → 14.8.

Five rounds of the PD (T = 4, R = 3, P = 2, S = 1). TIT-FOR-TAT plays ALLD. What is TIT-FOR-TAT’s total score?

TFT: C, D, D, D, D; ALLD: D every round. TFT scores 1 + 2 + 2 + 2 + 2 = 9 (ALLD scores 12).

Stage test

In the prisoner’s dilemma, what is the dominant strategy?

Against D, defecting gives 2 > 1; against C, 4 > 3. Same for both.

Which outcome of the prisoner’s dilemma maximises social welfare?

Sums: 4, 5, 5, 6. (C, C) = 6.

Payoffs (i, j), i on rows:

\(j\): \(s_3\) \(j\): \(s_4\)
\(i\): \(s_1\) (1, −1) (3, −3)
\(i\): \(s_2\) (−2, 2) (0, 0)

Which is a dominant strategy for \(i\)?

Against \(s_3\): 1 > −2. Against \(s_4\): 3 > 0. \(s_1\) is always better.

Payoffs (i, j), i on rows: (Swerve, Swerve) = (3, 3), (Swerve, Straight) = (2, 4), (Straight, Swerve) = (4, 2), (Straight, Straight) = (1, 1). How many pure Nash equilibria are there?

This is chicken. (Straight, Swerve) and (Swerve, Straight) are stable; at (Straight, Straight) both would swerve, at (Swerve, Swerve) both would go straight.

Which ordering of outcomes for \(i\) is the game of chicken?

  1. is the prisoner’s dilemma; chicken swaps the bottom two so mutual defection is worst. (C) cooperation dominates; (D) defection dominates.

Two agents will play the prisoner’s dilemma exactly 100 times, and both know it. What does backwards induction predict?

Round 100 is a one-shot game → defect; so round 99 is effectively last → defect; and so on back to round 1.

Each agent submits the program “IF TheirProgram == ThisProgram THEN DO(C) ELSE DO(D)” to a mediator. Why is this attractive?

The best response to this program is the same program: mutual cooperation, with no sucker’s payoff possible.

What does Pavlov do in the iterated prisoner’s dilemma?

Win-stay, lose-shift. (A) is TIT-FOR-TAT; (B) is GRIM; (D) is ALLD.

Matching pennies: which statement is correct?

Whatever pure pair is chosen, someone wishes they’d switched. The game is zero-sum, so every outcome has welfare 0.

Select all true statements about zero-sum games.

Matching pennies is zero-sum with no pure NE. Wooldridge: real zero-sum encounters are rare, though people often act as if they were.

Beauty contest: the target is \(\frac{2}{3}\) of the average. Level-0 players guess 50 on average. What does a level-2 player guess? (One decimal.)

Level 1: \(\frac{2}{3} \times 50 = 33.3\). Level 2: \(\frac{2}{3} \times 33.3 = 22.2\).

Which statement about TIT-FOR-TAT in Axelrod’s tournament is correct?

It scores less than or equal to its opponent in every match (against ALLD it loses), but collects many mutual-cooperation payoffs. It was the simplest entry.

\(u_i(D, D) = 1\), \(u_i(D, C) = 1\), \(u_i(C, D) = 4\), \(u_i(C, C) = 4\) (i’s action first). What is the rational choice for \(i\)?

\(i\) gets 4 from C whatever \(j\) does, and 1 from D whatever \(j\) does.
