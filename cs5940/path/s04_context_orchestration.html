Context, memory and orchestration

Week 6 second half: what goes into the context, RAG and keyword vs vector search, which price is current, the kinds of memory, and choosing the cheapest architecture that does the job.

Full notes: Context, retrieval and memory and Planning and orchestration.

1. Context engineering and RAG

The model sees only what the context builder puts in \(c_t\). Mechanisms: select (an excerpt, not the 40-page policy), filter (3 flights, not 25 in raw JSON), summarise (last week’s summary, not the transcript), disclose progressively (skill name, not full text), keep structured state (progress notes), prune history.

Knowledge routes: weights for general knowledge (not current), RAG over indexed documents, API tools for live data (fares, availability). A fixed retrieve-then-generate pipeline is a workflow. Retrieval gives sources, not guaranteed correctness.

The clerk needs today’s fare for flight #517. Where should it come from?

Live, authoritative data → API tool. Weights aren’t current; the policy document has rules, not today’s prices.

2. Keyword vs vector search

Keyword (BM25): shared words, rare words weigh more. Great for exact identifiers (“Y-2”); misses synonyms. Vector: embeddings, nearest by cosine similarity \(\frac{e(q) \cdot e(d)}{\lVert e(q) \rVert \lVert e(d) \rVert}\). Great for meaning (“carry-on” ≈ “cabin baggage”); can’t tell “Y-2” from “Y-3”. Production: hybrid.

\(e(q) = (1, 2, 2)\) and \(e(d) = (2, 1, 2)\). What is their cosine similarity? (Three decimals.)

Dot product \(2 + 2 + 4 = 8\); both lengths are 3; \(8/9 = 0.889\).

3. Which price is current? Memory types

Step 2: search says #441 $490. Step 12: check_fare says $560. Asked later, the model will usually say $560 but it depends: both are just text. The harness should reconcile: current fact ($560, with source and time), old one marked superseded, progress recomputed.

context \(c_t\) what the LLM sees now
working state \(m_t\) progress, constraints, current facts, pending steps
episodic past interactions, actions, outcomes
semantic stored facts
procedural how to do things: skills (and implicitly the weights)
RAG knowledge base searchable documents, not necessarily this agent’s memories

The agent stores “On 3 November the passenger rejected an overnight flight to Boston.” What kind of memory is this?

A record of a past interaction and its outcome: episodic.

4. Orchestration

Control patterns: incremental / ReAct (responsive; may drift), plan then execute (structured, fewer calls; plans go stale), hybrid (plan, act, monitor, replan; more engineering). Choose the cheapest adequate architecture by asking: what must be decided at run time? Daily fare check → workflow; one flight search → single agent loop; five-city tour → orchestrator with sub-agents (≈15× the tokens of a chat). A sub-agent has its own context. Reflection without new external information often fails.

Every morning a system checks one route’s fare and emails the passenger if it drops below $450. What is the cheapest adequate architecture?

Nothing needs deciding at run time beyond a fixed rule (slide 41, task A).

Stage test

Policy passages: P1 “Cabin baggage: one item up to 8 kg is included on all fares.” The passenger asks “What is the carry-on allowance?” Which retrieval method finds P1?

No words in common, so keyword misses it; “carry-on” and “cabin baggage” mean the same, so vector finds it.

The passenger asks “Can I change a ticket booked under Y-2?” Passages for fare rules Y-2 and Y-3 are worded almost identically. Which method is most likely to rank the Y-2 passage first?

“Y-2” is a rare exact token: keyword search wins. Vector search sees Y-2 and Y-3 as near-identical in meaning.

After compaction at step 9, the summary keeps #441 at $490 but drops the later $560 quote; the agent recommends #441 at $490. Which component failed?

Autopsy run 1. Fix: reconciled working state that survives compaction.

With a budget of 7,000 usable tokens and a question about cabin baggage on #517, which pair shows the filter mechanism?

  1. is summarise, (C) is progressive disclosure, (D) is select.

The flight-comparison procedure stored as a skill is an example of which kind of memory?

Knowing how to do something: procedural memory, stored outside the weights.

Which statement about RAG is correct?

Sources support checking but don’t guarantee correctness; live data comes from API tools; RAG changes the context, not the weights.

A 12-day, five-city conference tour needs flights, hotels near each venue, visa checks and a $6,000 budget. Which architecture fits best?

Breadth and parallel sub-tasks; each sub-agent gets a clean context. The cost is many more tokens.

Which is the main weakness of plan-then-execute compared with incremental (ReAct-like) control?

Clear structure and fewer calls, but stale plans; ReAct is responsive but may drift.

Slide 39. Commitment strategy ↔︎ how often the harness lets the model replan.

An agent re-reads its own answer and “critiques” it three times without running any tests or tools. What does the lecture say about this?

Ask of every extra loop: what new information does it bring? Reflexion uses real feedback stored in episodic memory.

\(e(q) = (1, 2, 2)\) and \(e(d) = (0, 0, 3)\). What is their cosine similarity? (Three decimals.)

Dot product \(6\); lengths 3 and 3; \(6/9 = 0.667\).
